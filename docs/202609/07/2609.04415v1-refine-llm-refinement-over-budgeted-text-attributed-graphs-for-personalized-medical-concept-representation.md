## 摘要
学习丰富的医学概念表示对于电子健康记录（EHR）预测至关重要。文本属性知识图谱（TKGs）通过组织异构医学关系及文本语义，为此提供了自然基础。然而，大多数现有编码器对患者统一处理概念，尽管代码的含义和预测价值取决于患者特定的临床背景和轨迹。从TKGs学习患者个性化的概念表示引入了两个关键挑战：（1）决定每个观察到的代码应纳入多少KG上下文，（2）将语义信息与患者特定的关系结构对齐。我们提出REFINE，一种KG感知的预算化LLM图精炼框架，用于患者个性化的医学概念编码。从全局TKG出发，REFINE构建患者特定的时间图。一个顺序强化学习策略为每个观察到的代码选择个性化的KG扩展预算。生成的患者图由异构GNN处理以捕获关系感知的结构依赖，而冻结的LLM使用图感知的软提示来语义精炼概念表示。在MIMIC-III和MIMIC-IV上的实验表明，REFINE持续改进多种EHR骨干模型，优于强基线，并在组件消融、KG选择和数据不足方面表现出稳健的提升。

## Abstract
Learning rich medical concept representations is essential for EHR prediction. Text-attributed knowledge graphs (TKGs) provide a natural foundation by organizing heterogeneous medical relations together with textual semantics. However, most existing encoders process concepts uniformly across patients, despite the fact that a code's meaning and predictive value depend on patient-specific clinical context and trajectory. Learning patient-personalized concept representations from TKGs introduces two key challenges: (1) deciding how much KG context to incorporate for each observed code, and (2) aligning semantic information with the patient-specific relational structure. We propose REFINE, a KG-aware budgeted LLM graph refinement framework for patient-personalized medical concept encoding. Starting from a global TKG, REFINE constructs patient-specific temporal graphs. A sequential reinforcement learning policy selects a personalized KG expansion budget for each observed code. The resulting patient graph is processed by a heterogeneous GNN to capture relation-aware structural dependencies, while a frozen LLM uses graph-aware soft prompts to semantically refine concept representations. Experiments on MIMIC-III and MIMIC-IV show that REFINE consistently improves diverse EHR backbones, outperforms strong baselines, and demonstrates robust gains across component ablation, KG selection, and data insufficiency.

## 2. 论文提出的方法论

### 2.1 方法总体流程
REFINE 包含五个主要步骤（如图 1 所示）：
1. 构建覆盖全部医学代码的全局文本属性医疗 KG；
2. 为每位患者提取包含患者节点、就诊节点、观测代码节点和所选 KG 邻居节点的个性化时序图；
3. 学习一个图预算策略（graph-budgeting policy），用**顺序强化学习（RL）** 决定每个观测代码的 KG 扩展深度和每跳邻居数量；
4. 用并行双分支处理个性化图：异构 GNN 捕获结构依赖，冻结 LLM 通过图感知混合软提示进行语义精炼；
5. 将两分支表示进行门控融合，用于下游 EHR 预测。

### 2.2 全局 TKG 构建
- 代码词汇表 $C = C_{dx} \cup C_{rx} \cup C_{px}$。
- 从纵向 EHR 中提取候选代码对证据：就诊内共现、相邻就诊转移，统计支持度、条件概率、平滑 PMI 和显著性检验（$\chi^2$）。
- 筛选后的代码对由**类型约束的 LLM 关系归纳**分配有向语义关系（如 treats、leads_to、diagnostic_of）和临床理由文本。
- 每个节点关联概念描述 $d_v$，每条边关联关系理由 $\eta_e$，形成文本属性图 $G = (V,E,\phi,\psi)$。

### 2.3 患者个性化图构建
- 对患者 $p$ 的历史 $X_{\le t^*}$，构造 $G_p^{\le t^*} = (V_p, E_p)$。
- 节点包括：患者节点、各就诊节点、观测代码节点和选中的 KG 邻居代码节点。
- 边包括两类结构：EHR 结构边（患者-就诊、就诊-代码）和从全局 TKG 映射来的选中 KG 边。
- 不同类型节点/边均保留类型、文本描述等属性。

### 2.4 个性化子 KG 提取（RL 预算策略）
- **扩展动作**：$a = (K, m)$，其中 $K$ 为扩展深度（0~$K_{\max}$），$m=(m_1,\dots,m_K)$ 为每跳邻居数。例如 $a=(2,(2,1))$ 表示从根代码先取 top-2 一跳邻居，再对每个一跳邻居取 top-1 二跳邻居。邻居排序基于 KG 构建时计算的证据评分。
- **顺序决策**：对患者每个不同观测代码 root，策略在每一步选择一个宏动作 $b_\ell = (c,a)$，更新该代码的扩展动作。每一步状态包含患者历史、已添加的 KG 上下文、剩余预算等。
- **奖励设计**：用冻结的 GNN-only 代理预测器计算加入选中图前后的损失差：
  $R_p = L_p(G_p^0) - L_p(G_p^{sel}) - \lambda_{\text{cost}} C_p$，
  其中 $C_p$ 为选中的额外节点和边的数量加权惩罚。
- **优化目标**：actor-critic 目标加熵正则，advantage 为 $A_\ell = R_p - V_\omega(s_\ell)$，总 RL 损失如公式 (15) 所示。
- 训练时采样动作，推理时采用贪婪选择。算法整体分为两阶段（Algorithm 1）：阶段一训练 RL 政策并冻结代理 GNN；阶段二固定选好的图，训练完整 REFINE。

### 2.5 图感知 LLM 精炼
- **初始化**：对每个代码节点，用可学习嵌入与文本语义编码的残差混合初始化；KG 边同理融合关系嵌入和理由文本。
- **GNN 分支**：异构图神经网络，按边类型计算消息并聚合，每层用类型相关更新函数更新节点表示，最终得到结构表示 $h^G_{p,c}$。
- **LLM 分支**：保持 LLM 完全冻结，用软提示注入信息：
  - 代码软提示 token = 投影代码残差表示；
  - KG 上下文软提示 token = 对选中 KG 子图做轻量 GNN 聚合（KGPool）后投影到 LLM 隐藏空间。
  - 硬文本 token 编码任务说明、就诊-代码层级结构和代码名称/类型。
  - 最终 prompt 结构为 `[task, query, {visit blocks}]`，每个代码块为 `[name, type, code_soft, kg_soft]`。
- LLM 编码混合序列后，取出每个观测代码对应位置处的隐藏状态，投影回原始空间作为语义精炼表示。
- **门控融合**：
  $g_{p,t,c} = \sigma(W_F [h^G_{p,c}; h^L_{p,t,c}])$，
  $z_{p,t,c} = g_{p,t,c} \odot h^L_{p,t,c} + (1-g_{p,t,c}) \odot h^G_{p,c}$，
  最终 $z$ 为输给下游预测头的个性化概念嵌入。

### 2.6 与下游模型集成
REFINE 作为即插即用概念编码器，可接入 AdaCare、Transformer、RETAIN、TCN 等标准 EHR 模型，输出每个代码的个性化表示，再聚合进患者表示进行下一就诊诊断预测。

## 6. 论文的主要结论与发现

- REFINE 作为即插即用编码器，在 MIMIC-III/IV 上的五种下游 EHR 骨干上均带来一致提升，表明方法具有通用性。
- 在整体性能对比中，REFINE 在两个数据集上的 AUPRC、F1、Acc@k 均优于 12 种基线（MIMIC-III AUPRC 47.41 vs MedCo 45.35；MIMIC-IV AUPRC 50.24 vs MedCo 48.28），并在 8 个标签频率分层中赢得 6 个最高 AUPRC。
- 消融显示：组件按贡献排序依次为**个性化 GNN 结构**（贡献最大）、**RL 预算**、**LLM 语义精炼**、**软提示与 KG 软 token**。即使移除 LLM 精炼，REFINE 也超越 MedCo，证明个性化预算图构造本身具有独立价值。
- RL 预算学习不会退化为单一固定动作，而是学会在不同患者-代码组合中采用混合的 0-hop、1-hop、2-hop 预算，符合直觉：罕见代码在短病史中更倾向获得深度扩展，高频常规药物往往不扩展。
- 数据不足时，REFINE 在 25%–100% 训练集比例下均稳定提升各骨干表现，低数据情境下增益更明显。
- 将 Llama-3.2-1B 换为更小的 Qwen2.5-0.5B 时，性能呈小幅下降但仍保持竞争力，说明 REFINE 对冻结 LLM 主干具有一定鲁棒性。

## 7. 优点

- **问题定位精准**：识别出“同一医学代码在不同患者中的语义与预测意义不同”这一关键盲点，区别于只学习全局静态概念表示的方法。
- **RL 预算机制新颖**：将 KG 扩展深度/扇出定义为离散动作，并用顺序决策使后续代码的预算选择可以参考已选上下文，而非逐个代码独立决策。
- **避免直接序列化全部 KG**：LLM 提示中采用“代码软 token + KG 软 token”的紧凑表示，不修改 LLM 参数也不显式展开全部关系文本，工程上高效且可扩展。
- **两阶段训练设计合理**：先在 GNN-only 代理上做预算选择，避免在 RL 迭代中重复调用 LLM，进而显著降低训练复杂度；第二阶段模型分离度好。
- **即插即用架构**：可接入多种下游模型，实验验证了 RETAIN、TCN、Transformer 等多种架构的一致增益，说明模块化好。
- **实验分析较全面**：包含消融、KG 选择策略对比、动作分布分析、定性个例展示（表 4）、数据稀缺、LLM 主干敏感性等多角度验证。
- **文本-结构深度融合**：GNN 提供结构表示，LLM 提供语义表示，通过门控融合，兼顾局部关系与全局语义，比单分支方法更全面。
