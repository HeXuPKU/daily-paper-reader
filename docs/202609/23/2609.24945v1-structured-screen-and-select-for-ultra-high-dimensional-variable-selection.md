## 摘要
在基因组学和生物医学研究中，p 远大于 n 的超高维数据十分常见。边际筛选可能会遗漏边际信号较弱的活跃预测变量，尤其是在预测变量之间存在强相关时。我们开发了结构化筛选-选择变量选择（Structured Screen-and-Select Variable Selection，S3VS），这是一个迭代框架，将基于结局的筛选与基于相关性的局部预测变量集合相结合。在每次迭代中，S3VS 识别主导变量，通过预测变量关联形成局部集合，应用特定于模型的选择器，汇总选中的和未选中的变量，并更新候选集，以及在适当时更新结局表示。该框架允许灵活的主导变量规则、局部集合规则和聚合规则，并提供了线性模型、广义线性模型、加速失效时间模型和 Cox 模型的实现。对于指定的一步线性配置，我们在代理覆盖、相关性分离、集合内保留和活跃变量保留式聚合等条件下建立了确定性筛选性质。模拟研究在线性、Logistic 和 Cox 情形下，将完整 S3VS 与首次迭代 S3VS 同单遍 SIS 流程进行比较。当相关预测变量提供有用的代理信息时，S3VS 可以改善变量恢复或预测，尽管收益取决于预测变量结构和选择器选择。在卵巢癌数据中，纳入临床变量的完整 S3VS 显示出最强的内部判别和早期预测，而纳入临床变量的 SIS-Cox-LASSO 显示出最强的外部判别。两种分子方法均未持续降低预测误差，且没有任何基因在所有五个外层折中均被选中。S3VS 提供了一个灵活框架，可在模型特定选择之前利用预测变量依赖性。该方法已在 CRAN R 包 S3VS 中实现。

## Abstract
Ultra-high-dimensional data, with p far exceeding n, are common in genomics and biomedical research. Marginal screening can miss active predictors with weak marginal signals, especially under strong predictor correlation. We develop Structured Screen-and-Select Variable Selection (S3VS), an iterative framework that combines outcome-based screening with correlation-based local predictor sets. At each iteration, S3VS identifies leading variables, forms local sets through predictor associations, applies a model-specific selector, aggregates selected and nonselected variables, and updates the candidate set and, when appropriate, the outcome representation. The framework allows flexible leading-variable, local-set, and aggregation rules, with implementations for linear, generalized linear, accelerated failure-time, and Cox models. For a specified one-step linear configuration, we establish sure screening under conditions on proxy coverage, correlation separation, within-set retention, and active-preserving aggregation. Simulations compare full and first-iteration S3VS with one-pass SIS procedures in linear, logistic, and Cox settings. S3VS can improve variable recovery or prediction when correlated predictors provide useful proxy information, although gains depend on predictor structure and selector choice. In ovarian-cancer data, full S3VS with clinical variables showed the strongest internal discrimination and early prediction, whereas SIS--Cox--LASSO with clinical variables showed the strongest external discrimination. Neither molecular approach consistently reduced prediction error, and no gene was selected in all five outer folds. S3VS provides a flexible framework for exploiting predictor dependence before model-specific selection. The method is implemented in the CRAN R package S3VS.

## 1. 核心问题与整体含义

- **研究背景**：超高维数据（p ≫ n）在基因组学、转录组学、蛋白质组学与医学影像等领域极为常见。科学目标通常是从海量候选预测变量中识别少数真正与结局相关的"活跃变量"。
- **核心痛点**：
  - 以 SIS（Sure Independence Screening, Fan & Lv 2008）为代表的边际筛选方法，仅依赖预测变量与结局的边际关联排序，**容易遗漏边际信号微弱但与其他变量联合贡献或强相关的活跃变量**。
  - 强共线性会同时破坏筛选的可靠性并使惩罚回归模型不稳定。
  - 直接对全部 p 个变量拟合 LASSO、SCAD、Dantzig 等惩罚方法在 p 极大时计算昂贵。
- **核心思想来源**：作者基于其前期工作 GWASinlps（Sanyal et al., 2019）提出的"**主导变量（leading variable）**"与"**主导集（leading set）**"概念，将预测变量依赖关系从"估计障碍"转变为"筛选信息源"。
- **整体含义**：论文提出 **S3VS（Structured Screen-and-Select Variable Selection）**，将基于结局的筛选与基于预测变量相关性的局部集合构造相结合，形成一个可迭代、模块化、支持多种统计模型的统一变量选择框架，并配有公开 R 包 `S3VS`（CRAN）。

## 2. 方法论

### 2.1 核心思想

- 每个迭代将原超高维问题**分解为若干低维子问题**，在每个局部主导集内拟合模型特定选择器，再通过聚合规则合并决策。
- 迭代机制允许在排除部分变量后重新评估剩余候选变量，并（对部分模型）更新结局表示。

### 2.2 五步迭代流程（Algorithm 1）

1. **确定主导变量**：对当前候选集 A⁽ⁱ⁾ 中的每个变量计算预测-结局筛选得分 Aᵢ(r)，按 Top-k / 固定阈值 / 相对最大值规则选出 kᵢ 个主导变量，按得分降序排列并保留次序（后续保守聚合依赖此顺序）。
2. **确定主导集**：对每个主导变量 zⱼ⁽ⁱ⁾，以预测-主导变量关联得分 Bᵢⱼ(r)（本文实现采用**绝对 Pearson 相关系数**）构造主导集 Sⱼ⁽ⁱ⁾，规则包括 Top-q / 固定阈值 / 相对最大值（当使用绝对相关且主导变量在候选集内时，相对最大值规则等价于固定阈值 τ_B = α_B）。
3. **主导集内选择**：对每个主导集独立拟合选择算子 V，输出 (Sⱼ,ₛₑₗ⁽ⁱ⁾, Sⱼ,ₙₒₛₑₗ⁽ⁱ⁾)。支持 LASSO、Elastic Net、SCAD、MCP、NLP（非局部先验）、bridge 惩罚、AFTGEE、PVAFT 等。
4. **聚合集内决策**：
   - 由最高排名主导集是否选出变量定义 Dᵢ = I{S₁,ₛₑₗ⁽ⁱ⁾ ≠ ∅}，使"选择"与"排除"在单次迭代中互斥。
   - **选中变量聚合**：Conservative Selection（前缀交集，取最后一个非空前缀交集）或 Liberal Selection（并集）。
   - **未选中变量聚合**：Conservative Exclusion from the Beginning（前缀交集）、Conservative Exclusion from the End（后缀交集）或 Liberal Exclusion（并集）。
5. **更新结局与算法状态**：M⁽ⁱ⁺¹⁾ = M⁽ⁱ⁾ ∪ Sₛₑₗ⁽ⁱ⁾；A⁽ⁱ⁺¹⁾ = A⁽ⁱ⁾ \ (Sₛₑₗ⁽ⁱ⁾ ∪ Sₙₒₛₑₗ⁽ⁱ⁾)；y⁽ⁱ⁺¹⁾ = U(y⁽ⁱ⁾, Sₛₑₗ⁽ⁱ⁾, Sₙₒₛₑₗ⁽ⁱ⁾, Dᵢ)。失败迭代计数器 cᵢ₊₁ = cᵢ + I(Dᵢ = 0)，且**不因成功迭代而重置**。

### 2.3 停止规则与返回模型

- 循环条件：|M⁽ⁱ⁾| < m_max，|A⁽ⁱ⁾| > 0，cᵢ < n_skip，且未触发终止标志。
- 返回累计选中集 M̂ = M⁽ⁱˢᵗᵒᵖ⁾；**不返回系数向量**，需另行联合拟合后选择模型。排除是不可逆的（无再入机制）。

### 2.4 模型特定实现

- **线性模型**：Aᵢ(r) = Cor(x_r, y⁽ⁱ⁾)；更新为 OLS 残差 y⁽ⁱ⁺¹⁾ = y⁽ⁱ⁾ − β̂₀1 − X_{Q⁽ⁱ⁾}β̂。
- **广义线性模型（二元 Logistic）**：Aᵢ(r) = 平方点二列相关 dCor(y⁽ⁱ⁾, x_r)²（与边际 Logistic 得分检验排序等价）；更新为可选，按阈值 h = 0.5 保留二元响应。
- **AFT 模型**：第一迭代用边际效用 MU_r，后续用条件效用 CU_r⁽ⁱ⁾（基于 Weibull AFT 的极大似然）；结局表示不变。
- **Cox 模型**：第一迭代用边际偏差下降 D₀ − D_marg,r，后续用条件偏差下降；结局表示 (t, d) 不变，M⁽ⁱ⁺¹⁾ 进入下一轮条件筛选。

### 2.5 理论结果（一步线性配置）

- **Assumption 3.1–3.6**：维度假设、Fan–Lv 型边际得分条件、代理边际强度、次高斯预测变量、相关性分离、集合内条件集式确定性筛选性质。
- **Theorem 3.7**：在上述假设及 ξ < 1 − 2κ_L、2κ_L + τ < θ_L < 1、d_L ≍ n^θ_L、|P*| ≤ d_L 下，一步 S3VS 的失败概率上界为
  P{M* ⊄ Sₛₑₗ⁽¹⁾} ≤ C₁ exp(−C₂ n^{1−2κ_L}/log n) + C₃p² exp(−c₂ n aₙ²) + C_V d_L exp(−c_V n^ζ)。
- **Corollary 3.8**：当 κ_L < κ_M 时，S3VS 推导失败概率上界的主项比 SIS 衰减更快。
- **Corollary 3.9**：候选池大小 D_S3VS ≤ d_L m_n = O(n^{θ_L+α})，在 θ_L + α < θ_M 时小于 SIS 的 d_SIS。
- **Corollary 3.10**：后筛选估计误差中的对数因子可减小（条件性结论）。
- **Proposition 3.11**：存在无代理信号优势的设计（如 x ∼ N(0, I_p) 且仅活跃变量有信号），此时一步 S3VS 退化为 SIS，无严格速率优势。
- **理论边界**：仅覆盖**一步线性**配置，不覆盖后续迭代、数据依赖的结局更新、保守聚合、排除分支及 GLM/AFT/Cox 实现。

## 3. 实验设计

### 3.1 线性模型模拟

- **网格**：n ∈ {200, 500, 800}，p ∈ {10,000, 15,000, 20,000}，13 个命名设计场景，3 个信噪比水平（SNR = 0.25 / 1 / 4），每组合 **100 次独立重复**，共 **35,100 次重复**。
- **13 个场景**：独立预测变量、不等正相关块、4 种代理/无代理配置（代理抵消、共享代理、零代理、误导性零）、AR(1)、潜因子、稀疏成对图、重叠因子模块、带符号负相关、重尾、行/特征污染。
- **活跃变量**：每重复 25 个活跃坐标。
- **对比方法（12 个）**：对 LASSO / SCAD / MCP / NLP 四种选择器，分别比较 **完整 S3VS**、**S3VS 首次迭代（one-step）**、**单遍 SIS + 同一选择器**。
- **评价指标**：TPR、确定性筛选概率、条件 FDP、无条件 FDP、精度、FP/FN、F-score、非空选择概率、模型规模、系数误差、独立测试 MSE；系数误差与测试 MSE 用统一的后选择 LASSO 重拟合。

### 3.2 二元 Logistic 模拟

- 网格同上（n × p 共 9 组合，每组合 100 重复）。
- **两种结构**：无代理（全独立）；相关代理（前 100 个预测变量成对相关 0.60，前 25 个活跃，其余 75 个为活跃变量的零代理）。
- **对比**：S3VS（top-1 主导变量、5 变量主导集、Liberal 聚合、Conservative-from-beginning 排除、LASSO 1se）vs **SIS–logistic–LASSO**。
- **指标**：非空选择概率、TPR、FDP、模型规模、独立测试 log-loss。

### 3.3 Cox 比例风险模拟

- 网格同上，两种结构（无代理 / 相关代理）。
- **主比较**：将 S3VS 限制为**一次迭代**（m_max = 1, n_skip = 1），以匹配单遍 SIS–Cox–LASSO；完整迭代结果作为次要分析。
- **对比方法**：S3VS（top-1 结局筛选、相对最大值 π_B = 95 主导集、Cox LASSO 1se）vs **SIS–Cox–LASSO**（基于边际 Cox Wald 统计量取前 min(200, n−1, p) 个）。
- **指标**：非空选择概率、TPR、无条件 FDP、模型规模、独立测试 C-index。

### 3.4 卵巢癌数据分析

- **发现集**：TCGA_eset（curatedOvarianData 包），Affymetrix HT HG U133A；结局为总生存期。
- **临床变量**：初诊年龄、肿瘤分期、分级、减瘤状态。
- **外部验证集**：GSE9891（285 例浆液性/子宫内膜样卵巢肿瘤，Affymetrix HG U133 Plus 2.0）。
- **设计**：事件分层五折外层验证；每折内比较 one-iteration S3VS、full-iteration S3VS、SIS–Cox–LASSO；将各自筛选流程应用于完整 TCGA 队列，锁定预测变量集与模型参数，再在 GSE9891 上外部评估。
- **性能指标**：Harrell C-index、1/3/5 年时变 AUC、积分 Brier 分数（IBS）；主结果为更保守的 λ₁ₛₑ 拟合。
- **Benchmark**：临床变量基线模型。
