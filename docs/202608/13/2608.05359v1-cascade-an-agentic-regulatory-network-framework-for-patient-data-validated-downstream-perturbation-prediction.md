## 摘要
CASCADE是一个智能体框架，它通过MCP从预计算的ARACNe调控网络中预测基因扰动的下游转录效应。先前的工作通过检查预测基因是否为已知癌症基因（成员资格）来验证此类工具；我们则测试预测的变化方向是否与现实一致，使用焦点基因拷贝数扩增作为敲低逆过程的剂量代理，并基于真实的TCGA患者肿瘤数据进行验证。对于MYC，CASCADE预测的敲低靶标在三种癌症类型中与真实扩增与未扩增肿瘤表达高度一致（BRCA：90.0%，COAD：72.0%，STAD：85.7%；所有p<0.0013），远高于排列基线，并通过了PAM50亚型对照，且在独立队列（METABRIC，87.2%）中得以重复。与经过筛选的MSigDB基因集基线通过Fisher精确检验进行比较，CASCADE的准确性并未表现出超越现有的MYC或E2F驱动生物学公共知识，但其基因特异性的方向判定明显优于朴素的均匀猜测。扩展到另外十五个基因，验证显示其具有基因特异性而非普遍性：增殖机制调节因子大多可重复，而谱系身份转录因子和一个细胞周期蛋白D旁系同源物（CCND2）则持续失败，我们将这一模式作为对冲后的事后假设进行讨论。我们另外评估了基于LLM的智能体是否能正确地将自然语言请求落实到CASCADE的真实MCP工具调用中。在35个查询中，一个有文档记录的本地模型达到71.4%的精确匹配（较大模型为85.7%）；模式和基因别名失败可通过规模或服务器端修正解决，但两个模型在模糊查询上都自信地默认使用错误的扰动类型，这一失败无法通过定向修复解决，因为其触发条件从未出现。

## Abstract
CASCADE is an agentic framework that predicts downstream transcriptional effects of gene perturbation from precomputed   ARACNe regulatory networks, exposed via MCP. Prior work validates such tools by checking whether predicted genes are   known cancer genes (membership); we instead test whether the predicted direction of change matches reality, using   focal-gene copy-number amplification as a dosage-based proxy for the inverse of knockdown against real TCGA patient   tumor data.   For MYC, CASCADE's predicted knockdown targets show strong concordance with real amplified-vs-non-amplified tumor   expression across three cancer types (BRCA: 90.0%, COAD: 72.0%, STAD: 85.7%; all p<0.0013), well above permutation   baselines, surviving a PAM50 subtype control and replicating in an independent cohort (METABRIC, 87.2%). Compared   against curated MSigDB gene-set baselines via Fisher's exact test, CASCADE's accuracy is not shown to exceed existing   public knowledge of MYC- or E2F-driven biology, though its gene-specific direction-calling clearly outperforms a naive   uniform guess.   Extending to fifteen additional genes, validation proves gene-specific rather than universal: proliferation-machinery   regulators mostly replicate, while lineage-identity transcription factors and one cyclin-D paralog (CCND2)   consistently fail, a pattern we discuss as a hedged, post-hoc hypothesis.   We separately benchmark whether an LLM-based agent correctly grounds natural-language requests into CASCADE's real MCP   tool calls. Across 35 queries, a documented local model reaches 71.4% exact match (85.7% for a larger model); schema   and gene-alias failures are resolved by scale or server-side correction, but both models confidently default to the   wrong perturbation type on ambiguous queries, a failure a targeted fix could not resolve because its trigger condition   never occurs.

- **研究背景**：预测基因扰动（如敲低或过表达）的下游转录后果是癌症系统生物学的核心任务，可用于机制假说和治疗靶点优先级排序。基于预计算调控网络的工具能低成本地生成预测，但缺乏严格的验证。
- **核心问题**：
  - 现有验证方式（如 RegNetAgents）通常只检查预测的基因是否是已知癌症基因（成员资格验证，membership validation），并未验证预测的“方向性”主张（该基因上调还是下调）是否与真实疾病一致。
  - 当工具被暴露为 LLM 智能体可调用的 MCP 函数时，智能体向用户报告的内容会继承工具本身的验证缺陷，成员验证无法弥补方向性验证的缺失。
- **整体含义**：本文提出一种**基于真实患者肿瘤数据的方向一致性验证方法**，用拷贝数扩增作为基因敲低的剂量反向代理，直接检验 CASCADE 框架预测的扰动效应方向是否与真实患者的表达差异相符，从而对智能体工具进行更严格的、面向实际主张的验证。同时，文章还评估了 LLM 智能体是否能把自然语言查询正确转换为真实的 MCP 工具调用参数，即“上游接地”可靠性。

## 2. 方法论：核心思想、关键技术细节、算法流程

### 2.1 核心思想
- **方向一致性验证**：假设焦点基因的拷贝数扩增（GISTIC = 2）近似等于该基因活性升高，即敲低的逆方向。若 CASCADE 预测某基因在敲低后表达下调（即正向受焦点基因调控），那么在扩增样本中该基因实际表达应更高，则计为“一致”。
- **患者数据直接验证**：使用 TCGA PanCancer Atlas 中扩增 vs 非扩增患者的 mRNA 表达 z-score 差异，检验预测方向是否正确，而无需实验扰动数据。

### 2.2 CASCADE 架构
- 基于 LangGraph 编排的工作流，通过 MCP 服务器暴露给 LLM 智能体。
- 网络组件：ARACNe 有向调控网络，BFS 传播，敲低初始效应为 -1.0，逐跳衰减因子 0.5；边权重由 ARACNe 互信息幅值与激活/抑制模式（激活保号、抑制翻转）相乘得到。
- 嵌入组件：GREmLN 预训练基因嵌入的余弦相似度加权，与网络信号按 α = 0.7 融合（网络为主，嵌入不改变已有基因的方向）。
- 默认参数：传播深度 2 跳，top_k = 50（验证实验显式指定）。
- 调用入口：`CascadeWorkflow.run()`，`analysis_depth="focused"`，内部路由仅触发 `{perturbation, targets}` 两个分析；只使用 `perturbation_effects` 字段做统计。

### 2.3 统计方法
- **二项检验**：零假设为一致性率 = 50%，单尾检验。
- **置换检验**：从 200 个背景基因池中随机抽取 N 个基因（排除焦点基因和 CASCADE 预测基因），随机分配与真实预测方向比例一致的标签，重复 1000 次，计算经验 p 值。
- **BH-FDR 校正**：对 27 个基因-癌症组合进行多重检验校正。

### 2.4 与基线比较
- 使用 MSigDB 的 MYC TARGETS V1 和 E2F TARGETS 作为精选基因集基线，与 CASCADE 预测的 top-50 基因集通过 Fisher 精确检验比较一致性率。
- 消融实验：将所有预测方向强制为“下调”，比较一致性率下降程度。

### 2.5 智能体工具调用接地评估
- 构造 35 个自然语言查询（7 个类别 × 5 个），涉及基因别名、非正式癌症名、非标准扰动表述、隐式参数、多实体干扰等。
- 用 CASCADE 真实 MCP 工具 schema 测试两个本地模型：`llama3.1:8b`（默认）和 `qwen2.5:72b`。
- 逐字段比较模型输出的工具调用参数与标注真值。
- 对基因别名错误，额外执行 CASCADE 服务端的 `resolve_alias()` 步骤后再评分。
- 设计了针对扰动类型缺省错误的修复：扫描原始请求文本中的方向性线索，但测试发现其触发条件（字段未设置）从未发生——模型总是自信地给出一个值（可能是错的）。

## 6. 主要结论与发现

### 6.1 MYC 预测的强验证
- MYC 敲低预测方向与患者扩增状态一致率：BRCA 90.0%（p < 10⁻⁸）、COAD 72.0%（p = 0.0013）、STAD 85.7%（p < 0.0001），显著高于任意基因的置换基线（48–54%）。
- PAM50 Luminal B 亚型内：92.0% 一致，排除亚型混杂。
- METABRIC 独立队列：87.2%（p < 10⁻⁶），排除共享数据来源的伪重复。
- N 从 25 到 100 变化时，一致率保持平坦（88–92%）。
- 预测靶标富集核糖体生物发生和核仁机制基因（NOP14, RIOK1, WDR43 等），与已知 MYC 生物学一致。

### 6.2 CASCADE 与精选基线无显著差异
- CASCADE 与 MSigDB 精选 MYC 靶标集差异仅 1–4 个百分点，方向不一致（部分类型 CASCADE 高，部分低），Fisher 精确检验 p = 0.34–0.86，均不显著；BH-FDR 后 q 值 0.767–0.863。
- E2F3 比较 p = 0.384，不显著。
- 结论：CASCADE 并未证明其整体准确性超越现有公共知识，但其方向判定本身有实质贡献——强一致性的“下调”猜测会降低 14–29 个百分点。

### 6.3 验证是基因特异性的
- **增殖机制调节因子**：E2F3、CCND1、CCND3、AURKA、CCNE1、MDM2、FOXM1、TOP2A、RPS6KB1 在至少一个癌症类型中验证（68–100%）；其中 7 个在 BRCA 干净复制（89.6–100%），MDM2 和 CCND3 较弱复制。
- **谱系身份转录因子**：SOX9（38.8%）、FOXA1（34.0%）、GATA3（0%）、ESR1（4.0%）全部失败，呈反向一致。
- **ERBB2**：BRCA 18.0%、COAD 14.3%（反向一致）但 STAD 93.6%（正向一致），癌症类型依赖。
- **CCND2**：唯一在所有测试癌症类型（BRCA、COAD）中失败的增殖机制基因，与其旁系同源基因 CCND1/CCND3 形成鲜明对比。
- 跨癌种扩展：AURKA（COAD 92%）、CCNE1（STAD 98%）、TOP2A（STAD 100%）、CCND3（STAD 79.6%）可复制；CCND1（STAD 57.1%）和 MDM2（STAD 42%）不可复制。
- 作者提出一个对冲的事后假设：增殖机制基因的活性输出可能随剂量线性放大，而谱系身份 TF 通过染色质机制可能非线性响应。但 CCND2 反例明确显示该规则不完美。

### 6.4 智能体工具调用接地结果
- `llama3.1:8b` 原始输出精确匹配率 71.4%（25/35）→ 经服务端别名解析提高至 77.1%（27/35）。
- `qwen2.5:72b` 原始匹配率 85.7%（30/35）→ 服务端解析后 94.3%（33/35）。
- 网络参数错误几乎只出现在小模型（8 次 vs 0 次）；基因别名错误可被服务端解析完全解决（所有测试别名均在固定表中）。
- 第三类失败：模糊查询（“What does MYC do?”）中两个模型均自信地默认选“overexpression”而非文档缺省的“knockdown”。定向修复（依赖缺省字段触发）无效，因为模型从不留空字段——是“自信的错误猜测”而非“省略缺省”。
- 结论：LLM 接地在较大模型下基本可靠，但模糊扰动类型查询仍存在未解决的失败模式。

## 7. 优点

- **验证范式创新**：提出用拷贝数扩增作为敲低方向代理的患者数据方向一致性验证，比成员资格验证更直接检验工具的真实主张，可推广到其他调控网络扰动预测工具。
- **实验严谨性高**：包含独立队列复制、亚型控制、置换检验、多重校正、消融实验、基线比较，以及对负面结果的公开报告。
- **透明性**：公开所有实验脚本、基因选择的来源和筛选标准，披露否定结果、失败基因和未解决的限制。
- **生物学合理性**：MYC 预测靶标富集核糖体生物发生基因，符合已知的 MYC 程序，增加结果的可信度。
- **实用性**：CASCADE 基于预计算网络和本地模型，不依赖专有 API 或大规模训练，使验证方法低成本可复现。
- **对智能体工具验证的贡献**：明确区分“预测是否准确”和“智能体是否正确调用工具”两个层次，并分别评估。

## 8. 不足与局限

- **验证覆盖有限**：泛化实验仅 15 个基因、27 个基因-癌症组合；由于符合“强扩增候选基因”很罕见（如 CTNNB1、KLF5、MYB 均因扩增样本不足无法测试），面板规模受限制。
- **代理的有效性**：拷贝数扩增只是基因剂量的近似，并非直接实验操作；剂量-活性关系未必线性，且肿瘤纯度、基质污染、扩增子共选等因素未控制（PAM50 控制和 METABRIC 复制部分缓解）。
- **基线比较不充分**：仅用两个 MSigDB 基因集，未测试更广泛的精选数据库（如 OncoKB、Hallmark 全集），未与 CellOracle 等类似工具头对头比较。这是未来工作。
- **统计显著性与保守性**：置换检验仅 1000 次，p = 0.0000 精度有限；BH-FDR 校正后 CCND1/STAD 和 CCND2/COAD 等中间结果不明显。
- **事后假设风险**：谱系身份 vs 增殖机制的解释是事后形成的，作者承认未预注册，且 CCND2 反例削弱了该规则的普适性。作者通过披露基因选择过程和包括 ESR1 反证选择来降低偏差，但不能完全消除。
- **智能体接地基准局限**：35 个查询、两个本地模型，未测试闭源前沿模型；只评估单步工具调用，未评估多轮对话或从失败调用中的恢复；基因别名表仅覆盖固定小集合，不能外推到更多别名。
- **扰动类型修复失败**：模型总是提供枚举值，导致依赖缺省字段的修复失效；需要更复杂的基于文本支持的校验，留作未来工作。
- **数据版本一致性**：CASCADE 网络基于 2015 年 TCGA 原始数据，验证数据基于 2018 年 GDC 统一处理数据（GRCh38），虽很可能患者重叠但管道不同，潜在混杂（通过 METABRIC 复制部分缓解）。
