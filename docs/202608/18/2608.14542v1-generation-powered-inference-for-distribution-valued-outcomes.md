## 摘要
现代生成模型越来越多地产生分布值输出，例如单细胞基因组学中对基因扰动后细胞反应的预测。尽管这些模型提供了有价值的辅助信息，但它们本质上并不完美，因此需要统计方法能够利用其预测而不依赖其正确性。我们提出生成驱动推断（GPI），这是一个利用辅助生成模型改进分布值参数推断的通用框架。我们聚焦于Wasserstein重心及相关分布泛函，引入一种函数值桥表示，将非线性Wasserstein空间中的推断转化为Hilbert空间中均值函数的估计，从而实现了类似于预测驱动推断的增强估计框架。我们开发了一类具有最优信息借用的GPI估计器，建立了相合性、渐近正态性和联合置信带，并推导了线性泛函和Wasserstein距离的有效推断。模拟研究表明，与仅使用标记数据的方法相比，该方法提高了效率，并且在生成模型误设定下具有稳健性能。我们利用K562细胞的Perturb-seq研究说明了所提出的框架，其中使用State基础模型生成的合成扰动反应来改进与40S核糖体模块扰动相关的通路级共识基因表达分布的推断。

## Abstract
Modern generative models increasingly produce distribution-valued outputs, such as predicted cellular responses to genetic perturbations in single-cell genomics. While these models provide valuable auxiliary information, they are inherently imperfect, creating a need for statistical methods that leverage their predictions without relying on their correctness. We propose generation-powered inference (GPI), a general framework for improving inference on distribution-valued parameters using auxiliary generative models. Focusing on Wasserstein barycenters and related distributional functionals, we introduce a function-valued bridge representation that transforms inference in the nonlinear Wasserstein space into estimation of a mean function in a Hilbert space, enabling an augmented estimation framework analogous to prediction-powered inference. We develop a family of GPI estimators with optimal information borrowing, establish consistency, asymptotic normality, and simultaneous confidence bands, and derive valid inference for linear functionals and Wasserstein distances. Simulation studies demonstrate efficiency gains over labeled-data-only methods and robust performance under generative model misspecification. We illustrate the proposed framework using a Perturb-seq study of K562 cells, where synthetic perturbation responses generated by the State foundation model are used to improve inference for pathway-level consensus gene expression distributions associated with perturbations of the 40S ribosome module.

## 2. 论文提出的方法论

### 2.1 核心思想：函数值桥表示

在推断 Wasserstein 重心 `μ*` 时，论文不直接在非线性空间 `W2(I)` 中做加性校正，而是引入一个**已知连续参考分布函数 λ**，定义函数值目标参数：

```
θλ(·) := μ*⁻¹ ∘ λ(·)
```

即重心分布的分位数函数与参考分布的复合。当 λ 取均匀分布时，θλ 就是重心分布的分位数函数；当 λ 取某个对照分布 μ₀ 时，θλ 是从 μ₀ 到 μ* 的最优传输映射。该表示的核心性质在于（Lemma 1）：

```
θλ(·) = E[Y⁻¹ ∘ λ(·)]
```

即重心分位数等于**个体分布分位数变换的均值**。这一线性表示将非线性 Wasserstein 空间中的推断问题转化为 Hilbert 空间 L²(T; λ) 中一个普通均值函数的估计，从而使得 PPI 式的增广校正自然可行。

### 2.2 GPI 估计器的构造

- 定义变换后的观测 `Zλ = Y⁻¹∘λ` 和变换后的生成代理 `gλ(X) = G(X)⁻¹∘λ`。
- 目标分解式：`θλ = E[Γgλ(X)] + E[Zλ − Γgλ(X)]`，其中 `Γ: L² → L²` 是一个有界线性算子，控制从生成模型中借用信息的方式；`E[Zλ − Γgλ(X)]` 被称为分布级“校正项”（rectifier）。
- 基本 GPI 估计器（生成模型已知时）：

```
θ̂λ,Γ = (1/N) Σ_{j∈U} Γ·ĝλ(Xj) + (1/n) Σ_{i∈O} {Ŷᵢ⁻¹∘λ − Γ·ĝλ(Xi)}
```

，其中 O 为有标注样本（n 个），U 为无标注样本（N 个）。

- **跨拟合（cross-fitted）版本**：当生成模型需要训练时（通用情形），将已标注样本分成 K 折，每折用其余 K−1 折训练生成模型，然后在对应折上评估；最终估计器是 K 个折特定估计器的加权平均。这种设计避免了对同一份数据既训练又评估造成的过拟合偏差。

### 2.3 最优信息借用算子 Γ

- 论文建立了固定 Γ 的渐近分布（Theorem 1，高斯过程极限），并推导了**最优算子**（Theorem 2）：

```
(1 + ρ)·Γ*·C_gg = C_Zg
```

其中 `C_gg` 为生成代理的协方差算子，`C_Zg` 为真实与生成代理的互协方差算子，`ρ = lim n/N`。Γ* 可理解为对变换后代理的**收缩型函数回归算子**，在所有有界线性算子中实现协方差算子意义下的最优性（即方差协方差核的最优偏序）。在生成代理恰为条件期望的特例下，Γ* 退化为 `(1+ρ)⁻¹I` 的简单形式。

- 借助泛函主成分分析（FPCA），论文给出了 Γ* 的**可计算估计**（带截断和岭正则化），并证明了可行估计与理想化估计的渐近等价性（Proposition 2）。

### 2.4 推断程序

- **联合置信带（SCB）**：利用协方差核估计引导高斯过程分位数，构造重心分位数函数的联合置信带。
- **线性泛函推断**：对任意权重 ℓ ∈ L²，`θ_{λℓ} = ⟨ℓ, θλ⟩` 的推断（置信区间），覆盖重心均值、截尾均值、尾均值、位移泛函等。
- **Wasserstein 距离推断与假设检验**：对 `W₂(μ*, μ₀)` 进行一致性估计、正态极限推断，并构造对照分布与重心相等的假设检验（基于高斯过程范数的临界值）。最优 Γ* 保证这些推断的渐近方差不超过仅标注数据方法。

## 6. 论文的主要结论与发现

1. **GPI 提供了一类有效的增强推断框架**：通过桥表示，在 Wasserstein 空间中原本困难的重心推断被转化为 Hilbert 空间中的均值函数估计，使传统 PPI 的校正逻辑可以沿用。
2. **最优算子 Γ\*** 在协方差算子偏序下对所有有界线性算子最优，且对任意线性泛函同时最优；效率增益由生成代理的可线性解释变异程度决定。非信息性代理不会造成效率损失（Γ\* = 0 是有效解），而完全线性可恢复时的最大增益为 `ρ/(1+ρ)` 的方差缩减。
3. **校准至关重要**：（a）Naive GPI 在生成模型负对齐或混合对齐时，RMISE 增大、置信带变长、检验功效下降；（b）Scalar GPI 在正对齐下有效，但混合对齐时可能不如 General GPI；（c）General GPI 在所有场景中最稳健，保持名义覆盖/水平的有效性，且统计效率不低于仅标注方法。
4. **直接混合生成数据不可取**：真实数据中 Pooled 基准（直接替代未观测扰动）虽然 CI 更窄，但估计偏差大、与 Full observed 的一致性差；GPI 通过对偏差的校准，在保留生成模型有用分布信息的同时消除了系统误差。
5. **生物发现**：40S 核糖体扰动的共表达响应在分位数层面呈高度异质性——细胞周期/染色体分离相关基因表现为中高尾抑制；翻译/蛋白质稳态相关基因表现为广泛负向位移；DNA 复制起始相关基因表现为低中尾抑制而高尾相对保留——说明仅看均值效应会丢失大量维度信息。

- **最优算子 Γ\* 的估计依赖 FPCA 截断与岭正则化**：截断参数和正则化参数的选择虽然提供了理论指导，但在小样本（如真实数据中 n=21）下如何自适应选择仍无统一准则，实际表现可能对调参敏感。
- **生成模型的不确定性未充分建模**：论文将生成模型当作“已知的随机代理”处理，用交叉拟合避免过拟合偏差，但对生成模型自身的随机性（如训练随机性、模型初始化差异）仅通过蒙特卡洛近似间接考虑，未将其作为额外方差来源纳入推断程序。
- **同质性假设**：所有个体共享同一个噪声分布（个体分布观测误差）的假设在单细胞数据中未必成立——不同扰动靶点的细胞数、测序深度差异很大，异方差问题值得单独建模。
- **计算与可扩展性**：全函数空间协方差算子估计与 bootstrap 联合置信带的计算复杂度随观测点数 m 和未标注量 N 增长，论文未报告大规模（十万级细胞、百万级基因）场景下的运行时间与内存表现。
- **真实数据的验证层次有限**：仅聚焦一个 40Sr 模块和一个生成模型（State），结论的外部推广性需在更多扰动模块、更多基础模型（如 scGPT、Geneformer）上进一步检验。

## 9. 与现有工作的比较

- **与传统 PPI（Angelopoulos et al., 2023）**：PPI 处理有限维参数（均值、回归系数），GPI 通过桥表示将分布值目标（Wasserstein 重心）转化为函数值均值，再套用 PPI 逻辑；当目标退化为标量均值且参考分布选为退化分布时，GPI 可视为 PPI 在无穷维空间的推广与细化。
- **与基于随机优化的直接推断（如 Barycenter 估计、分布鲁棒优化）**：这些方法仅用标注数据，不以生成模型为辅助；GPI 提供了系统的辅助信息接入方式，且理论保证不损失效率。
- **与“预测 + 直接替代”（Pooled/Imputation-based）**：该类方法将生成分布当作真实观测使用，方差小但偏差不可控；GPI 的校正项消除系统性偏差，等价于在“效率和偏差”之间做有原则的最优权衡。
- **与贝叶斯模型平均 / 先验加权**：贝叶斯方法需要为生成模型设定先验可信度，GPI 无需先验，完全由数据驱动的协方差估计决定借用程度，更适应生成模型不可靠的情形。
- **与 conformal prediction 类方法**：conformal 提供有限样本分布自由的预测集，但不适合做效率增强的参数推断；GPI 提供渐近最优的效率增益，两者目标互补。

## 11. 总体评价与学术意义

Generation-Powered Inference 在方法论上填补了一个重要空白：此前利用预测模型辅助推断的框架局限于欧氏参数，而现代生成模型的核心优势恰恰在于输出整个分布。论文通过一个简洁的“桥表示”完成了非线性空间到线性空间的转化，理论上给出了最优借用算子及其可计算实现，并在单细胞扰动场景中展示了显著的效率提升。它不仅为分布值推断提供了一个新范式，也为生成模型与统计推断的交叉领域提供了可扩展的技术工具箱。

若严格审视，其核心局限在于对分布质量/矩条件的正则性要求、对生成模型不确定性的简化处理，以及真实数据验证的广度。但这些不足都属于“后续工作可自然扩展”的类型，而非框架性缺陷。综合而言，这是一篇理论深度与实证价值兼备的高质量方法论论文，值得关注者精读；其思想也容易移植到其他输出为分布的生成模型（如扩散模型、气候模拟器、数字孪生）辅助推断的问题中。
