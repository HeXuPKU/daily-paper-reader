## 摘要
CASCADE 是一个智能体框架，它通过 MCP 暴露的预计算 ARACNe 调控网络来预测基因扰动的下游转录效应。先前的工作通过检查预测的基因是否为已知癌症基因（成员资格）来验证此类工具；我们则检验预测的变化方向是否与现实一致，使用焦点基因拷贝数扩增作为敲低的剂量代理，并基于真实的 TCGA 患者肿瘤数据进行反向验证。对于 MYC，CASCADE 预测的敲低靶标在三种癌症类型（BRCA：90.0%，COAD：72.0%，STAD：85.7%；所有 p<0.0013）中与真实的扩增与非扩增肿瘤表达高度一致，远高于排列基线，并经受住了 PAM50 亚型对照的检验，且在独立队列（METABRIC，87.2%）中重复。与通过 Fisher 精确检验的精选 MSigDB 基因集基线相比，CASCADE 的准确性并未显示出超越现有关于 MYC 或 E2F 驱动生物学的公共知识，但其基因特异性的方向判定明显优于朴素的统一猜测。扩展到另外十五个基因，验证证明是基因特异性的而非普遍性的：增殖机制调控因子大多可重复，而谱系身份转录因子和一个 cyclin-D 旁系同源物（CCND2）则持续失败，我们将这一模式作为有对冲的事后假设进行讨论。我们另外评估了基于 LLM 的智能体是否能正确地将自然语言请求落地到 CASCADE 的真实 MCP 工具调用中。在 35 个查询中，一个有文档记录的本地模型达到了 71.4% 的精确匹配（较大模型为 85.7%）；模式和图谱别名失败可通过规模或服务器端修正解决，但两个模型在模糊查询上都会自信地默认使用错误的扰动类型，这是一个针对性修复无法解决的失败，因为其触发条件从未出现。

## Abstract
CASCADE is an agentic framework that predicts downstream transcriptional effects of gene perturbation from precomputed   ARACNe regulatory networks, exposed via MCP. Prior work validates such tools by checking whether predicted genes are   known cancer genes (membership); we instead test whether the predicted direction of change matches reality, using   focal-gene copy-number amplification as a dosage-based proxy for the inverse of knockdown against real TCGA patient   tumor data.   For MYC, CASCADE's predicted knockdown targets show strong concordance with real amplified-vs-non-amplified tumor   expression across three cancer types (BRCA: 90.0%, COAD: 72.0%, STAD: 85.7%; all p<0.0013), well above permutation   baselines, surviving a PAM50 subtype control and replicating in an independent cohort (METABRIC, 87.2%). Compared   against curated MSigDB gene-set baselines via Fisher's exact test, CASCADE's accuracy is not shown to exceed existing   public knowledge of MYC- or E2F-driven biology, though its gene-specific direction-calling clearly outperforms a naive   uniform guess.   Extending to fifteen additional genes, validation proves gene-specific rather than universal: proliferation-machinery   regulators mostly replicate, while lineage-identity transcription factors and one cyclin-D paralog (CCND2)   consistently fail, a pattern we discuss as a hedged, post-hoc hypothesis.   We separately benchmark whether an LLM-based agent correctly grounds natural-language requests into CASCADE's real MCP   tool calls. Across 35 queries, a documented local model reaches 71.4% exact match (85.7% for a larger model); schema   and gene-alias failures are resolved by scale or server-side correction, but both models confidently default to the   wrong perturbation type on ambiguous queries, a failure a targeted fix could not resolve because its trigger condition   never occurs.

- **核心问题**：现有基于调控网络的基因扰动预测工具（如 RegNetAgents）的验证方法仅关注“预测的基因是否为已知癌症基因”（成员资格验证，membership validation），但**完全忽略了预测的核心声明——扰动后的下游基因表达方向（上调/下调）是否正确**。这种验证缺口在工具被暴露为 LLM 可调用的函数（如通过 MCP）时会被放大，因为智能体会将错误的方向性声明直接传递到用户报告中。
- **研究动机**：
  - 在癌症系统生物学中，预测基因扰动的下游后果是一项核心任务，影响机制假设与治疗靶点优先级排序。
  - 基于预计算调控网络的工具无需新实验数据或模型训练即可廉价产生预测，但“廉价”的代价是验证困难，缺乏黄金标准的实验扰动数据。
  - 作者引入了一种替代验证路径：以真实患者肿瘤基因型-表达数据为基准，假设拷贝数扩增是敲低（knockdown）的“逆方向剂量代理”，直接用患者数据检验“该基因上调/下调”这一具体方向性声明是否成立。
- **整体含义**：本文提出了一种**方向级（directional）患者数据验证范式**，将基因扰动预测的验证目标从“预测的基因是否已知癌症基因”升级为“预测的方向变化是否确实发生在真实疾病中”。全篇围绕 CASCADE 框架展开，同时将验证推广到 15 个基因的泛化测试，并额外审视了上游步骤——LLM 代理能否正确地将自然语言请求映射到真实的 MCP 工具调用参数。

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 2.1 核心思想
- **网络传播进行扰动预测**：CASCADE 基于预计算的 TCGA 肿瘤特异 ARACNe 调控网络，对有向的“调控者→目标”边进行有符号信号传播，模拟给定基因敲低/过表达后的下游转录组变化。
- **患者数据反向验证方向**：将焦点基因拷贝数扩增（GISTIC = 2）视为“敲低的逆”（即基因剂量增加），比较扩增与非扩增（GISTIC = 0）患者肿瘤中，CASCADE 预测的每个下游靶基因的实际表达均值差异。预测“敲低后下调”的基因（即正向调节靶标），若其在扩增样本中实际表达更高，则判为一致；预测“敲低后上调”的基因（负向调节靶标），若其在扩增样本中实际表达更低，则判为一致。

### 2.2 关键技术细节

- **传播算法**：确定性广度优先算法（BFS）。敲低时焦点基因初始效应为 −1.0；每一跳，传播到目标基因的效应 = 父基因当前效应 × 边权重 × 衰减因子 0.5，跨路径的效应累加。边权重由 ARACNe 互信息幅度与边的作用模式注释（激活/抑制）共同决定——抑制边翻转符号，这是产生方向预测的主要机制。默认传播深度为 2 跳。
- **嵌入增强**：CASCADE 默认将网络传播与 GREmLN 预训练基因嵌入的余弦相似度混合，权重参数 α = 0.7（网络信号占主导）。嵌入组件可以补充网络传播之外的候选基因，但不会翻转已由网络可达基因的方向。
- **基因角色分类## 路由**：CASCADE 依据网络的出/入度将焦点基因分类为 master regulator、transcription factor、minor regulator、effector 或 isolated（阈值规则，表 1），并据此决定工作流路由。所有实验均使用 `analysis_depth = "focused"`，每项实验都调用真实的 `CascadeWorkflow.run()` 公共入口。
- **统计框架**：
  - 二项检验（零假设：一致性率 = 0.5，单尾）；
  - 独立的置换检验（1,000 次）：从 200 个随机网络基因背景池（排除焦点基因和真实预测集），随机分配与真实预测集相同上下比例的预测方向标签，计算经验 p 值；
  - Benjamini-Hochberg FDR 校正（分别适用于 27 个组合验证的泛化家族和 4 个基线比较家族）。

### 2.3 智能体工具调用验证

- 构建 35 条手工标注的自然语言查询，覆盖 7 个类别（每类 5 条）：基线 TCGA 癌症类型 / 基线免疫细胞类型 / 基因别名 / 非正式癌症类型名 / 非规范扰动措辞 / 隐式默认参数 / 多实体干扰项。
- 用两种本地 LLM（llama3.1:8b 为 CASCADE 文档默认、qwen2.5:72b 为更大对比模型）通过 Ollama 生成对真实 MCP 工具 schema 的调用，逐字段比对生成参数与真实参数的精确匹配。
- 基因别名额外区分“原始模型输出”评分与“经 CASCADE 服务器端 `resolve_alias()` 步骤后”评分，模拟真实部署时服务器实际行为。

## 3. 实验设计

### 3.1 使用的数据集与场景

- **TCGA PanCancer Atlas 2018**（BRCA 乳腺癌、COAD 结肠癌、STAD 胃癌）：表达与拷贝数数据（GISTIC2.0），通过 cBioPortal REST API 获取（GDC 统一处理、GRCh38 参考基因组，与 CASCADE 网络构建所用的 2015 年原始 TCGA 下载数据在管道上无重叠，但患者可能有重叠）。
- **METABRIC 独立队列**（2,509 例乳腺癌，微阵列技术，英国/加拿大机构）——与 TCGA 完全不同来源，用于排除共享数据假象。
- **PAM50 分子亚型注释**（cBioPortal 临床数据）——用于亚型对照测试。
- **MSigDB 精选基因集**：MYC TARGETS V1（三种癌症类型）、E2F TARGETS（仅在 BRCA），作为与 CASCADE 对比的身份匹配基线。
- **LINCS L1000 shRNA 数据**（GSE106127，MCF7）——尝试直接实验验证谱系身份假说，但因靶标覆盖率不足而失败（每个基因仅 2–5 个预测靶标在 L1000 的 978 基因面板上，且 SOX9 不在 shRNA 库中）。

### 3.2 Benchmark 与对比方法

- **主实验**：MYC 敲低预测靶标（top 50）在三种癌症类型中的方向一致率；
- **面板大小敏感性**：BRCA/MYC 在 N=25、50、100 三种面板大小下的一致性（88.0% / 90.0% / 92.0%）；
- **亚型对照**：PAM50 的 Luminal B 亚型内重复验证（92.0%）；
- **独立队列复制**：METABRIC（87.2%）；
- **15 基因泛化面板（27 个基因-癌症组合）**：每种候选基因要求网络出度 ≥25 且有 ≥15–20 个扩增患者样本；基因进入面板的方式被如实披露（盲筛 / 系统性筛选 / 为证伪假设而选择的 ESR1）；
- **基线比较**：CASCADE 与精选 MYC/E2F 基因集通过 Fisher 精确检验对比（四个比较均不显著，p = 0.34–0.86）；

- **智能体工具调用基准**：35 条查询 × 2 个 LLM，精确参数匹配率；
- **置换检验**：1,000 次置换基线对照，每个基因-癌症组合均执行。

## 6. 论文的主要结论与发现

1. **MYC 的验证结果强且稳健**：预测的敲低靶标方向与真实患者表达在 BRCA、COAD、STAD 中一致率分别为 90.0%、72.0%、85.7%（所有 p < 0.0013，置换经验 p = 0.0000），且不受面板大小影响、通过 PAM50 亚型对照（Luminal B 92.0%）、在 METABRIC 独立队列中复制（87.2%，p < 10⁻⁶）。生物学上，BRCA 一致基因集富含核糖体生物发生/核仁机器组分（NOP14、RIOK1、WDR43、KAT2A 等），与 MYC 在癌症中最公认的转录程序吻合。
2. **CASCADE 的方向判定能力明确重要**：强制统一猜“下调”使一致率下降 14–29 个百分点；上调预测子集本身有 76.5–92.3% 的正确率，排除了“上调预测只是陪衬噪音”的可能。
3. **但 CASCADE 并未被证明超越公共知识**：与精选 MSigDB 基因集基线比较，一致性差距仅为 1–4 个百分点（方向不一致），Fisher 检验均不显著（p = 0.34–0.86），BH-FDR 后仍不显著。
4. **泛化是基因特异的，而非普遍**：增殖机器相关基因（E2F3、CCND1、CCND3、AURKA、CCNE1、MDM2、FOXM1、TOP2A、RPS6KB1）大多在至少一种癌症类型中验证成功（68–100%）；谱系身份转录因子（SOX9 38.8%、FOXA1 34.0%、GATA3 0%、ESR1 4.0%）和 ERBB2（BRCA 18.0%、COAD 14.3%）基本失败；CCND2 —— 与验证成功的 CCND1/CCND3 共享相同分子功能的 cyclin-D 旁系同源物 —— 在 BRCA 和 COAD 中**均**失败，是唯一在每种被测试的癌症类型中都失败的增殖机器基因。
5. **癌症类型背景同样关键**：CCND1 和 MDM2 在 BRCA 中验证但在 STAD 中失败；ERBB2 显示完全相反的模式（BRCA/COAD 反一致，STAD 93.6% 一致）。基因类别无法单独预测验证结果。
6. **LLM 工具调用基准**：llama3.1:8b 原始精确匹配 71.4%，qwen2.5:72b 为 85.7%（服务器端别名解析后分别升至 77.1% 和 94.3%）。三个失败模式：网络参数违规（主要存在于较小模型，大模型已消除）、基因别名（服务器端解析后全部解决）、扰动类型模糊性（**两种模型均自信地默认选择错误的扰动类型**）。针对后者设计的修复方案失效——因为模型从不留下未设置的字段，修复的触发条件从未发生，实际问题是“自信猜错”而非“未设置后的静默默认”。

## 7. 优点（亮点）

- **验证范式的创新**：首次引入“方向级”患者数据验证方法——拷贝数扩增作为敲低逆代理、检验特定方向声明的正确性，而非传统成员资格验证；方法论原则上可泛化到任何基于调控网络的扰动预测工具。
- **统计严谨性**：多层验证体系（二项检验 + 独立置换检验 + FDR 校正 + 独立队列 + 亚型对照 + 面板大小敏感性 + 基线比较 + 消融验证），每个步骤都设计了合适的对照组，直接排除了常见伪影来源（基因集结构、亚型组成、数据重叠、方向偏斜）。
- **诚实与透明**：编码与数据完全开源（MIT 许可证、Zenodo 存档），每个基因进入面板的“选择来源”被如实披露（盲筛 / 假设驱动 / 证伪测试），负面及不一致结果（CCND2、ERBB2、LINCS 验证失败、修复方案失效）被完整报告，未做选择性筛选。
- **验证工具调用层（上游）**：明确区分“预测质量本身”与“LLM 代理能否正确调用工具”这两个不同问题，为 MCP 暴露的 AI 工具提供双重验证的范例。
- **计算轻量**：预计算网络 + 确定性传播 + 只读 API 调用，无需模型训练即可产出可复现结果，具有很高的可操作性。
