## 摘要
基于结构化电子健康记录（EHR）的预测模型仍然是医疗保健机器学习领域的核心，但很少有模型同时强调定量实验室信息和相对于输入医疗事件的可解释性。我们提出了BERT-LER，一种针对编码EHR时间线的BERT风格模型，该模型在包含7500万患者的去标识化EHR数据集上进行预训练和微调，将实验室检测结果编码为离散标记，同时通过基于百分位的分箱保留分级信息，并与集成梯度（Integrated Gradients）相结合，基于输入EHR序列进行标记级归因。我们在公开的EHRShot基准测试套件以及基于真实世界数据的哮喘严重程度进展研究上对我们的方法进行了基准测试。这通过将实验室值表示和可解释性统一在一个框架中，弥补了EHR基础模型建模中的方法论空白，同时评估了预测性能和解释是否能够泛化到标准临床预测任务之外。在EHRShot和哮喘任务中，BERT-LER实现了与公开基准模型相当的预测性能，并且在实验室相关任务上往往超过这些模型，同时提供了与临床已知风险因素一致的归因。我们的架构和可解释性方法可应用于许多治疗领域和预测任务，使用在结构化EHR上训练的语言模型。

## Abstract
Predictive models over structured electronic health records (EHRs) remain central to machine learning for healthcare, but few have jointly emphasized quantitative laboratory information and interpretability with respect to input medical events. We present BERT-LER, a BERT-style model for coded EHR timelines pretrained and fine-tuned from a de-identified EHR dataset of 75 million patients, that encodes laboratory test results as discrete tokens while retaining graded information through percentile-based binning, paired with Integrated Gradients for token-level attributions grounded in the input EHR sequence. We benchmark our approach on the public EHRShot benchmark suite and on an asthma severity progression study based on real-world data. This addresses a methodological gap in EHR foundation-style modeling by unifying laboratory value representation and explainability in a single framework, while assessing whether both predictive performance and explanations generalize beyond standard clinical prediction tasks. Across EHRShot and asthma tasks, BERT-LER achieves predictive performance that is competitive with, and on laboratory-related tasks often exceeds, publicly available benchmark models, and provides attributions that align with clinically known risk factors. Our architecture and explainability approach can be applied to many therapeutic areas and prediction tasks using language models trained on structured EHRs.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：基于结构化电子健康记录（EHR）的临床预测模型是医疗机器学习的关键方向，但现有方法存在两个明显缺口：
  1. 结构化实验室检测结果本质上是连续值、且临床语义细腻，难以在不丢失定量信息的前提下被纳入离散 token 化的 Transformer 架构；
  2. 许多高性能模型缺乏对“单个医疗事件如何贡献于预测结果”的可解释性，而临床部署恰恰需要这种可解释性。
- **背景**：已有研究（如 TransformEHR、Med-BERT、CLMBR、Labrador 等）探索了 Transformer 在 EHR 上的应用，也有工作尝试通过注意力权重或事后解释方法提供可解释性，但很少有方法能够**同时**实现：
  - 保留实验室值的渐变定量信息；
  - 提供与具体输入事件直接关联的 token 级解释。
- **整体含义**：论文提出 BERT-LER，将实验室值表示与可解释性统一在同一框架中，并在大规模真实世界数据上预训练，在公共基准和临床协议两个层面验证其性能与解释质量，试图弥合 EHR 基础模型在实验室值建模与临床可解释性之间的方法论空白。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：
  1. 使用 BERT 风格的编码器-only Transformer 对结构化 EHR 时间线建模；
  2. 实验室值通过**基于百分位的分箱**离散化为 10 个等级，从而兼容 token 化架构；
  3. 利用 **Integrated Gradients (IG)** 生成 token 级归因，将预测直接映射回输入医疗事件。
- **模型架构（BERT-LER）**：
  - 输入为三类序列：
    - 医疗事件 token 序列（含人口统计学信息如年龄、性别、种族等）；
    - 位置 ID 序列（表示距首个医疗事件的天数）；
    - 百分位 ID 序列（表示实验室值所在百分位区间，非实验室 token 为 0）。
  - 每个 token 的嵌入 = token embedding + lab 值 percentile embedding；
  - 位置编码采用相对 key-query 嵌入（Shaw et al., 2018）。
- **实验室值表示**：
  - 结果被划分为 10 个百分位 bin（0–10%, 10–20%, …, 90–100%）；
  - 开放尾端 bin 无需单独处理离群值；
  - 分箱阈值基于全参考人群统计，独立于任务标签和训练/验证/测试划分；
  - 因子化表示（lab code embedding + 共享 percentile embedding）比“每个 lab×percentile 组合一个 token”的表（N×M）节省大量参数。
- **预训练**：
  - 采用掩码语言建模（MLM），mask 比例为 15%；
  - 实验室 code token 与其 percentile ID 不联合掩码；
  - 预训练数据来自 TriNetX Dataworks（约 7500 万患者的去标识化 EHR），仅使用 2012 年后的数据、且患者至少有间隔 365 天的两个事件。
- **可解释性（Integrated Gradients）**：
  - 公式为：
    \[
    IG_i(x) = (x_i - x'_i) \int_{\alpha=0}^{1} \frac{\partial F(x' + \alpha(x - x'))}{\partial x_i} d\alpha
    \]
  - 实践中用 Riemann 和近似；
  - baseline 选择：
    - 一般 token：全零嵌入；
    - 人口统计学 token：该类别内 token 嵌入的平均值，避免固定位置导致的偏差；
    - 实验室 token：采用中位数百分位区间作为基线。
  - 选择 IG 而非 SHAP/输入删除法的主要原因是**可扩展性**：IG 的计算成本与积分步数相关，而非与输入序列长度相关，适合多年 EHR 长序列。
- **归因聚合**：
  - 对测试集所有患者的 token 级归因求平均；
  - 对低频 token 使用频率惩罚：`adj.score = avg.score × max(0, 1 - k/n)`；
  - 对实验室 token，用百分位 bin（10 组）与归因分数做线性回归，按回归系数绝对值排序。

- **对比方法**：

## 6. 论文的主要结论与发现

- **预测性能**：BERT-LER 在 EHRShot 14 项任务上总体达到与 CLMBR 相当的水平，**在全部实验室预测任务上显著优于所有对比方法**；在红斑狼疮诊断上也明显更好。
- **实验室值幅度贡献**：与移除 percentile 嵌入的消融变体相比，完整 BERT-LER 在哮喘任务上表现更好，说明实验室值的**大小/等级**提供了超越“是否做了该检查”的额外预测信号。
- **可解释性发现**：
  - 贫血任务：模型捕捉到儿童和老年人风险更高、女性风险更高、高红细胞/血氧类指标与正常结果正相关、肠道疾病与贫血相关、羟基脲和部分化疗药物与贫血相关；
  - 哮喘任务：SABA 频繁使用、LABA/ICS 联合用药、孟鲁司特、COPD、肥胖、黑人种族、体重偏高等均与失控风险上升相关，符合临床文献；
  - 实验室指标：BMI 高、有核红细胞比例高、碱剩余升高与失控正相关；肾功能良好、血细胞比容/红细胞计数/氧饱和度/维生素 D/铁/HDL 相关指标与失控负相关；
  - 作者强调实验室归因需要警惕**confounding by indication / informed-presence bias**，即检查的“被开立”本身可能编码了照护场景和病情严重程度，因此应视为预测性关联而非因果效应。
- **总体判断**：BERT-LER 可以作为一个通用框架，将实验室感知的 EHR 建模与 token 级解释结合，适用于多种治疗领域和临床任务。

## 7. 优点

- **大规模预训练**：使用 7500 万患者的去标识化 EHR 数据，远超多数已有模型（如 TransformEHR 648 万、零样本 GPT 240 万、Labrador 仅限 MIMIC 小规模）。
- **实验室值表示的可扩展性**：因子化 lab code + 共享 percentile embedding 避免了“组合爆炸”，参数规模显著小于 per-combination 词表；支持更细粒度的分箱扩展。
- **可解释性的可扩展性**：选择 Integrated Gradients 而非 SHAP/删除法，计算成本与序列长度解耦，适合长 EHR 序列。
- **双重评估设计**：既在公共基准 EHRShot 上做标准对比，又按预先指定的哮喘临床协议做现实场景验证，增强了结论的泛化可信度。
- **消融设计清晰**：通过移除 lab value embedding 的变体，分离了“实验室事件发生”与“实验室值幅度”的贡献，是一个干净且有信息量的对照。
- **解释结果与文献高度一致**：无论是贫血还是哮喘，归因都能映射到已知风险因素，且与 RETAIN、XGBoost 的特征排名有较好一致性。
- **开源**：发布了训练包和可解释性工具包，便于复现和推广。

## 8. 不足与局限

- **混杂与偏差风险**：
  - 实验室检测的“开立”由临床关注度和照护环境驱动，实验室出现与取值可能编码严重程度/住院状态而非直接病理，存在 **confounding by indication** 和 **informed-presence bias**；
  - 哮喘队列排除死亡与生物制剂使用者属于“post-baseline 选择”，可能使队列偏向较轻病程，作者在附录中承认了这一局限。
- **可解释性的验证不足**：
  - IG 归因是定性验证，缺少对 faithfulness、稳定性、交互结构（correlated tokens）的定量测试；
  - IG 会在相关 token 间分摊重要性，且不显式建模特征交互；
  - 未做 identity-vs-value 分析，无法区分“实验室事件本身”与“实验室值大小”对归因的贡献（尽管消融实验部分缓解了这一点）。
- **建模限制**：
  - 共享 percentile embedding 意味着具体 lab 的含义需要在后续层中学习，对于“非单调”解释（如某些检测值过高和过低都危险）可能分辨率有限；
  - 无法处理训练词表中不存在的全新或罕见临床编码，泛化到新概念受限。
- **实验与比较的局限**：
  - 哮喘任务上未能直接对比 CLMBR（编码体系不匹配）；
  - 哮喘任务整体表现低于 EHRShot（急性事件难预测、队列规模较小）；
  - 未明确提供微调阶段的算力/资源明细、训练时长等复现细节。
- **因果解释边界**：作者明确说明归因是预测性关联，不构成因果结论，但临床用户仍需警惕过度解读。
