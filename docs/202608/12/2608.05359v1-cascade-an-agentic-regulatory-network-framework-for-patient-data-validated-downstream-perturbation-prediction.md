## 摘要
CASCADE是一种智能体框架，可从预计算的ARACNe调控网络（通过MCP暴露）预测基因扰动的下游转录效应。先前的工作通过检查预测基因是否为已知癌症基因（成员资格）来验证此类工具；我们则检验预测的变化方向是否与现实一致，使用局灶基因拷贝数扩增作为敲低逆向的剂量代理，并基于真实的TCGA患者肿瘤数据进行验证。对于MYC，CASCADE预测的敲低靶标在三种癌症类型（BRCA：90.0%，COAD：72.0%，STAD：85.7%；所有p<0.0013）中与真实的扩增与非扩增肿瘤表达高度一致，远高于置换基线，并通过PAM50亚型对照检验，且在独立队列（METABRIC，87.2%）中得以复制。与基于精选MSigDB基因集的基线通过Fisher精确检验进行比较，CASCADE的准确性并未显示超过现有关于MYC或E2F驱动生物学的公共知识，但其基因特异性的方向判定明显优于朴素均匀猜测。扩展到另外十五个基因，验证证明是基因特异性的而非普遍性的：增殖机制调控因子大多可复制，而谱系同一性转录因子和一个cyclin-D旁系同源物（CCND2）持续失败，我们将这一模式作为有对冲的事后假设进行讨论。我们另外对基于LLM的智能体是否能正确地将自然语言请求锚定到CASCADE的真实MCP工具调用进行基准测试。在35个查询中，一个有文档记录的本地模型达到71.4%的精确匹配（更大的模型为85.7%）；模式错误和基因别名错误可通过规模或服务器端修正解决，但两个模型在模糊查询上均自信地默认为错误的扰动类型，这是一个针对性的修复无法解决的失败，因为其触发条件从未发生。

## Abstract
CASCADE is an agentic framework that predicts downstream transcriptional effects of gene perturbation from precomputed   ARACNe regulatory networks, exposed via MCP. Prior work validates such tools by checking whether predicted genes are   known cancer genes (membership); we instead test whether the predicted direction of change matches reality, using   focal-gene copy-number amplification as a dosage-based proxy for the inverse of knockdown against real TCGA patient   tumor data.   For MYC, CASCADE's predicted knockdown targets show strong concordance with real amplified-vs-non-amplified tumor   expression across three cancer types (BRCA: 90.0%, COAD: 72.0%, STAD: 85.7%; all p<0.0013), well above permutation   baselines, surviving a PAM50 subtype control and replicating in an independent cohort (METABRIC, 87.2%). Compared   against curated MSigDB gene-set baselines via Fisher's exact test, CASCADE's accuracy is not shown to exceed existing   public knowledge of MYC- or E2F-driven biology, though its gene-specific direction-calling clearly outperforms a naive   uniform guess.   Extending to fifteen additional genes, validation proves gene-specific rather than universal: proliferation-machinery   regulators mostly replicate, while lineage-identity transcription factors and one cyclin-D paralog (CCND2)   consistently fail, a pattern we discuss as a hedged, post-hoc hypothesis.   We separately benchmark whether an LLM-based agent correctly grounds natural-language requests into CASCADE's real MCP   tool calls. Across 35 queries, a documented local model reaches 71.4% exact match (85.7% for a larger model); schema   and gene-alias failures are resolved by scale or server-side correction, but both models confidently default to the   wrong perturbation type on ambiguous queries, a failure a targeted fix could not resolve because its trigger condition   never occurs.

## 2. 论文提出的方法论

### 2.1 CASCADE 架构核心技术
- **传播机制**：确定性广度优先（BFS）算法，沿 ARACNe 网络的“调控子→靶基因”有向边传播。敲低时焦点基因初始效应为 −1.0，每跳以边缘权重 × 衰减因子 0.5 传递，跨路径累加。
- **符号翻转机制**：ARACNe 边缘模式注释（激活/抑制）决定方向——激活边保持符号，抑制边翻转符号。这是产生上下调方向预测的核心机制。默认传播深度为 2 跳。
- **嵌入增强**：默认将网络传播与 GREmLN 嵌入余弦相似度混合（加权 α=0.7）。嵌入分量可新增候选基因，但不翻转网络可达基因的方向。
- **智能体编排**：基于 LangGraph 工作流，`CascadeWorkflow.run()` 为公开入口，负责基因角色分类（表 1：Master regulator / Transcription factor / Minor regulator / Effector / Isolated）、路由决策及并发批次调度。分析深度 `"focused"` 仅触发 `perturbation` 与 `targets` 两个分析。
- **MCP 暴露**：通过 Model Context Protocol 将分析工具暴露给 LLM 智能体，支持自然语言查询。

### 2.2 方向一致性验证方法
- 对焦点基因 g，取 CASCADE 预测的 top-50（按 |效应|）靶基因，记录每个基因的预测方向。
- 以**焦点基因拷贝数扩增**（GISTIC 值=2）作为基因剂量增加的代理，视为敲低的逆方向；非扩增组为 GISTIC=0 患者。
- 对每个预测靶基因，比较扩增与非扩增患者平均 mRNA 表达 z-score：预测敲低后下调（正向调控）者，若扩增样本中表达更高则判为一致；预测上调（负向调控）者，若扩增样本中表达更低则判为一致。
- **统计检验**：单侧二项检验（零假设一致率=0.5）+ 独立置换对照（1,000 次从 200 个背景基因池中抽样，随机分配方向标签，排除焦点基因与 CASCADE 预测基因的污染）得到经验 p 值。

### 2.3 LLM 工具调用基准方法
- 使用 CASCADE 真实的 `comprehensive_perturbation_analysis` 工具 schema，35 条手标注查询，覆盖七类：基线 TCGA 癌种、免疫细胞类型、基因别名、非正式癌种名、非标准扰动动词、隐含参数、多实体干扰。
- 评分标准：逐字段精确匹配；省略字段按 CASCADE 文档默认值计分（如扰动类型默认 knockdown）。
- 测试模型：`llama3.1:8b`（CASCADE 文档默认的本地模型）与 `qwen2.5:72b-instruct-q4_0`（较大的本地对比模型），通过 Ollama 本地运行。

## 6. 论文的主要结论与发现

### 6.1 MYC 核心验证结果
- **三癌型方向一致性**：BRCA 45/50（90.0%，p<10⁻⁸）、COAD 36/50（72.0%，p=0.0013）、STAD 42/49（85.7%，p<0.0001）；置换 p 均为 0.0000，置换基线落在 48.4%–53.8%（接近随机）。
- **一致性生物学合理**：BRCA 一致靶标集中于核糖体生物发生/核仁组件（NOP14、RIOK1、NOLC1、WDR43、KAT2A 等），为 MYC 已知的核心转录程序。
- **稳健性**：N=25/50/100 时一致率 88.0%/90.0%/92.0%，几乎平坦；PAM50 LumB 亚型内 92.0%；METABRIC 独立队列 87.2%（p<10⁻⁶）。
- **基线对比**：与 MSigDB 精选 MYC 靶集差距仅 1–4 个百分点（方向不一致、均不显著，p=0.34–0.86）；E2F3 对 E2F TARGETS 名义领先（96.0% vs 90.7%）但不显著（p=0.384）。所有四个比较经 BH 校正后均不显著（q=0.767–0.863）。
- **方向消融**：强制统一猜测使一致率下降 14–29 个百分点；上调预测子集自身 76.5–92.3% 正确，排除“被下调预测支撑的噪声”假说。

### 6.2 泛化测试结论——验证是基因特异的
- **增殖机制基因（大多验证）**：E2F3（96.0%）、CCND1（BRCA 96.0%）、CCND3（BRCA 76.0%、STAD 79.6%）、AURKA（BRCA 100%、COAD 92.0%）、CCNE1（BRCA 100%、STAD 98.0%）、FOXM1（100%）、TOP2A（BRCA/STAD 均 100%）、RPS6KB1（89.6%）验证；MDM2（BRCA 68.0%）较弱验证。
- **谱系因子/RTK（全部失败或矛盾）**：GATA3（0.0%）、FOXA1（34.0%）、SOX9（38.8%）、ESR1（4.0%，故意选来证伪）、ERBB2（BRCA 18.0%/COAD 14.3% 反一致，STAD 93.6% 强一致）。
- **关键反例**：CCND2 与验证的旁系同源物 CCND1/CCND3 同为 cyclin-D，但在 BRCA（38.0%，反一致）和 COAD（54.2%，随机）中均失败——唯一在所有测试癌型中失败的增殖机制基因。
- **跨癌型不一致**：CCND1（96.0%→57.1%）与 MDM2（68.0%→42.0%）在 BRCA 验证但在 STAD 失败；ERBB2 呈相反方向的不一致。据此，基因类别无法单独预测验证结果，癌型背景同样重要。
- **嵌入伪影排除**：27 个组合中嵌入独有基因 0–1 个，GATA3 网络只传播结果仍为 0/50，确认反一致性源于网络本身。
- **提出事后假说**：增殖机制基因的输出随剂量缩放，而谱系因子以染色质级非线性的方式建立细胞状态，可能不随拷贝数线性响应。作者明确将其标记为有对冲的事后假说，非既定机制。

### 6.3 LLM 工具调用基准结论
- 精确参数匹配：`llama3.1:8b` 71.4%（25/35），`qwen2.5:72b` 85.7%（30/35）。
- **三类失败模式**：
  - 模式违反（网络参数缺失/错置）：几乎只在 llama3.1:8b 出现（8 次），更大模型 0 次；
  - 基因别名：原始输出都错（3/5），但经 CASCADE 服务器端 `resolve_alias()` 后全部解决（llama 升至 3/5、qwen 升至 5/5）；剩余失败本质是网络参数错误而非基因命名；
  - **扰动类型歧义**：两个模型都在“What does MYC do?”上自信地选择 overexpression 而非文档默认 knockdown；qwen 在另一查询上同样出错。该失败**无法**通过服务器端检查修复——因为两个模型从不留空该字段，触发条件（字段缺失）在 35 个查询中从未出现，属于“自信的错误猜测”而非“省略后默认”。
- 针对性修复：添加自然语言语句扫描 + 缺失时要求澄清——测试结果 0/6 触发，原因相同：字段从未缺失。论文由此提出更根本的修复方向（验证供给值与查询文本一致性，或要求显式“未指定”哨兵值），超出实现范围。
