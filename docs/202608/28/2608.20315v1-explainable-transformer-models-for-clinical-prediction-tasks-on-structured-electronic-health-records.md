## 摘要
基于结构化电子健康记录（EHRs）的预测模型仍然是医疗保健机器学习的关键，但很少有模型同时强调定量实验室信息和相对于输入医疗事件的可解释性。我们提出了BERT-LER，一种BERT风格的模型，用于编码EHR时间线，该模型从包含7500万名患者的去标识化EHR数据集中进行预训练和微调，将实验室检测结果编码为离散标记，同时通过基于百分位的分箱保留分级信息，并与Integrated Gradients相结合，以基于输入EHR序列进行标记级归因。我们在公共EHRShot基准套件和基于真实世界数据的哮喘严重程度进展研究上对我们的方法进行了基准测试。这通过将实验室价值表示和可解释性统一在一个框架中，解决了EHR基础模型建模中的方法论空白，同时评估了预测性能和解释是否能超越标准临床预测任务进行泛化。在EHRShot和哮喘任务中，BERT-LER实现了与公开可用的基准模型具有竞争力的预测性能，并且在涉及实验室的任务上通常超过这些模型，同时提供了与临床已知风险因素一致的归因。我们的架构和可解释性方法可应用于许多治疗领域和预测任务，使用在结构化EHR上训练的语言模型。

## Abstract
Predictive models over structured electronic health records (EHRs) remain central to machine learning for healthcare, but few have jointly emphasized quantitative laboratory information and interpretability with respect to input medical events. We present BERT-LER, a BERT-style model for coded EHR timelines pretrained and fine-tuned from a de-identified EHR dataset of 75 million patients, that encodes laboratory test results as discrete tokens while retaining graded information through percentile-based binning, paired with Integrated Gradients for token-level attributions grounded in the input EHR sequence. We benchmark our approach on the public EHRShot benchmark suite and on an asthma severity progression study based on real-world data. This addresses a methodological gap in EHR foundation-style modeling by unifying laboratory value representation and explainability in a single framework, while assessing whether both predictive performance and explanations generalize beyond standard clinical prediction tasks. Across EHRShot and asthma tasks, BERT-LER achieves predictive performance that is competitive with, and on laboratory-related tasks often exceeds, publicly available benchmark models, and provides attributions that align with clinically known risk factors. Our architecture and explainability approach can be applied to many therapeutic areas and prediction tasks using language models trained on structured EHRs.

## 1. 核心问题与研究动机

电子健康记录（EHRs）是现代医疗保健的核心，包含纵向的患者历史信息（诊断、治疗、药物、实验室结果等），是临床预测建模的重要数据来源。近年来，基于 Transformer 的模型在 EHR 预测任务上表现优异，但仍有两大关键挑战尚未被现有方法同时解决：

- **实验室值的表示问题**：结构化实验室检测结果本质上是连续、临床语义细微的数据，难以在不丢失重要数量信息的前提下嵌入基于离散 token 的 Transformer 架构。
- **可解释性不足**：临床部署要求模型预测能够依据患者历史进行解读，但许多高性能模型对单个医疗事件如何影响预测提供有限洞见。

现有研究或侧重于预测性能但忽视实验室感知建模，或提供可解释性但不保留实验室值的分级信息；几乎没有工作将“实验室感知表示”与“token 级归因”统一在同一个框架中。BERT-LER 旨在填补这一方法论空白。

## 2. 方法论

### 2.1 模型架构：BERT-LER
BERT-LER 是一种 BERT 风格的编码器模型，专门用于编码化 EHR 时间线，其核心设计如下：

### 2.2 实验室值的百分位分箱
- 每个实验室检测结果被离散化为 **10 个百分位等级**（0–10% 至 90–100%），以整个 TriNetX Dataworks 数据集为参考人群计算分位切点。
- 最低和最高 bin 为开放尾端（(−∞, P10] 与 [P90, +∞)），因此不需要单独的异常值处理；缺失值天然由“事件未出现”隐式处理。
- **因子化表示**：每个实验室检测使用“检测代码嵌入 + 共享百分位嵌入”求和，而非为每个“检测×百分位”组合分配独立 token。这一设计显著节省了参数量（N + M vs. N × M），且随着分箱变细，参数增加幅度大为降低。

### 2.3 输入表示
每个患者的输入由三个序列数组构成：
- **Token 序列**：人口统计学信息（年龄、性别、种族等）和医疗事件（ICD-10、NDC、LOINC 等代码）按时间顺序排列。
- **位置 ID 序列**：自首个医疗事件起的天数；采用相对键-查询位置嵌入（Shaw et al., 2018）。
- **百分位 ID 序列**：实验室结果的百分位等级；非实验室 token 的百分位 ID 为 0。

### 2.4 预训练
- 使用**掩码语言建模（MLM）**进行预训练，遵循 TransformEHR 的方法。
- 预训练数据：TriNetX Dataworks 约 7500 万患者（约一半用于预训练，另一半用于下游基准测试，确保无患者重叠）。
- 模型输入限制为 512 个 token 或最多 5 年患者数据（更长序列删除最早事件）。
- 实验设置：12 层、12 个注意力头、嵌入维度 768、fp16、相对位置编码；超参数搜索范围：学习率 {5e-5, 1e-5, 5e-6}，批量大小 {16, 32}；在单个 A10 GPU（24 GB VRAM）上预训练，训练约 1–2 个 epoch，覆盖 2000 万至 4000 万独特患者历史。

### 2.5 可解释性：Integrated Gradients（IG）
- 采用 **Integrated Gradients**（Sundararajan et al., 2017）方法计算每个输入 token 对预测的归因分数，公式如下：

  ```
  IG_i(x) = (x_i − x′_i) × ∫₀¹ ∂F(x′ + α(x − x′)) / ∂x_i dα
  ```

  其中 F 为模型预测函数，x′ 为基线输入，α 为插值缩放参数，积分通过 Rieman 和近似。
- **基线选择**：非特殊 token 使用全零嵌入；人口统计学 token 使用类别内平均嵌入；实验室 token 的百分位基线设为中位百分位。
- **选择 IG 而非 SHAP/反事实删除法**：IG 的计算成本只与积分步数相关，与序列长度无关，更适合可能跨越数年的 EHR 序列。
- 对实验室 token，归因基于“检测代码嵌入 + 百分位嵌入”的联合嵌入，反映检测及其值的共同贡献。
- 归因聚合时引入频率下加权调整：`adj.score = avg.score × max(0, 1 − k/n)`，以减少低频噪声 token 的影响。

### 2.6 变体：实验室消融
BERT-LER（无实验室值嵌入）保留了实验室检测 token 但移除百分位嵌入，用于隔离“实验室值大小”与“实验室事件存在”的各自贡献。

## 6. 主要结论与发现

1. **预测性能**：BERT-LER 在 EHRShot 的大部分任务上取得最优或并列最优结果，**尤其在所有实验室预测任务上显著优于 CLMBR**（如贫血 0.910 vs. 0.891、低钠血症 0.867 vs. 0.733、血小板减少 0.808 vs. 0.783）。ICU 相关结果任务与 CLMBR 相当。Med-BERT 和 RETAIN 在所有任务上均未优于 CLMBR 或 BERT-LER。
2. **哮喘任务**：BERT-LER 在全部 3 个任务、PR-AUC 和 ROC-AUC 两种指标上均取得最佳性能（如失控任务 PR-AUC 0.599 vs. XGBoost 0.554、Med-BERT 0.509）。
3. **消融实验的意义**：去除百分位嵌入后性能一致下降，证明**实验室值幅度**对预测有独立贡献，且比单独事件存在提供更多信息。
4. **可解释性的临床对齐**：归因结果与已知临床风险因素广泛一致——贫血方面恢复出年龄（儿童和极高龄）、性别（女性）、肠道疾病合并症与贫血的关联；哮喘方面识别出哮喘严重程度代码、SABA 频繁使用、LABA-ICS 组合、COPD 合并症、肥胖、种族差异、实验室指标（BMI、有核红细胞比率、eGFR、维生素 D 等）等已知风险因素。
5. **方法论可推广性**：该架构和可解释性方法可应用于多种治疗领域和预测任务，无需专家人工特征工程。

## 7. 优点

- **规模优势**：在 7500 万患者规模的去标识化数据上预训练，显著大于现有工作。
- **因子化实验室表示**：百分位分箱（保留分级信息）与共享百分位嵌入（参数高效，N+M 而非 N×M）的结合是工程上的亮点；对开放尾端和缺失值的自然处理也很优雅。
- **统一的可解释性框架**：实验室值 token 与诊断/药物 token 通过同一 IG 归因框架进行解释，避免将预测性能与可解释性割裂。
- **方法选择有理有据**：选择 IG 而非 SHAP 等扰动方法，基于序列长度扩展性的明确论证。
- **领域知识整合**：在归因分析中充分考虑“ confounding by indication / informed-presence bias”，并承认实验室检测的下单本身编码了护理场景和病情严重程度，不将相关性误读为因果性。
- **对可复现性的重视**：提供了训练包和可解释性软件的开源仓库。
- **对多编码体系适应性的处理**：通过 UMLS 映射实现 TriNetX 与 EHRShot 之间的概念迁移，被公认为一个实际工程挑战。

## 8. 不足与局限

### 方法层面
- **不建模混杂因素**：未显式建模潜在的混杂变量，尤其是实验室 token 的“检测下单行为”可能编码了护理环境和病情严重程度，使归因部分反映检测场景而非直接病理生理。
- **IG 的固有局限**：Integrated Gradients 可能在相关 token 之间分配重要性，且不显式处理特征交互；归因验证仅限于定性层面，缺少正式的忠实性/稳定性测试。
- **非单调解释受限**：共享百分位嵌入意味着实验室值特异的临床含义需要由后层学习，对解释强烈非单调于百分位的检测（如某些激素的双相效应）可能分辨率不足。
- **词汇外推能力有限**：无法解释训练中未见的新临床编码，限制对罕见或新引入概念的泛化。

### 临床/实验层面
- **选择偏差风险**：哮喘研究中排除“随访期死亡”和“生物制剂起始”作为标准（基于随访后信息），属于在基线后变量的条件下选择样本，可能使队列偏向较轻轨迹、减弱最严重结果的关联。
- **性能天花板**：哮喘任务中整体性能有限（尤其中度任务 PR-AUC 仅 0.232），反映罕见、仅部分可预测的进展事件的预测难度及较小的微调队列规模。
- **泛化性证据有限**：仅在贫血和哮喘两个场景上有可解释性评估，且后者与对比模型（RETAIN/XGBoost）的归因对齐虽存在但主要依赖人工定性比较。

## 9. 总体评价

BERT-LER 在“实验室感知的 EHR 表示”与“token 级可解释性”的交叉点上提供了一个工程上优雅、实证上有效的解决方案。其因子化百分位嵌入设计在参数效率和临床信息保留之间取得了较好平衡，且通过大规模预训练和统一的可解释性框架，展示了 Transformer 类模型在医学时间线建模中的潜力。论文的评估设计（公共基准 + 自定义临床协议 + 消融）较为全面，统计严谨性良好，对基线模型的公平性处理也较为透明。

但论文在可解释性的量化验证、跨领域的泛化证据以及某些工程细节的披露方面仍有明显不足。特别是，IG 归因与临床事实的一致性是定性人工评估的，缺乏衡量归因忠实性和稳定性的客观指标，这限制了对“模型真正依据历史事件决策”这一核心主张的可信度。此外，哮喘任务的较低性能也提醒我们，真实世界中的罕见事件预测仍具有内在难度，不是任何单一建模技巧能完全克服的。

总体而言，本文的贡献在于：
1. 提出了一种参数高效且保留实验室值分级信息的离散化表示方法；
2. 构建了一个同时支持预测和归因的统一框架；
3. 在多项任务上验证了实验室感知预训练模型相较于基线的优势；
4. 为后续工作在“可解释的临床时间线建模”方向上提供了可复用的工具和基线。

对于关注 EHR 建模和临床可解释 AI 的研究者，这是一篇值得仔细研读的工作；其方法可推广性仍需在更多疾病和治疗领域中进行检验。
