## 摘要
通过插入或替换节点来更新图，同时保持语义并重用现有结构，是一个反复出现的计算问题。在群体遗传学中，这一问题出现在基因型表示图（GRG）中，GRG是一种有向无环图，通过共享单个突变的子图结构，无损地编码跨越数十万样本的定相遗传变异。在GRG中，每个突变的携带者集合被隐式编码为从分配给该突变的节点可达的叶节点集合。因此，更新一个突变本质上是一个结构编辑问题，而当前的方法会逐个重新映射突变。本文介绍了一种批量突变重映射算法，该算法用一次共享的反向拓扑遍历取代独立的、考虑重用的遍历，一次性为整个批次识别重用候选。该遍历传播紧凑的每突变位并行状态，并使用自适应的稀疏/稠密携带者集合表示，涵盖从稀有到常见变异密度的范围。批处理是基分裂并行性（split-based parallelism）的一种内存可扩展补充，后者需要为每个工作器复制图和遍历状态。我们在受控更新工作负载和端到端等位基因极化（群体遗传分析中常见的批量携带者集合更新）上评估了我们的重映射算法。与独立重映射相比，我们的方法在保持精确携带者集合语义的同时，速度最高可提升10.5倍。

## Abstract
Updating a graph by inserting or replacing nodes while preserving semantics and reusing existing structure is a recurring computational problem. In population genetics, this problem arises in the genotype representation graph (GRG), a directed acyclic graph that losslessly encodes phased genetic variation across hundreds of thousands of samples by sharing subgraph structure for individual mutations. In a GRG, each mutation's carrier set is implicitly encoded as the set of leaf nodes reachable from the node it is assigned to. Updating a mutation is therefore a structural editing problem, and current approaches remap mutations individually.   This paper introduces a batched mutation-remapping algorithm that replaces independent reuse-aware traversals with a single shared reverse-topological pass, identifying reuse candidates for an entire batch at once. The pass propagates compact bit-parallel per-mutation state and uses an adaptive sparse/dense carrier set representation spanning rare-to-common variant densities. Batching is the memory-scalable complement to split-based parallelism, which instead replicates graph and traversal state per worker. Our remapping is evaluated on a controlled update workload and on end-to-end allele polarization, a bulk carrier set update that is common in population genetic analysis. Our approach is up to 10.5$\times$ faster than independent remapping while preserving exact carrier-set semantics.

# 《Cheaper by the Batch: Shared Traversal for Genotype Graph Editing》中文总结

## 1. 核心问题与研究动机

基因型表示图（Genotype Representation Graph, GRG）是一种多树结构的有向无环图（DAG），用于无损编码数十万样本的定相遗传变异，其紧凑性来源于对相同子图结构的复用。**核心挑战在于**：GRG中每个突变的携带者集合是通过节点可达性（reachability）隐式编码的，即某节点可达的叶子集合即为该节点所携带突变的携带者。这意味着**更新一个突变的携带者集合并非局部编辑，而是需要重构图拓扑**——必须找到复用现有图结构的候选节点，必要时引入新结构。

现有的单突变映射（MapMutations）方法逐个处理突变，每个突变都触发一次独立的、数据依赖的图遍历（reverse topological traversal），在大规模批量更新时导致大量重复遍历同一子图的工作。论文针对这一痛点，提出**批量突变重映射算法**，用一次共享反向拓扑遍历替代多次独立遍历，以摊销大规模更新场景（如等位基因极化）中的重复计算。

## 2. 方法论：核心思想与关键技术

**核心理念**：将 k 次独立的、带复用感知的单突变遍历合并为一次共享遍历，通过**位并行（bit-parallel）状态传播**同时找出整批突变的重用候选节点，同时采用**自适应稀疏/稠密载体集表示**以覆盖稀有到常见变异的密度范围。

**关键技术细节**：

- **两阶段流程**：
  1. **批量候选发现**：以所有突变的载体集并集为起点，每次激活节点仅处理一次，逐节点传播每个突变的兼容性掩码（bitmask），节点兼容判定为所有子节点兼容的与运算（`D(n) ⊆ Si ⇔ ∀c∈children(n), D(c) ⊆ Si`）。
  2. **串行应用（贪心选择）**：按 |D(n)| 降序贪心选择互不相交的候选覆盖尽可能多的载体集；无候选覆盖的样本直接挂到新节点下。

- **位并行状态**：每个批次最多 w 个突变（w 为字长）可用一个机器字表示每个活跃节点的兼容状态；批量大于 w 时用 q=⌈k/w⌉ 个字分组传播，成本为 O(q·|VB|)。

- **自适应载体集表示**：小集合用稀疏向量（样本ID数组），超过密度阈值 τ 后转为稠密位图；转换是单向的（只增不删），稠密位图与稀疏向量结合时直接吸收。阈值 τ=1/32 是 32 位 ID 的存储交叉点，实验跨越 τ∈{0.001, 0.005, 0.01, 0.03125, 0.05, 1.0}。

- **与分裂式并行协作**：共享遍历在分区（split）内部运行，不增加工作器内存复制，是分裂并行（按基因组位置分块）的内存可扩展补充。

**复杂度对比**：独立发现的总代价为 O(Σi(|Vi|+Zi))；批量为 O(q|VB|+ZB)。当重叠因子 ρ(k)=Σ|Vi|/|∪Vi| > q 时，批处理占优。

## 6. 主要结论与发现

- **显著加速**：在200k单倍型数据集上，批量大小1024相比批量1：共享遍历时间减少**79.5×**，端到端极化时间加速**10.5×**，且峰值内存仅上升1.29倍。
- **重叠因子高**：ρ 随批量大小近乎线性增长，批量1024时达 **916.8×**，说明批量内突变遍历路径高度共享，独立映射存在大量重复工作。
- **自适应表示有效**：在大批量（1024）时稠密替代稀疏可带来1.72×–2.44×的额外遍历加速；固定 τ=0.01 的稳健性较好（22/25配置在最优值20%范围内，平均慢9.5%）。
- **紧凑度代价可控**：批量≤256时输出图结构性成本较低（边数增加≤18.73%、序列化大小增加≤6.43%）；批量1024时边数增加78.24%、序列化大小增加27.15%，需要权衡。
- **跨数据一致性**：真实数据（AoU chr21）与最大模拟数据集表现出相同趋势（9.6×加速），验证了方法的实用价值。

## 7. 优点与亮点

- **方法创新性**：将多源图搜索中“合并前沿”的思想推广到GRG编辑场景，并用位并行状态在单次遍历中同时评估多个突变的兼容性，是算法设计上的亮点。
- **与分裂式并行正交融合**：批量共享遍历在子图分区内部运行，不增加内存复制，补充了现有并行化方案的内存可扩展短板——这是系统层面的巧妙搭配。
- **理论完备性**：用归纳法证明了批量发现与独立发现产生的候选列表逐项等价（在相同图快照上），并给出复杂度分析，理论界限清晰。
- **工程实用性**：自适应稀疏/稠密表示在稠密度临界点自动切换，一次转换无回退，且 τ=0.01 的固定值在大范围配置上接近最优，降低了调参负担。
- **验证严谨性**：模拟实验通过“翻转10%位点祖先等位”构造已知期望答案的受控工作负载，可直接验证GRG语义正确性；代码开源可复现。

## 8. 不足与局限

- **紧凑度退化风险**：批内应用顺序固定，后处理突变不能复用批内新建结构，批量1024时边数增加78.24%，可能影响下游分析性能（更长的遍历时间），大规模生产环境中需权衡。
- **实验覆盖范围有限**：真实数据仅验证单条染色体，未做全基因组或多染色体（如常染色体+性染色体）的极化测试，无法确认更大规模、不同连锁结构的图上的外推性。
- **缺少与其他方法的直接对比**：仅以批量=1为基线，未与PLINK PGEN、BCF等替代格式的更新流程对比，也未见与并行版单突变映射的系统对比（文中仅描述为现有基础）。
- **工作分解的粒度**：在批量1024时，遍历时间已大幅下降，但候选发现、应用、极化专用处理、I/O成为新瓶颈，论文只做了定性描述，未深入优化这些阶段。
- **内存增长的潜在风险**：批量1024内存增加26%–29%在200k规模下约37GB额外内存；若扩展到百万单倍型或更大批次，内存访问模式与缓存缺失行为可能改变最优参数（τ、批量大小），需要重新调优。
