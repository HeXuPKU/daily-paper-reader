## 摘要
将汇总层面的科学知识整合到神经网络模型中，为将训练于充分抽样源队列的预测模型迁移到个体数据往往有限或不可得的少数目标人群提供了一种实用策略。在本研究中，我们提出了融合外部汇总层面科学知识的迁移预测策略，并展示了其在PRISMA母婴健康研究中的应用，即在源数据上训练神经网络模型以预测目标队列中的不良结局。此外，我们还扩展了现有的GRU-D框架，通过引入静态特征嵌入和注意力权重，联合利用时间序列信息与静态信息来提升预测性能。我们的方法利用源自目标人群汇总统计的软标签，对最初在源人群上训练的GRU-D-Static模型进行微调。我们评估了六种母婴结局，包括死产、早产、低出生体重、小脆弱新生儿、新生儿死亡和孕产妇近 miss。在所有测试场景中，与在源样本上训练的深度学习模型相比，仅使用基本协变量生成的软标签进行微调即可显著提升预测性能。此外，当逻辑回归模型中纳入额外协变量，或当目标人群的部分输入特征可用于微调时，性能略有进一步提升。这些发现表明，通过源神经网络模型的迁移预测整合文献中已有的科学知识，可以提升少数目标人群的预测性能，减少对大规模数据收集的依赖，并支持全球健康领域的风险预测。

## Abstract
Integrating summary-level scientific knowledge into neural network models provides a practical strategy for transferring prediction models trained on adequately sampled source cohorts to underrepresented target populations, where individual-level data in the target domain are often limited or unavailable. In this study, we propose transfer prediction strategies incorporating external summary-level scientific knowledge and illustrate its application on the PRISMA Maternal and Neonatal Health Study, training a neural network model on the source data to predict adverse outcomes in the target cohorts. Besides, we also extend the existing GRU-D framework by incorporating static feature embeddings and attention weights to jointly leverage temporal and static information for improved prediction. Our approach employs soft labels derived from summary-level statistics describing the target population to fine-tune GRU-D-Static models that are initially trained on the source populations. We evaluate six maternal and neonatal outcomes, including stillbirth, preterm birth, low birth weight, small vulnerable newborn, neonatal death, and maternal near miss. Across all tested scenarios, fine-tuning using soft labels from just basic covariates substantially improved predictive performance compared with deep learning models trained on the source sample. Furthermore, the performance slightly improves more when additional covariates were incorporated into the logistic regression model or when partial input features from the target population were available for fine-tuning. These findings demonstrate that integrating existing scientific knowledge in the literature through transfer prediction of source neural network models can enhance prediction performance in underrepresented target populations, reducing reliance on large-scale data collection and supporting risk prediction in global health.

### 一、论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在代表性不足的人群（如非洲和亚洲的低中收入国家）中，由于目标人群个体级数据（individual-level data）往往稀缺或不可得，直接在目标人群上训练预测模型非常困难；而直接将源人群（如数据充足的亚洲或非洲队列）训练好的模型应用于目标人群，又会因风险因子分布、结局患病率以及协变量-结局关系的地区差异导致预测性能显著下降。
- **研究背景**：
  - 目标人群个体级数据不可得时，已有文献中往往存在基于目标人群的汇总级统计知识（例如多因素逻辑回归系数），但这些知识在现有迁移预测框架中未被充分利用。
  - 现有迁移学习方法（如COMMUTE、TransRF、PRIME等）大多需要目标人群的个体级协变量数据，难以应对仅存在汇总级知识的现实场景。
  - 经典GRU-D深度学习框架只能处理带缺失的时间序列数据，无法纳入仅测量一次的静态特征（如产妇年龄、BMI、教育程度等），限制了其在临床纵向数据中的应用潜力。
- **整体含义**：以PRISMA母婴健康研究为平台，提出一种利用汇总级科学知识生成软标签来微调源训练深度学习模型的迁移预测策略，使模型在无目标个体数据或仅部分目标协变量可用的情境下，仍能显著提升对目标人群不良结局的预测能力。这项策略旨在降低对大规模数据收集的依赖，助力全球健康领域的风险预测。

### 二、论文提出的方法论

#### 1. 总体思路（核心工作流）

- 先在一个数据充足的**源人群**上训练深度神经网络（GRU-D-Static）模型；
- 利用目标人群公开文献中已有的**汇总级知识**（即目标人群中拟合的多因素逻辑回归系数 \(\hat{\beta}_{\text{target}}\)）在源人群协变量上生成**软标签**（soft labels，即预测概率 \(\hat{p} = \sigma(X\hat{\beta}_{\text{target}})\)）；
- 将源人群协变量与软标签组合，对源训练模型进行**微调（fine-tuning）**，使模型适配目标人群的特性；
- 最终在目标人群的真实数据上评估预测性能。

该方法为**模型无关**（model-agnostic），可直接套用到其他深度学习框架，不仅限于GRU-D-Static。

#### 2. GRU-D-Static框架

- 在原始GRU-D框架（Che et al., 2018）基础上扩展，以处理**时序特征与静态特征并存**的临床数据。
- **时序部分（沿用GRU-D）**： 
  - 输入带掩码的时序特征 \(X_{\text{temp}}\) 和掩码向量 \(M_{\text{temp}}\)；
  - 使用**输入衰减机制** \(\gamma_t = \exp(-\mathrm{ReLU}(W_\gamma \delta_t))\) 对缺失值进行指数衰减插补；
  - 门控更新公式为：
    \[
    R_t = \sigma(W_R^{(x)} x_t^d + W_R^{(h)} H_{t-1} + W_R^{(m)} m_t + b_R),
    \]
    \[
    Z_t = \sigma(W_Z^{(x)} x_t^d + W_Z^{(h)} H_{t-1} + W_Z^{(m)} m_t + b_Z),
    \]
    \[
    \tilde{H}_t = \tanh(W^{(x)} x_t^d + W^{(h)}(R_t \odot H_{t-1}) + W^{(m)} m_t + b),
    \]
    \[
    H_t = (1 - Z_t) \odot H_{t-1} + Z_t \odot \tilde{H}_t.
    \]
- **静态特征嵌入**：通过全连接层与ReLU激活将静态特征 \(X_{\text{static}}\) 嵌入为 \(\phi_{\text{static}} = \mathrm{ReLU}(W_{\text{static}} X_{\text{static}})\)。
- **注意力权重**：利用 \(\phi_{\text{static}}\) 生成注意力向量 \(\alpha_{\text{static}} = \sigma(W_{\text{att}} \phi_{\text{static}})\)，对最终GRU隐状态 \(H_t\) 做元素级加权得到 \(H_t^{\text{att}} = \alpha_{\text{static}} \odot H_t\)；
- **输出**：将 \(H_t^{\text{att}}\) 与 \(\phi_{\text{static}}\) 拼接，经Dropout后由全连接层输出预测概率 \(\hat{Y} = \sigma(W_{\text{out}} H_{\text{final}})\)。
- **设计优势**：静态特征既可通过注意力权重调节时序表征的贡献，也可直接参与最终预测，同时保留GRU-D对时序依赖和缺失模式的建模能力。

#### 3. 迁移预测策略（三种场景）

- **场景1（仅基本协变量的科学知识）**：目标人群无个体级数据可用，仅知目标逻辑回归模型中**基本协变量**（如社会人口学、临床信息）的系数；用源人群协变量 + 软标签微调源模型。
- **场景2（全部协变量的科学知识）**：与场景1类似，但目标逻辑回归模型涵盖**全部协变量**（包括实验室、超声等具体特征），可提供更完整的关联信息。
- **场景3（科学知识 + 部分目标协变量）**：除知识外，目标人群中有部分无标签协变量数据可用（5%–100%），用目标人群协变量及生成的软标签微调模型。
- **微调策略**：冻结时序部分参数（包括衰减权重 \(W_\gamma\) 和GRU门控 \(R_t, Z_t, H_t\)），仅微调**静态嵌入层** \(\phi_{\text{static}}\)、**注意力模块** \(\alpha_{\text{static}}\) 和最终分类层，以适配目标人群的静态特征与结局关联模式。

### 六、论文的主要结论与发现

- **软标签微调显著提升预测性能**：在所有测试场景中，仅使用基本协变量的逻辑回归系数生成软标签进行微调，即可大幅提升源训练模型在目标人群上的AUC。例如：
  - 亚洲→非洲：死产AUC从0.738提升至0.879，新生儿死亡从0.585提升至0.665；
  - 非洲→亚洲：死产AUC从0.946提升至0.983，早产从0.592提升至0.668。
- **纳入更多协变量可进一步改善**：场景2（全部协变量）的性能略优于场景1（基本协变量），但增益有限。
- **鲁棒性良好**：即使目标知识中10%的结局标签被随机翻转（Noise），微调后模型仍优于未微调的Baseline。
- **与目标上界接近**：除个别情况（如非洲为目标时的死产）外，场景1和场景2的AUC与直接在目标数据上训练的模型（Target）差异不大。
- **优于传统逻辑回归**：微调后的GRU-D-Static在各结局上的AUC普遍高于直接使用目标数据拟合的逻辑回归（LR），表明深度模型结合迁移微调优于简单应用汇总系数。
- **场景3的样本效率**：仅用10%的目标协变量数据进行微调，即可达到接近100%目标数据微调的性能，说明该方法对目标数据需求量小、数据利用率高。
- **总体判断**：整合已有文献知识、通过源模型迁移预测可有效提升代表性不足人群的预测性能，减少对大规模数据收集的依赖，为全球健康风险预测提供了可行路径。

- **计算资源信息披露不足**：未报告GPU型号、训练时间、超参设置等，影响可复现性和工程部署评估。
- **泛化性讨论有限**：仅以母婴结局为验证对象，对于其他疾病领域（如T2D、心血管）中的应用效果需要进一步验证；且仅采用AUC单指标评估，未扩展到校准度（calibration）、灵敏度/特异度、阈值相关指标。

### 总结

本论文提出了一个实用且方法新颖的迁移预测框架，通过将汇总级科学知识转化为软标签对源训练的GRU-D-Static模型进行微调，显著提升了目标人群中母婴不良结局的预测性能。虽在实验验证和外部真实摘要应用上存在一定局限，但整体研究在方法创新性、实验设计的系统性和应用落地价值上具有较高水准，为资源有限环境下的临床风险预测提供了有希望的新思路。
