## 摘要
Transformer模型用于高维组学分析时处理数千个基因或通路，尽管其中只有一部分需要深度计算。递归混合（MoR）通过自适应令牌选择或专家选择路由来提高效率。我们提出bioMoR，据我们所知，这是首个将MoR应用于基因水平和通路水平学习的框架。我们的贡献包括在MoR骨干中整合结构化生物学知识的三个位置：基于图的信息共享细化令牌嵌入，结构偏差引导自注意力朝向生物学相关的令牌，以及图感知路由器使用邻域信息来确定每个令牌的递归深度。这些技术以我们的洞察力为中心，即令牌交互的额外知识可以有效地帮助模型构建嵌入并选择哪些令牌应该更深入地学习。在跨越不同组学数据类型的八个基准测试中，并在统一的五折交叉验证协议下评估，bioMoR相比最强的生物学无关MoR基线，平均宏F1提高了8.2个百分点，平衡准确率提高了7.1个百分点，同时相比非递归Transformer，参数减少了75%，FLOPs减少了高达58%。选定的标记基因或通路提供了生物学可解释性，而它们的令牌特定递归深度揭示了计算如何分配。

## Abstract
Transformer models for high-dimensional omics analysis process thousands of genes or pathways, although only a subset requires deep computation. Mixture-of-Recursions (MoR) improves efficiency through adaptive token-choice or expert-choice routing. We propose bioMoR, which, to the best of our knowledge, is the first framework to apply MoR to gene-level and pathway-level learning. Our contributions include identifying three locations for integrating structured biological knowledge within an MoR backbone: graph-based information sharing refines token embeddings, a structural bias guides self-attention toward biologically related tokens, and a graph-aware router uses neighborhood information to determine each token's recursion depth. These techniques are centered on our insight that additional knowledge of token interaction can effectively help models construct embeddings and select which tokens should be learned more deeply. Across eight benchmarks spanning diverse omics data types and evaluated under a unified five-fold cross-validation protocol, bioMoR improves average macro-F1 by 8.2 percentage points and balanced accuracy by 7.1 percentage points over the strongest biology-agnostic MoR baseline while using 75 percent fewer parameters and up to 58 percent fewer FLOPs than a non-recursive Transformer. The selected marker genes or pathways provide biological interpretability, while their token-specific recursion depths reveal how computation is allocated.

- **研究动机**：高维组学数据（如单细胞转录组、多组学癌症数据）通常包含数千个基因或通路，但真正驱动表型的往往只是少数标记基因/调控程序。标准 Transformer 对所有 token 施加相同深度的计算，导致计算浪费，且无法适应基因组信号的稀疏性。
- **核心问题**：哪个基因/通路 token 应被保留？哪些 token 需要更深度的模型计算？这两个选择应同时解决，且应受生物学结构指导。
- **整体含义**：论文提出 bioMoR，据称是首个将 Mixture-of-Recursions（MoR）应用于基因级和通路级组学学习的框架。它将结构化生物学知识（基因共表达、Reactome 通路关系）注入 MoR 骨干的三个环节，使生物学知识成为自适应计算的控制信号，而非仅作为静态先验或后处理解释工具。

## 方法论

- **核心思想**：在 MoR 的共享递归 Transformer 骨干中，将固定生物学知识同时用于嵌入平滑、注意力偏置和路由决策，使不同 token 获得不同的递归深度。
- **Token 化**：
  - 单细胞数据：通过可学习 query 对基因进行软选择，形成 M 个 marker 基因 token；测试时每个 token 可对应一个指定基因。
  - 多组学癌症数据：将基因按 Reactome 通路分组，池化表达、CNV 与突变信息，形成 pathway token。
- **MoR 基础**：共享一个 Transformer 块 fθ，重复 K 次；路由器决定 token 是否继续下一轮递归。专家选择（expert-choice）和 token 选择（token-choice）两种路由策略均被实现。
- **生物学知识构造**：
  - 单细胞：Genomap 方法中的基因共表达矩阵（基于表达逆协方差的部分相关），仅保留选中 marker 基因。
  - 多组学：Reactome 通路间关系，视为无向图，行归一化得 A = D⁻¹B。
- **三个生物知识注入点**：
  1. **嵌入平滑（Site 1）**：T̃ = (1−λ)T + λAT，在进入递归前将 token 向生物学邻居方向平滑。
  2. **注意力偏置（Site 2）**：在 softmax 注意力 logit 中加入 λattn·1[A>0]，鼓励生物学相关 token 交互。
  3. **生物学感知路由（Site 3）**：路由分数 = 原始 MoR 分数 + 基于生物学邻域信息的可学习修正项，修正网络初始输出为零，训练开始时退化为普通 MoR，避免噪声知识干扰。
- **训练与效率**：主损失为类别加权交叉熵，另加标记充分性、多样性、稀疏性和路由器稳定等辅助损失；通过共享参数和按步裁剪活跃 token 数降低 FLOPs。

- bioMoR 相比最强无生物知识 MoR 基线，平均宏 F1 提升 8.2 个百分点，平衡准确率提升 7.1 个百分点。

## 优点

- **首次将 MoR 引入组学学习**：填补了自适应递归与生物学知识结合的空缺。
