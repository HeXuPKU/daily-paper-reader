## 摘要
将汇总层面的科学知识整合到神经网络模型中，为将由充分抽样源队列训练的预测模型迁移到代表性不足的目标人群提供了一种实用策略，而目标领域的个体层面数据通常有限或不可用。在本研究中，我们提出了结合外部汇总层面科学知识的迁移预测策略，并在PRISMA母婴健康研究中展示了其应用：在源数据上训练神经网络模型以预测目标队列中的不良结局。此外，我们还扩展了现有的GRU-D框架，通过引入静态特征嵌入和注意力权重，联合利用时序信息和静态信息以改进预测。我们的方法利用描述目标人群的汇总层面统计信息生成的软标签，对最初在源人群上训练的GRU-D-Static模型进行微调。我们评估了六种母婴结局，包括死产、早产、低出生体重、小而脆弱新生儿、新生儿死亡和孕产妇危重。在所有测试场景中，与在源样本上训练的深度学习模型相比，仅使用基本协变量的软标签进行微调显著提高了预测性能。此外，当在逻辑回归模型中纳入额外协变量，或当目标人群的部分输入特征可用于微调时，性能略有进一步提升。这些发现表明，通过源神经网络模型的迁移预测整合文献中已有的科学知识，可以增强代表性不足目标人群的预测性能，减少对大规模数据收集的依赖，并支持全球健康中的风险预测。

## Abstract
Integrating summary-level scientific knowledge into neural network models provides a practical strategy for transferring prediction models trained on adequately sampled source cohorts to underrepresented target populations, where individual-level data in the target domain are often limited or unavailable. In this study, we propose transfer prediction strategies incorporating external summary-level scientific knowledge and illustrate its application on the PRISMA Maternal and Neonatal Health Study, training a neural network model on the source data to predict adverse outcomes in the target cohorts. Besides, we also extend the existing GRU-D framework by incorporating static feature embeddings and attention weights to jointly leverage temporal and static information for improved prediction. Our approach employs soft labels derived from summary-level statistics describing the target population to fine-tune GRU-D-Static models that are initially trained on the source populations. We evaluate six maternal and neonatal outcomes, including stillbirth, preterm birth, low birth weight, small vulnerable newborn, neonatal death, and maternal near miss. Across all tested scenarios, fine-tuning using soft labels from just basic covariates substantially improved predictive performance compared with deep learning models trained on the source sample. Furthermore, the performance slightly improves more when additional covariates were incorporated into the logistic regression model or when partial input features from the target population were available for fine-tuning. These findings demonstrate that integrating existing scientific knowledge in the literature through transfer prediction of source neural network models can enhance prediction performance in underrepresented target populations, reducing reliance on large-scale data collection and supporting risk prediction in global health.

## 2. 论文提出的方法论

### 核心思想
提出了一种**知识引导的迁移预测策略**：在源人群上训练一个深度预测模型（GRU-D-Static），然后利用从目标人群中拟合的汇总层面统计学知识（逻辑回归系数）生成"软标签"（Soft Labels，即预测概率而非二值结果），在冻结源模型时序参数的同时微调其静态特征处理模块，使模型适应目标人群的特征关联结构。

### 关键技术细节

**（1）GRU-D-Static框架（方法贡献之一）**

原始GRU-D模型能够处理带有缺失值的多变量时序数据，利用衰减机制根据观测时间间隔调整输入特征与隐藏状态。但其关键缺陷在于：**静态特征（一次测量、无时间间隔）无法被纳入**。

本文的扩展策略：
- 静态特征通过一个带ReLU激活的全连接层嵌入：`φ_static = ReLU(W_static · X_static)`
- 通过**注意力机制**生成针对最终GRU隐藏状态逐元素注意力权重：`α_static = σ(W_att · φ_static)`
- 注意力加权后的时序表示为：`H_att_t = α_static ⊙ H_t`
- 将加权时序表示与静态嵌入拼接后经Dropout和全连接层输出预测概率

这使得静态协变量同时具备两种功能：（a）通过注意力权重重新校准时序信息对预测的贡献；（b）通过自身嵌入直接参与预测。

**（2）软标签生成与微调流程（方法贡献之二）**

三种迁移预测场景：

- **场景1**：仅具备目标人群基本协变量（社会人口学特征+临床信息）与结局之间关联的汇总知识，没有目标个体数据。步骤为：在目标数据上拟合多元逻辑回归（模拟文献已发表的系数）→ 将系数应用于源数据的协变量矩阵，生成软标签 `p_source = σ(X_source · β_target)` → 用源协变量与软标签微调源训练好的GRU-D-Static模型。
- **场景2**：与场景1类似，但逻辑回归模型中包含了**全部协变量**（包括实验室检测和超声检查等，在资源匮乏环境中难以获取的特征）。
- **场景3**：除汇总知识外，还可以获得目标人群的部分协变量数据（但没有标签）。此时用目标数据的协变量和软标签进行微调。

**（3）微调策略**
- **冻结**：时序相关的衰减参数、GRU门控参数（W_γ、门函数）——这些被认为已从源数据中捕获了通用的时序模式；
- **更新**：静态特征嵌入层和注意力权重模块——以利用软标签调整静态特征对预测和目标人群的作用。
- 该设计符合迁移学习的一般经验：保留通用的特征表示层，只调整较专门化的层以捕捉目标特有模式。

## 6. 论文的主要结论与发现

1. **软标签微调显著有效**：在所有测试场景中，仅用基本协变量的目标逻辑回归系数生成的软标签进行微调，就能在六个结局上一致性地提升AUC（例如：亚洲→非洲预测死产AUC从0.738提升到0.879；非洲→亚洲预测新生儿死亡AUC从0.693提升到0.868）。
2. **包含全部协变量带来小幅额外提升**：场景2（全部协变量）优于场景1（仅基本协变量），但改善幅度较小，说明基本协变量已包含大部分可迁移的预测信号。
3. **对噪声具有鲁棒性**：即使目标逻辑回归拟合中随机翻转10%结局，微调模型的性能虽有轻微下降，但仍持续优于基线模型。
4. **逼近目标训练上界**：仅用软标签微调（场景1和2）的性能已接近直接在目标数据上训练的模型（Target列），说明在数据有限的情况下这是一种高效的替代方案。
5. **优于传统逻辑回归**：微调后的GRU-D-Static模型在所有场景下均优于直接在目标数据上训练的简单逻辑回归（LR列）。
6. **少量目标数据即可产生显著增益**：场景3中，仅使用10%的目标协变量数据微调，性能即可与使用全部源数据微调的结果相当，表明边际数据收益快速递减。
7. **GRU-D-Static扩展有效**：加入静态特征嵌入与注意力权重后，能够联合利用时序与静态信息提升预测能力。

## 7. 优点

### 方法层面
- **创新性**：首次系统性地将"文献中的汇总统计量"转化为软标签用于深度模型的迁移预测，为"无目标个体数据"的迁移场景提供了一种可行路径；

### 方法层面
