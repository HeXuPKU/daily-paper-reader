## 摘要
基于结构化电子健康记录（EHRs）的预测模型仍然是医疗机器学习领域的核心，但很少有模型同时强调定量实验室信息和相对于输入医疗事件的可解释性。我们提出了BERT-LER，一种BERT风格的模型，用于编码EHR时间线，该模型在包含7500万患者的去标识化EHR数据集上进行预训练和微调，将实验室检测结果编码为离散标记，同时通过基于百分位数的分箱保留分级信息，并结合集成梯度（Integrated Gradients）实现基于输入EHR序列的标记级归因。我们在公开的EHRShot基准套件和一项基于真实数据的哮喘严重程度进展研究上对我们的方法进行了基准测试。这通过将实验室值表示和可解释性统一在单一框架中，解决了EHR基础模型建模中的方法论空白，同时评估了预测性能和解释是否能够推广到标准临床预测任务之外。在EHRShot和哮喘任务中，BERT-LER达到了与公开基准模型竞争的性能，并且在实验室相关任务上通常超过它们，同时提供了与临床已知风险因素一致的归因。我们的架构和可解释性方法可以应用于许多治疗领域和预测任务，使用基于结构化EHR训练的语言模型。

## Abstract
Predictive models over structured electronic health records (EHRs) remain central to machine learning for healthcare, but few have jointly emphasized quantitative laboratory information and interpretability with respect to input medical events. We present BERT-LER, a BERT-style model for coded EHR timelines pretrained and fine-tuned from a de-identified EHR dataset of 75 million patients, that encodes laboratory test results as discrete tokens while retaining graded information through percentile-based binning, paired with Integrated Gradients for token-level attributions grounded in the input EHR sequence. We benchmark our approach on the public EHRShot benchmark suite and on an asthma severity progression study based on real-world data. This addresses a methodological gap in EHR foundation-style modeling by unifying laboratory value representation and explainability in a single framework, while assessing whether both predictive performance and explanations generalize beyond standard clinical prediction tasks. Across EHRShot and asthma tasks, BERT-LER achieves predictive performance that is competitive with, and on laboratory-related tasks often exceeds, publicly available benchmark models, and provides attributions that align with clinically known risk factors. Our architecture and explainability approach can be applied to many therapeutic areas and prediction tasks using language models trained on structured EHRs.

## 1. 论文核心问题与整体含义

电子健康记录（EHR）中的结构化数据是临床预测建模的重要基础，但现有模型普遍存在两个短板：
- **实验室定量信息建模不足**：实验室检验结果本质上是连续值，难以在不丢失分级信息的前提下融入基于离散 token 的 Transformer 架构；
- **可解释性薄弱**：许多高性能模型无法说明哪些输入医疗事件对预测结果起了作用，限制了临床部署和验证。

现有研究（如 CLMBR、TransformEHR、BEHRT 等）已探索 Transformer 用于 EHR 建模，但很少将“实验室感知的表示”与“token 级可解释性”联合起来。本文提出 **BERT-LER**，将实验室值与可解释性统一在同一框架中，并在公共基准和真实临床研究两个场景下验证其性能与解释质量。

## 2. 方法论

### 2.1 核心思想
采用 BERT 风格的双向 Transformer，在约 7500 万患者的去标识化 EHR 数据上预训练，通过**百分位分箱**将连续实验室检验值编码为离散 token（保留分级信息），并利用**集成梯度（Integrated Gradients, IG）** 提供 token 级归因，将预测直接联系回输入医疗事件。

### 2.2 关键实现细节
- **输入表示**：每个患者由三个序列组成：
  - token ID 序列：人口统计信息（年龄、性别、种族等）和医疗事件编码（ICD10、NDC、LOINC、CPT 等）；
  - 位置 ID 序列：自首个医疗事件以来的天数；
  - 百分位 ID 序列：实验室值所属的十分位段（1 表示 0–10%，10 表示 90–100%），非实验室 token 取 0。
- **实验室值编码**：所有实验室检测结果按全体参考人群划分为 10 个百分位桶，采用“实验室代码嵌入 + 共享百分位嵌入”的因子化表示，而非“每个组合一个 token”，显著减少参数量；开放尾部桶处理离群值，缺失值通过“事件未出现即无 token”自然处理。
- **位置编码**：采用相对键-查询嵌入（Shaw et al., 2018）。
- **预训练**：掩码语言建模（MLM），掩码率为 15%；实验室代码 token 和百分位 ID 不联合掩码，即掩码代码时仍保留百分位信息。
- **可解释性**：使用集成梯度计算每个 token 的归因得分，公式为：
  - \( \mathrm{IG}_i(x) = (x_i - x'_i) \int_{\alpha=0}^{1} \frac{\partial F(x' + \alpha(x - x'))}{\partial x_i} d\alpha \)
  - 采用 Riemann 和近似积分；基线嵌入为零向量，但人口统计 token 使用类别平均嵌入作为基线（避免位置模式偏差），实验室 token 使用中位百分位嵌入作为基线。
- **归因聚合**：对测试集全部患者的 token 归因取平均，并用 \( \text{adj.score} = \text{avg.score} \times \max(0, 1 - \frac{k}{n}) \) 对低频 token 进行降权。

## 6. 主要结论与发现

- **预测性能**：BERT-LER 在 EHRShot 全部实验室相关任务上优于 CLMBR（如贫血 0.910 vs 0.891、低钠血症 0.867 vs 0.733、低血糖 0.77 vs 0.75）；在多数诊断和结局任务上与 CLMBR 相当；所有任务中 MED-BERT 和 RETAIN 均未超过 CLMBR 或 BERT-LER。哮喘三项任务中 BERT-LER 在 PR-AUC 和 ROC-AUC 上全面领先。
- **实验室值的贡献**：消融实验显示，去除百分位嵌入后性能下降（如哮喘失控任务 PR-AUC 从 0.599 降至 0.586，恶化任务从 0.232 降至 0.213），证明检验值幅度提供了超出事件是否发生的额外预测信号。
- **可解释性符合临床认知**：贫血任务中模型识别出年龄（儿童和极老年风险高）、性别（女性）、肠道疾病合并症等已知风险因素；哮喘任务中 SABA 频繁使用、ICS/LABA 用药、COPD、肥胖、种族差异等均与文献一致。
- **实验室归因具有提示意义**：高 BMI、有核红细胞比例升高、碱剩余升高与哮喘失控正相关；肾功能指标、血细胞比容、氧饱和度、维生素 D 等与失控负相关。但作者指出这类关联可能受到“指示混杂”（confounding by indication）影响，应视为假设生成而非因果结论。
- **推广性**：该框架不依赖专家手工特征工程，可直接处理完整 EHR，适用于多种治疗领域和预测任务。

## 7. 优点

- **大规模预训练**：7500 万患者的预训练语料显著大于此前同类工作（如 TransformEHR 648 万、GPT 研究 240 万）。
- **实验室值表示的创新**：因子化的“代码嵌入 + 共享百分位嵌入”既保留了分级信息，又避免了 \(N \times M\) 的参数爆炸，内存效率高，且兼容标准 NLP 解释工具。
- **统一框架**：将实验室感知建模与 token 级归因整合在单一流程中，而非将性能与可解释性作为两个分离目标。
- **双场景评估策略**：同时采用公共基准和前瞻性定义的临床方案，兼顾方法学可比性与临床真实性，为后续研究提供了可复制的模板。
- **实验严谨性**：预训练与下游评估患者严格不相交；输入事件限制在索引日期前，避免目标泄漏；置信区间来自 bootstrap；基线模型拥有相同实验室信息。
- **开源**：提供了训练软件包和通用可解释性软件包。

## 8. 不足与局限

- **混杂因素未显式建模**：实验室检验的开单受临床关切和护理场景驱动，实验室 token 的存在和数值可能编码疾病严重程度或护理环境而非直接生理联系（即 informed-presence bias），因此归因应视为预测性关联而非因果效应。
- **解释方法本身的局限**：集成梯度可能将重要性分散在相关 token 上，且未显式刻画特征交互；验证以定性为主，缺少对归因忠实度（faithfulness）和稳定性的量化检验。
- **共享百分位嵌入的局限**：模型需在后续层中学习实验室特异的值含义，对解释呈现强非单调百分位关系的检验项目可能分辨率不足。
- **词汇外泛化受限**：无法解释训练时未见过的临床代码，对罕见或新引入概念不友好。
- **哮喘任务性能偏低**：预测罕见且仅部分可预测的进展事件难度较大，且哮喘微调队列较小。
- **哮喘队列选择的偏倚风险**：排除标准中使用随访期的死亡和生物制剂启动信息，是一种后基线的选择，可能使队列偏向较轻轨迹并弱化最严重结局的关联；作者承认这一点并建议未来采用竞争风险模型处理。
- **代码映射的潜在损耗**：EHRShot 中 SNOMED 概念经 UMLS 映射到 ICD10CM 等编码体系，可能引入映射误差或信息损失。
