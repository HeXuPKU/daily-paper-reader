## 摘要
预测未见遗传扰动下的全转录组响应仍是一项重大计算挑战，因为准确预测需要同时恢复扰动特异性的转录变化和异质性的细胞响应。现有方法往往将确定性响应结构与随机群体水平变异纠缠在一起，导致主导的共享模式掩盖较弱的扰动特异性信号，并损害分布建模。为解决这些挑战，我们提出DeMixPert，一种用于分布外（OOD）单细胞扰动预测的基于高斯混合的分解响应建模方法。DeMixPert将扰动诱导的变化分解为依赖于基础状态的系统性响应、扰动特异性响应和群体水平变异。系统性组分从对照细胞表达编码的基础状态推导而来，而扰动特异性组分则从预训练的目标嵌入推断，以实现未见目标的泛化。DeMixPert使用高斯原型可逆网络对群体水平变异进行建模，并根据基础状态和扰动条件自适应地组合可复用的高斯原型。所得混合分布被映射为条件特异性变异分布。采样的变异与系统性和扰动特异性组分整合，再与基础状态联合解码，以重建扰动细胞的基因表达。实验结果表明，DeMixPert能有效捕获异质性单细胞扰动响应，并在未见扰动设置中取得优越性能。源代码在发表后公开提供。

## Abstract
Predicting transcriptome-wide responses to unseen genetic perturbations remains a major computational challenge because accurate prediction requires recovering both perturbation-specific transcriptional shifts and heterogeneous cellular responses. Existing methods often entangle deterministic response structure with stochastic population-level variation, causing dominant shared patterns to mask weaker perturbation-specific signals and impair distributional modeling. To address these challenges, we propose \textbf{DeMixPert}, an approach for Decomposed response Modeling with Gaussian Mixtures for Out-Of-Distribution (OOD) single-cell Perturbation prediction. DeMixPert decomposes perturbation-induced changes into a basal-state-dependent systematic response, a perturbation-specific response, and population-level variation. The systematic component is derived from the basal state encoded from control-cell expression, whereas the perturbation-specific component is inferred from pretrained target embeddings for unseen-target generalization. DeMixPert models population-level variation using a Gaussian prototype Invertible Network and adaptively combines reusable Gaussian prototypes according to the basal state and perturbation condition. The resulting mixture is mapped to a condition-specific variation distribution. Sampled variations are integrated with the systematic and perturbation-specific components, followed by joint decoding with the basal state to reconstruct perturbed-cell gene expression. Experimental results show that DeMixPert effectively captures heterogeneous single-cell perturbation responses and achieves superior performance across unseen-perturbation settings. The source code is made publicly available upon publication.

## 1. 论文的核心问题与整体含义（研究动机和背景）

单细胞遗传扰动技术（如 Perturb-seq）能够将基因干预与转录组读数相结合，用于刻画细胞对扰动的响应，但其可扩展性受限于扰动目标、细胞状态与生物学背景的组合爆炸，难以对所有条件进行穷尽测量。因此，**计算机模拟扰动响应预测**成为关键工具。然而，在未见过的扰动条件下进行预测，面临三项核心挑战：

- **系统性结构迁移**：基底细胞状态（basal state）贡献的共享响应模式需要学习并迁移到未见条件；
- **未见目标效应推断**：每个扰动具有特异性的转录效应，对于未见扰动需依赖其与已知目标的生物学关系进行推断；
- **条件特异性群体分布估计**：同一扰动下细胞可能存在多个响应亚群，其内部结构和相对丰度随状态改变而变化，且缺乏直接观测。

现有方法（如 scGen、CPA、GEARS、GenePert、scDFM、STATE 等）通常将完整扰动响应作为单一预测目标，**将系统性响应、扰动特异性响应和群体水平变异纠缠在一起**，导致共享的系统性变异主导评估指标，掩盖了较弱的扰动特异性信号，并损害分布建模质量。因此，论文提出 DeMixPert，旨在通过显式分解响应成分，解决 OOD 单细胞扰动预测中的上述难题。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想

DeMixPert 将每个细胞的扰动响应分解为三个可解释的成分：

\[
\hat{r}_i = g_i + a_p + \epsilon_i
\]

- \(g_i\)：依赖基底状态的**系统性响应**（shared systematic response）；
- \(a_p\)：**扰动特异性响应**（perturbation-specific response），由预训练嵌入推导；
- \(\epsilon_i\)：**群体水平变异**（population-level variation），刻画细胞异质性。

该分解将确定性响应结构与随机群体变异分开：前两者构成“确定性响应中心”，后者通过条件生成模型建模。

### 2.2 技术细节与算法流程

#### （1）确定性响应中心学习（Deterministic Response Center Learning）

- 使用三个编码器：
  - 状态编码器 \(E_s\)：从对照细胞表达 \(x_j^0\) 生成基底状态表示 \(s_i\)；
  - 系统响应编码器 \(E_{sys}\)：从 \(s_i\) 生成系统性响应 \(g_i\)；
  - 扰动编码器 \(E_{pert}\)：从预训练 scGPT 基因嵌入平均得到的扰动嵌入 \(e_p\) 生成扰动特异性响应 \(a_p\)。
- 响应中心定义为 \(\bar{r}_i = g_i + a_p \in \mathbb{R}^{d_r}\)。

#### （2）高斯原型可逆网络（Gaussian prototype Invertible Network）

- 全局可复用高斯原型：通过 EM 算法从所有训练细胞的目标残差 \(\epsilon_i^* = r_i^* - \bar{r}_i\) 中估计 K 个对角高斯分量 \(\{(\pi_k, \mu_k, \sigma_k^2)\}\)。
- 条件混合权重：将基底状态 \(s_i\) 和扰动表示 \(a_p\) 拼接，经 MLP 与 softmax 生成原型权重 \(\alpha_i\)，形成条件高斯混合 \(P(z|\alpha_i)=\sum_k\alpha_{ik}\mathcal{N}(z;\mu_k,\mathrm{diag}(\sigma_k^2))\)。
- 可逆网络 \(T_\theta\)：由 L 个加性耦合层构成（类似 RealNVP），将源变量 \(z_i\) 映射为变异样本 \(\epsilon_i = T_\theta(z_i;c_i)\)，其中条件 \(c_i = \mathrm{concat}(s_i,a_p)\)。
  - 耦合层中，未变化维度用于计算与各高斯原型的匹配责任 \(\gamma_{ik}^\ell\)，再与条件网络产生的调制系数 \(b_i^\ell\) 组合，生成对另一维度的加性偏移，保证可逆性和单位雅可比。
- 训练时，将目标残差逆变换回混合空间 \(z_i^* = T_\theta^{-1}(\epsilon_i^*;c_i)\)，用负对数似然监督权重与网络。

#### （3）表达解码与训练目标

- 解码器 \(D_\psi\) 将基底状态 \(s_i\) 与预测响应 \(\hat{r}_i = \bar{r}_i + \epsilon_i\) 拼接，重建扰动后表达 \(\hat{x}_i^p\)。
- 总损失由四部分组成：
  - 响应对齐损失 \(L_{align}\)（MSE）；
  - 群体变异似然损失 \(L_{gm}\)（条件高斯混合NLL）；
  - 基因表达重建损失 \(L_{rec}\)（包含预测响应、目标响应、零响应对照三项）；
  - 分布匹配损失 \(L_{dist}\)（能量距离，按扰动条件计算）。
  - 总损失：\(L = L_{align} + \lambda_{gm}L_{gm} + L_{rec} + L_{dist}\)。

## 6. 论文的主要结论与发现

1. **响应分解有效**：将扰动响应分解为系统性、扰动特异性和群体变异三部分，可防止共享系统变异掩盖扰动特异信号，显著提升 C-DEGs 和 PDS 等指标。
2. **高斯原型可逆网络能充分建模群体异质性**：条件性组合共享高斯原型并映射为条件变异分布，优于仅依赖确定性响应中心的方法（w/o GM 除 C-DEGs 外全面下降）。
3. **预训练嵌入对未见扰动至关重要**：移除基于 embedding 的扰动效应后，C-DEGs 明显下降，验证了 scGPT 基因表示对推断未见目标效应的价值。
4. **可解释性：**
   - 去除系统性成分后，响应表示在 UMAP 中形成更紧凑、更可分离的扰动簇（如 Replogle 纯度从 0.308 提升至 0.769）；
   - 原型权重差异与扰动间残差分布的距离显著正相关（ρ≈0.46–0.51，p<0.001），说明自适应原型组合确实编码了条件特异性群体结构。
5. **综合性能**：在四个数据集上，DeMixPert 在扰动特异性恢复和分布保真度方面整体优于 GEARS、scGPT、GenePert、scDFM、STATE。

## 7. 优点

- **创新性分解框架**：首次在单细胞扰动预测中显式分离系统性响应、扰动特异响应和群体变异，避免各类信号相互干扰，提升了可迁移性和可解释性。
- **高斯原型可逆网络的独特设计**：既有全局共享的统计结构，又通过条件权重实现每个细胞/扰动自适应的混合分布；可逆性保证训练和采样的一致性，并能通过 NLL 直接监督。
- **利用预训练基础模型**：通过 scGPT 嵌入赋予未见过目标基因间的生物学先验知识，增强 OOD 泛化能力。
- **多损失联合训练**：响应对齐、分布似然、表达重建、能量距离匹配共同作用，兼顾了表达量恢复和群体分布保真。
- **可解释性验证完善**：提供了分解有效性的直接证据（聚类纯度提升）及原型权重的生物学一致性（Mantel 检验）。
- **实验设计规范**：条件不重叠划分、五种子重复、统一评估代码，结果可靠性较高。
