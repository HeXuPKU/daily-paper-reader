## 摘要
CASCADE是一个代理式框架，通过MCP暴露的预计算ARACNe调控网络，预测基因扰动的下游转录效应。先前的工作通过检查预测的基因是否为已知癌症基因（成员资格）来验证此类工具；我们则测试预测的变化方向是否与现实一致，使用焦点基因拷贝数扩增作为敲低逆过程的剂量代理，并基于真实的TCGA患者肿瘤数据进行验证。对于MYC，CASCADE预测的敲低靶标在三种癌症类型（BRCA：90.0%，COAD：72.0%，STAD：85.7%；所有p<0.0013）中与真实的扩增与非扩增肿瘤表达高度一致，远高于置换基线，经PAM50亚型对照后仍显著，并在独立队列（METABRIC，87.2%）中重复。与经过筛选的MSigDB基因集基线通过Fisher精确检验进行比较，CASCADE的准确性并未显示出超过现有MYC或E2F驱动生物学公共知识，但其基因特异性方向判定明显优于朴素均匀猜测。扩展到另外十五个基因后，验证证明是基因特异性的而非普适性的：增殖机制调节因子大多可重复，而谱系身份转录因子和一个细胞周期蛋白D旁系同源物（CCND2）持续失败，我们将这一模式作为带对冲的事后假说进行讨论。我们另外评估了基于LLM的代理是否能正确地将自然语言请求落实到CASCADE的真实MCP工具调用中。在35个查询中，一个有记录可查的本地模型达到71.4%的精确匹配（较大模型为85.7%）；模式和基因别名失败可通过规模或服务器端修正解决，但两个模型在模糊查询上都自信地默认为错误的扰动类型，这一失败无法通过有针对性的修复解决，因为其触发条件永远不会出现。

## Abstract
CASCADE is an agentic framework that predicts downstream transcriptional effects of gene perturbation from precomputed   ARACNe regulatory networks, exposed via MCP. Prior work validates such tools by checking whether predicted genes are   known cancer genes (membership); we instead test whether the predicted direction of change matches reality, using   focal-gene copy-number amplification as a dosage-based proxy for the inverse of knockdown against real TCGA patient   tumor data.   For MYC, CASCADE's predicted knockdown targets show strong concordance with real amplified-vs-non-amplified tumor   expression across three cancer types (BRCA: 90.0%, COAD: 72.0%, STAD: 85.7%; all p<0.0013), well above permutation   baselines, surviving a PAM50 subtype control and replicating in an independent cohort (METABRIC, 87.2%). Compared   against curated MSigDB gene-set baselines via Fisher's exact test, CASCADE's accuracy is not shown to exceed existing   public knowledge of MYC- or E2F-driven biology, though its gene-specific direction-calling clearly outperforms a naive   uniform guess.   Extending to fifteen additional genes, validation proves gene-specific rather than universal: proliferation-machinery   regulators mostly replicate, while lineage-identity transcription factors and one cyclin-D paralog (CCND2)   consistently fail, a pattern we discuss as a hedged, post-hoc hypothesis.   We separately benchmark whether an LLM-based agent correctly grounds natural-language requests into CASCADE's real MCP   tool calls. Across 35 queries, a documented local model reaches 71.4% exact match (85.7% for a larger model); schema   and gene-alias failures are resolved by scale or server-side correction, but both models confidently default to the   wrong perturbation type on ambiguous queries, a failure a targeted fix could not resolve because its trigger condition   never occurs.

## 论文核心问题与整体含义

- **研究背景**：预测基因扰动的下游转录效应是癌症系统生物学的核心任务。现有基于预计算调控网络的工具（如 RegNetAgents）在验证时通常采用**成员资格验证**——只检查预测出的基因是否恰好是已知癌基因，而**不检验预测的方向性声明**（该基因上调还是下调）是否符合真实疾病状态。
- **核心问题**：当 CASCADE 这类工具通过 MCP 协议暴露给 LLM 智能体时，智能体会把工具的输出转述给用户，因此工具本身携带的验证缺陷会被直接继承。若只用"基因是否为已知癌基因"这种成员级验证，无法回答"预测的方向是否真实成立"这一具体声明。
- **本文含义**：提出一种**不依赖注释的、以真实患者数据直接检验方向性预测**的验证方法论，并检验了 CASCADE 框架的预测可信度，同时评估了 LLM 智能体将自然语言正确落地为工具调用的能力。

## 方法论

### 核心思想
以焦点基因的**拷贝数扩增（GISTIC = 2）作为基因剂量增加的代理**，将其视为"敲低"的逆方向，随后检验 CASCADE 预测的下游靶标表达方向是否与真实患者中扩增与非扩增样本的表达差异一致。

### 关键技术细节
- **CASCADE 架构**：LangGraph 编排的工作流 + MCP 服务器；所有实验直接调用 `CascadeWorkflow.run()`（`analysis_depth="focused"`，`top_k=50`），仅提取 `perturbation_effects` 字段用于统计检验。
- **传播算法**：在 ARACNe 有向网络上做确定性广度优先传播——敲低时焦点基因初始效应为 −1.0，每跳将父节点效应乘以边权重及衰减因子 0.5，沿路径累加；边权由 ARACNe 互信息量大小经作用模式（激活/抑制）符号化决定。默认深度为 2 跳。
- **嵌入融合**：网络信号与 GREmLN 嵌入余弦相似度按权重 α = 0.7 混合；网络信号占主导，嵌入只调幅度、可新增候选基因，但不翻转已达基因的方向。
- **方向一致性判定**：预测敲低后下调（即被焦点基因正调控）的基因，若在扩增样本中均表达更高则记为一致；预测上调的基因则反之。
- **统计检验**：单尾二项检验（零假设：一致率 = 50%）+ 1,000 次置换检验（从 200 个背景网络基因中抽样，排除焦点基因和真实预测集基因，按真实预测的上下调比例随机赋方向标签）。置换基线均落在理论随机水平（约 50%）附近，确认结果非基因集结构造成的假象。

## 实验设计

- **数据集**：
  - TCGA PanCancer Atlas 2018（BRCA、COAD、STAD 三种癌症类型），GISTIC2.0 拷贝数调用，经 cBioPortal REST API 获取（GRCh38/GDC 流程）。
  - **METABRIC**（2,509 例乳腺癌，microarray）作为完全独立的复制队列，与 TCGA 无数据来源重叠。
  - ARACNe 网络来自 Bioconductor `aracne.networks`（2015 年 TCGA RNA-seq 数据构建，14 种癌症类型）。
  - PAM50 亚型注释用于亚型混杂控制。
- **基准/对照**：
  - **置换基线**（1000 次，检验是否高于随机水平）。
  - **MSigDB 精选基因集基线**：MYC TARGETS V1（三种癌症类型）与 E2F TARGETS（仅 BRCA），用 Fisher 精确检验与 CASCADE 对比。
  - **消融对照**：将所有预测方向强制改为"下调"，检验方向判定本身是否起作用（一致性下降 14–29 个百分点）。
- **LLM 工具调用基准**：35 条手工标注查询 × 7 类（基线 TCGA、基线免疫细胞、基因别名、非正式癌症名、非规范扰动措辞、隐式参数、多实体干扰），对比 `llama3.1:8b`（CASCADE 文档默认本地模型）与 `qwen2.5:72b`（更大的对比模型）。
- **基因面板**：MYC 之外另测 15 个基因（E2F3、CCND1、CCND2、CCND3、AURKA、CCNE1、MDM2、FOXM1、TOP2A、RPS6KB1、ERBB2、SOX9、FOXA1、GATA3、ESR1），共 27 个基因-癌症类型组合。

## 资源与算力

- 论文**未明确说明**任何 GPU 型号、数量或训练时长。LLM 推理通过本地 Ollama 服务器完成（`llama3.1:8b` 与 `qwen2.5:72b`），未涉及大规模模型训练。

## 实验数量与充分性

- **分组实验概况**：
  - MYC 主实验：3 种癌症类型（BRCA/COAD/STAD）+ PAM50 LumB 亚型对照 + METABRIC 独立队列复制 + 面板大小敏感性检验（N=25/50/100）。
  - 15 个额外基因 × 多个癌症类型 = 27 个组合（含跨癌种扩展）。
  - 与 MSigDB 基线的 4 组 Fisher 精确检验比较。
  - LLM 工具调用：35 条查询 × 2 个模型 × 原始输出/服务器解析后两种计分方式。
- **充分性评价**：实验设计总体**透明且较充分**——作者披露了基因进入面板的三种途径（盲筛、系统筛查、特意选择来证伪假设的 ESR1），未隐藏失败结果；置换检验、亚型对照、独立队列复制、方向消融构成了较完整的验证链条。但 LLM 基准仅覆盖 35 查询 × 2 个本地模型，规模偏小，作者自己也承认这属于"刻画失败模式"而非精确的泛化准确率估计；与 CellOracle 等邻近方法的头对头比较未展开。

## 主要结论与发现

1. **MYC 预测方向显著且稳健地一致**：BRCA 90.0%（p < 10⁻⁸）、COAD 72.0%（p = 0.0013）、STAD 85.7%（p < 0.0001），置换 p 均为 0.0000；PAM50 LumB 亚型内 92.0%；METABRIC 独立队列 87.2%（p < 10⁻⁶）。BRCA 中一致性最高的靶标多为核糖体生物发生相关基因（NOP14、RIOK1、WDR43、KAT2A 等），与 MYC 已确立的转录程序吻合。
2. **与精选基因集基线相比无显著差异**：CASCADE 与 MSigDB 的 MYC/E2F 靶标基因集差 1–4 个百分点，Fisher 精确检验均不显著（p = 0.34–0.86；BH-FDR q = 0.767–0.863）——CASCADE 的准确率**未显示出超越已有公共知识**，但也未显示落后。
3. **方向判定本身起实质作用**：强制统一预测方向使一致性下降 14–29 个百分点；且"上调"预测子集本身正确率 76.5–92.3%，排除少数上调调用仅为噪声的可能。
4. **验证是基因特异的，而非普适的**：9/10 增殖机制基因至少在一种癌症类型中验证成功；谱系身份转录因子（SOX9、FOXA1、GATA3、ESR1）全部失败；CCND2 与其旁系同源物 CCND1/CCND3 形成最尖锐的对照——同一分子功能、同一癌症类型，却唯一在所有测试中失败。基因类别不能单独预测结果，癌症类型背景同样关键（如 ERBB2 在 BRCA/COAD 反一致但 STAD 一致）。
5. **LLM 工具调用基础能力**：`llama3.1:8b` 原始输出精确匹配 71.4%，`qwen2.5:72b` 85.7%；服务器端别名解析后分别升至 77.1% 和 94.3%。第三种失败模式——在模糊查询上自信地默认错误的扰动类型——两个模型都有，且针对"字段缺失"设计的修复无法生效，因为模型从不留空字段。

## 优点

- **验证范式创新**：将验证从"预测的基因是否为已知癌基因"推进到"预测的方向是否在真实患者数据中成立"，直接检验工具经 agent 传递给用户的具体声明。
- **方法严谨性**：置换检验排除了基因集结构假象；PAM50 亚型对照排除了亚型组成混淆；METABRIC 独立队列排除了共享数据来源的伪重复。
- **负面结果透明披露**：CCND2 失败、ERBB2 跨癌种不一致、与 MSigDB 无显著差异、LLM 歧义失败等问题全部如实报告，且对基因选择的来源做了完整披露。
- **对 LLM 工具调用问题的诊断细致**：区分了模型原始输出与服务器端解析后的真实行为，区分了"可修复的架构失败"与"置信地猜错"这一更根本的问题，并指出了针对性修复无效的机制性原因。

## 不足与局限

- **群体平均网络的局限**：TCGA ARACNe 网络是癌种级群体平均，不反映肿瘤亚克隆异质性或单患者调控状态。
- **剂量代理的间接性**：拷贝数扩增不是直接实验扰动，拷贝数-活性关系并非对所有基因都线性；对 GATA3 这类以点突变驱动为主的基因可能根本不适用。
- **泛化面板规模有限**：15 个基因、27 个组合小于部分基准研究；强扩增驱动的基因本身稀缺，限制了可测基因数量；LINCS L1000 shRNA 直接实验因靶标覆盖不足（每基因仅 2–5 个基因在 978 基因面板上）而无法进行。
- **基线比较不充分**：仅测试了两个 MSigDB 基因集、E2F 仅在 BRCA 中测试，无法全面刻画 CASCADE 相对公共知识的表现；与 CellOracle 等结构最接近的方法未做头对头比较。
- **事后假设风险**：增殖机制/谱系身份的分裂是事后形成的对冲假设，作者明确承认并非预先注册；虽然 ESR1 是特意选来证伪的基因，但整体模式仍需独立验证。
- **LLM 基准的边界**：35 条查询规模小、未测专有前沿模型、单轮工具调用而非多轮行为评估；基因别名表只覆盖固定的小集合，服务器解析后的高准确率不应被解读为对表外别名的泛化。
- **模糊扰动类型问题未解决**：即使用更大模型或针对性服务器端修复，该失败模式依然存在——模型总是"自信地给出一个猜测"而非"表示不确定"，需要未来工作的新机制（如验证所给值与查询文本的支撑关系）。
