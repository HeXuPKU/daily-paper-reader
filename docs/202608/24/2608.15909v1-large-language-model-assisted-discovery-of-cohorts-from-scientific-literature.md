## 摘要
背景：规划多研究分析需要识别具有相关参与者、表型和数据模态的队列。这一过程通常依赖于先验知识、队列目录和手动文献检索。我们开发了一种互补的、由问题驱动的框架，该框架搜索相关科学文献并提取明确的队列名称。方法：该框架首先从可配置的词汇表和模板中生成多个PubMed查询，并通过PubMed API自动检索所得科学文献。然后，大型语言模型筛选检索到的标题和摘要，并使用针对研究问题定制的提示提取明确的队列名称。提取的名称经人工审核后去重。可配置代码、提示和示例输出可在 https://gitlab.rz.uni-frankfurt.de/cap_molgenlab/literature-cohort-discovery 获取。评估：作为用例，我们将该框架应用于青少年攻击行为遗传学。从5,400个生成的PubMed查询中，该框架检索到5,254条唯一记录，并识别出188个候选队列。使用预定义标准（包括参与者年龄和遗传数据可用性）进行手动筛选，保留了44个符合条件的队列。基于LLM的自动名称提取与人工标注者的一致性范围相符。我们还使用相同的研究问题检索了四个已建立的队列目录。其合并结果包含44个符合条件的队列中的27个，而17个未被任何队列目录检索返回。结论：该框架通过大规模自动文献检索，将研究问题特定的词汇转换为可筛选的队列清单。它可以适应不同的人群、表型、数据模态和研究设计，并为基础队列目录提供基于文献的补充。

## Abstract
Background: Planning multi-study analyses requires identifying cohorts with the relevant participants, phenotypes, and data modalities. This process commonly relies on prior knowledge, cohort catalogues, and manual literature searches. We developed a complementary question-driven framework that searches relevant scientific literature and extracts explicit cohort names. Methods: The framework first generates multiple PubMed queries from configurable vocabularies and templates and retrieves the resulting scientific literature automatically through the PubMed API. A large language model then screens the retrieved titles and abstracts and extracts explicit cohort names using a prompt tailored to the research question. The extracted names are deduplicated with human review. Configurable code, prompts, and example outputs are available at https://gitlab.rz.uni-frankfurt.de/cap_molgenlab/literature-cohort-discovery. Evaluation: As a use case, we applied the framework to youth aggression genetics. From 5,400 generated PubMed queries, the framework retrieved 5,254 unique records and identified 188 candidate cohorts. Manual screening using predefined criteria, including participant age and genetic-data availability, retained 44 eligible cohorts. Automated LLM-based name extraction was within the agreement range of human annotators. We also searched four established cohort catalogues using the same research question. Their combined results contained 27 of the 44 eligible cohorts, while 17 were not returned by any cohort catalogue search. Conclusion: The framework converts research-question-specific vocabulary into screenable cohort inventories via a large, automated literature search. It can be adapted across populations, phenotypes, data modalities, and study designs, and provides a literature-based complement to curated cohort catalogues.

## 1. 核心问题与整体含义
- **研究动机**：在人群数据科学中，重用与联合分析已有数据日益重要，而发现符合特定研究问题的队列是第一步。传统方法依赖研究者先验知识、同事推荐或手动文献检索，存在偏向知名队列、结果难以审计与复现等问题。
- **现有资源局限**：已有一些队列/数据目录（如 Maelstrom、Atlas、CatMH、dbGaP），但各目录覆盖范围、术语和检索方式不一致，且是围绕数据资源而非具体研究问题组织的；即使引入 LLM 优化目录内的数据集发现，仍受限于目录已收录的资源。
- **本文解决的问题**：提出一种**问题驱动的、可配置的 LLM 辅助队列发现框架**，直接从科学文献中检索并提取显式命名的队列，无需预定义队列列表，从而与策展目录形成互补。
- **整体含义**：将大规模自动文献检索与大语言模型信息抽取结合，把研究问题转化为可筛选的队列清单，有望降低跨研究分析中队列发现的偏差与工作量，并支持未来目录的完善。

## 2. 方法论
- **核心思想**：通过可配置的概念词汇表和查询模板将研究问题转化为 PubMed 检索式，自动检索文献；再用 LLM 对标题/摘要进行分类和显式队列名提取；最后通过字符串匹配和人工审核完成别名消解。
- **三个主要阶段**：
  1. **问题相关文献检索**：基于人口、领域、表型、数据模态、研究设计等可配置词汇，生成两类查询模板：
     - 宽松模板：`population AND (domain OR phenotype) AND modality`
     - 严格模板：`population AND domain AND phenotype AND modality AND study-design`
     - 每个查询取 PubMed 排名前 50 条标题/摘要，按 PMID 去重。
  2. **LLM 辅助队列名提取**：
     - 使用 OpenAI GPT-4o（快照 gpt-4o-2024-08-06），固定提示词 + 结构化 JSON 输出格式。
     - 模型先判断记录为 INCLUDE 或 DISCARD，再提取显式数据库/研究/队列名。
     - 仅将标题和摘要提交给模型，不涉及全文或个体数据。
     - 提取重复执行 3 次，取并集以减少随机波动。
  3. **别名与身份消解**：
     - 使用 Python `difflib` 字符串相似度（阈值 0.8）聚类相似名称。
     - 人工审核每一聚类，为真实队列分配规范标签，移除诊断工具等非队列实体。
     - 最终输出“规范标签—名称变体—PMID”映射表。
- **关键设计选择**：LLM 只负责候选名称提取，最终纳入资格判定仍由人工完成，保证独立验证性。

## 3. 实验设计
- **案例场景**：青少年攻击行为遗传学中的队列发现（用于遗传分析需要大样本跨队列数据）。

## 6. 主要结论与发现
- 框架能够以低成本将大规模文献语料转化为可筛选的队列清单：从 5,254 条记录中产出 188 候选队列，最终 44 个符合条件的队列，总样本量约 89 万人。

- 两次独立 LLM 运行的 Jaccard 相似系数为 0.85，表明提取流程在记录层面的可重复性较好。
- 与四个目录比较：目录合并结果包含 44 个合格队列中的 27 个（61.4%），但 **17 个合格队列未被任何目录检索到**；目录本身高度碎片化，93.7% 的记录只出现在单一目录。
- 结论：文献挖掘与策展目录是互补的队列发现渠道；该框架还可用于为目录补充候选队列。

## 8. 不足与局限
- **单一应用领域**：仅在青少年攻击行为遗传学中验证，其他人群、表型、数据模态下的表现尚不明确。
- **文献来源受限**：只依赖 PubMed，若队列主要记录在其他学科数据库或以全文而非标题/摘要呈现，可能被遗漏。
- **依赖显式命名**：文献中未明确写出队列名或使用缩写/嵌套子研究时，提取可能失败；LLM 的保守判定也导致召回率有限。
- **目录比较的公平性存疑**：不同目录平台的功能和元数据结构差异大，需定制不同检索策略；目录检索与文献检索存在时间差，可能因目录内容更新而影响重叠统计。
- **人工审核仍是瓶颈**：虽然 LLM 减少了初级筛选量，但最终资格评估仍需要约 400 小时人工时间，对于更大规模研究可能依然耗费人力。
- **模型时效性**：使用的是 GPT-4o 早期快照，虽然文中预期更现代模型会带来改进，但未进行实际比较验证。
