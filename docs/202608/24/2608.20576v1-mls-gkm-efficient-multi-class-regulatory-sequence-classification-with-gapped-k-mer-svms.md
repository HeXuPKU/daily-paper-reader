## 摘要
间隙k-mer支持向量机（gkm-SVMs）广泛用于调控DNA序列分类以及识别这些预测背后的序列特征。尽管LS-GKM提供了基于gkm核的高效实现，但它仅限于二分类，且不提供校准的概率输出。在此，我们提出mLS-GKM，它是LS-GKM的扩展，增加了多类分类、概率校准预测、并行化推理、内存高效的序列解释以及训练过程中的检查点功能。在322个ENCODE ChIP-seq数据集上，使用mLS-GKM训练的分类器与LS-GKM产生的分类器相同，而gkmpredict和gkmexplain在64线程下分别快22倍和80倍，gkmexplain的峰值内存减少超过65%。作为实际演示，mLS-GKM能够直接从序列中准确区分增强子、启动子和CTCF结合位点，并识别出生物学相关的调控基序。总之，这些改进将gkm-SVMs扩展到多类问题，并显著提高了其可扩展性，使大型复杂数据集中的调控DNA序列能够被高效解释。

## Abstract
Gapped k-mer support vector machines (gkm-SVMs) are widely used for classifying regulatory DNA sequences and identifying the sequence features underlying those predictions. Although LS-GKM provides an efficient implementation of gkm-based kernels, it is restricted to binary classification and does not provide calibrated probability outputs. Here, we present mLS-GKM, an extension of LS-GKM that adds multiclass classification, probability-calibrated predictions, parallelised inference, memory efficient sequence interpretation and checkpointing during training. Across 322 ENCODE ChIP-seq datasets, classifiers trained using mLS-GKM are identical to those produced by LS-GKM, while gkmpredict and gkmexplain run 22x and 80x faster respectively at 64 threads, and gkmexplain peak memory is reduced by more than 65%. As a practical demonstration, mLS-GKM was able to accurately distinguish between enhancers, promoters and CTCF binding sites directly from sequence and identified biologically relevant regulatory motifs. Together, these improvements extend gkm-SVMs to multiclass problems and substantially improve their scalability, enabling efficient interpretation of regulatory DNA sequences in large and complex datasets
