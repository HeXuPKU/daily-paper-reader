## 摘要
电子健康记录（EHR）被广泛用于使用机器学习的临床风险预测。国际疾病分类（ICD）编码提供了关于患者诊断的结构化信息，但有效地表示它们仍然具有挑战性。现有方法常常面临预测性能与可解释性之间的权衡：基于分组的表示是可解释的，但可能丢失信息，而基于嵌入的表示实现了强大的预测性能，但难以解释。我们提出了多种ICD编码的可解释表示（xMICD），一种从ICD编码集合构建低维患者表示的方法。xMICD将临床上有意义的诊断分组与预训练的ICD嵌入空间中的相似性相结合。该方法不是使用二元组别成员资格，而是通过基于相似性的相对分配将编码分配到组中，产生反映患者诊断与每个临床组对齐程度的特征。在大规模EHR数据集上的实验表明，xMICD在多个临床预测任务中实现了与基于嵌入的表示（如ICD2Vec）相当的预测性能。同时，所得特征在临床上仍然可解释，因为每个维度对应于一个可识别的诊断组。因此，xMICD为将基于嵌入的语义关系整合到机器学习模型的可解释临床特征空间中提供了一种实用方法。

## Abstract
Electronic Health Records (EHRs) are widely used for clinical risk prediction using machine learning. International Classification of Diseases (ICD) codes provide structured information about patient diagnoses, but representing them effectively remains challenging. Existing approaches often face a trade-off between predictive performance and interpretability: grouping-based representations are interpretable but may lose information, while embedding-based representations achieve strong predictive performance but are difficult to interpret. We propose Explainable Representation of Multiple ICD Codes (xMICD), a method for constructing low-dimensional patient representations from sets of ICD codes. xMICD combines clinically meaningful diagnostic groupings with similarity in a pre-trained ICD embedding space. Instead of using binary group membership, the method assigns codes to groups via similarity-based relative assignments, yielding features that reflect how closely a patient's diagnoses align with each clinical group. Experiments on large-scale EHR datasets demonstrate that xMICD achieves predictive performance comparable to embedding-based representations such as ICD2Vec across multiple clinical prediction tasks. At the same time, the resulting features remain clinically interpretable because each dimension corresponds to a recognizable diagnostic group. xMICD therefore provides a practical way to integrate embedding-based semantic relationships into interpretable clinical feature spaces for machine learning models.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **问题背景**：电子健康记录（EHR）中，ICD编码是患者诊断的结构化摘要，广泛用于临床风险预测和决策支持。但ICD编码数量庞大（ICD-10-CM约70,000个代码），直接做one-hot编码会导致高维、稀疏的特征空间，增加模型复杂度并损害泛化性能。
- **核心矛盾**：现有ICD编码表示方法存在“可解释性”与“预测性能”之间的权衡：
  - **基于分组的表示**（如ICD章节/块、CCI、ECI、CCSR）：维度低、临床可解释，但将组内所有编码视为等价，丢失细粒度信息，预测性能往往有限。
  - **基于嵌入的表示**（如Med2Vec、ICD2Vec、BEHRT）：预测性能强，能捕捉代码间的语义关系，但学习的潜在维度抽象、缺乏临床含义，难以被临床医生理解。
- **核心观点**：在医疗等高利害场景中，可解释性不仅取决于模型本身，还取决于输入特征是否具有临床意义。即使线性模型，若特征缺乏清晰含义也难以解释。因此，设计“既信息丰富又临床可解释”的ICD表示至关重要。
- **研究目标**：提出xMICD方法，**在不显著牺牲预测性能的前提下，构建每个维度都对应临床可识别诊断组的低维可解释患者表示**，弥合两类方法之间的鸿沟。

## 2. 论文提出的方法论

**核心思想**：将预训练ICD嵌入的语义相似性与临床定义的分组结构相结合，用**基于相似性的相对分配**替代传统的二元组成员关系，使每个特征维度反映患者的诊断与某一临床参考组的“关联强度”。

**方法框架（xMICD）**：

1. **输入**：一次就诊（visit）关联的ICD编码集合 {C₁, C₂, ..., Cₙ}，及m个临床意义的锚点组（anchors）。

2. **相似度计算**：对每个编码Cᵢ和每个锚点Aⱼ，计算相似度 sᵢⱼ = Sim(Cᵢ, Aⱼ)。相似度函数可选：
   - **编码级相似度**：基于ICD本体层级结构的语义相似度（如Wu–Palmer、Leacock–Chodorow）。
   - **嵌入级相似度**：在预训练嵌入空间中用余弦相似度（本文主要采用ICD2Vec嵌入）。

3. **行内归一化**：对每个编码Cᵢ，在所有锚点之间做**min–max缩放**：
   s′ᵢⱼ = (sᵢⱼ − minⱼ sᵢⱼ) / (maxⱼ sᵢⱼ − minⱼ sᵢⱼ)
   
   使得与Cᵢ最相似的锚点映射为1，最不相似的映射为0，其余锚点取0到1间的值。归一化强调每个编码内部锚点的“相对主导性”，而非绝对几何距离。

4. **跨编码聚合**：对每个锚点Aⱼ，取所有编码中归一化相似度的最大值：
   Sⱼ = maxᵢ s′ᵢⱼ
   
   最终向量 S = (S₁, ..., Sₘ) 即xMICD表示。Sⱼ=1表示该锚点至少对一个编码是排名最高的锚点；Sⱼ<1表示该锚点在所有编码中都被其他锚点超越。该方法编码的是“锚点在编码集合中的上下文主导性”，而非全局相似度。

5. **锚点选择策略**：
   - **临床定义锚点**：从ECI组、ICD-10-CM Blocks、CCSR类别等临床分组中选取；组内多个编码时选嵌入空间中最中心的代码（与组内其他代码平均相似度最高的代码）作为锚点。
   - **数据驱动锚点**：最远点采样（FPS）覆盖嵌入空间，或聚类取medoids。

**定位**：xMICD介于二元分组表示与密集嵌入表示之间——比分组方法保留更多分级语义关系，比嵌入方法每个维度都有明确的临床锚点，增强了特征级透明度。

## 3. 实验设计

**数据集**：
- **MIMIC-IV-ED**（急诊数据集）：448,972次急诊就诊，预处理后418,490次。特征包括当前急诊诊断及前五年住院诊断，拼接后维度翻倍。
- **eICU-CRD**（多中心ICU数据集）：所有ICD-9-CM映射到ICD-10-CM。特征仅用当前ICU住院诊断。医院级别划分训练/测试集，实现跨机构外部验证。

**预测任务（Benchmark）**：
- MIMIC-IV-ED：Critical Outcome（危重结局预测）、Hospitalization（住院需求）、Revisit in 72h（72小时再就诊）。
- eICU-CRD：ICU内死亡率（in-ICU mortality）、延长住院（Prolonged Stay，>3天）。

**基线方法**：
- Raw ICD（one-hot编码原始特征）
- 分组二元表示：ECI（31/62维）、ICD-10-CM Blocks（209/418维）、CCSR（553/1106维）
- 嵌入表示：ICD2Vec平均（1024/2048维）

**xMICD变体**：基于ICD2Vec嵌入+余弦相似度，锚点策略包括ECI medoids、Blocks medoids、CCSR medoids、FPS（209维与553维）。

**预测模型**：XGBoost和多层感知器（MLP，Adam优化器）。

**评估指标**：AUROC，200次bootstrap重采样估计置信区间。

**相似性保持评估**：计算各表示下患者间余弦相似度矩阵，用Spearman秩相关衡量不同表示间患者相似性结构的一致性。

**可解释性评估**：采用定性框架（Readable、Understandable、Meaningful、Trackable、Simulatable五个属性，三档评级），并分析全局SHAP值。

- **预测性能**：除xMICD-ECI（仅31维，信息量不足）外，xMICD各变体在几乎所有任务和模型上达到与ICD2Vec相当的预测性能。XGBoost下xMICD偶尔略超ICD2Vec；MLP下ICD2Vec略优，但差异普遍较小。

- **相似性保持**：xMICD变体与ICD2Vec的患者相似性结构高度一致（最高为xMICD-FPS，Spearman ρ=0.7961），远高于二元分组特征（0.21–0.33）。这解释了xMICD为何能在保持可解释结构的同时保留大部分预测能力。
- **可解释性优势**：xMICD每个维度对应可识别的临床诊断组；SHAP分析显示，xMICD-CCSR保留了与CCSR一致的疾病组重要性排序（如呼吸衰竭、脓毒症、肾衰竭），同时能将Z66（Do Not Resuscitate）等罕见编码与危重锚点关联，揭示潜在的临床表型——这种“表型发现”能力是Raw ICD等稀疏表示难以实现的。
- **核心论断**：高可解释性不一定需要牺牲预测性能。xMICD可视为ICD2Vec嵌入在临床可解释分组上的“结构化投影”。

## 8. 不足与局限

- **依赖预训练嵌入**：xMICD的性能上限受限于底层嵌入模型（ICD2Vec）的质量；嵌入的偏差或噪声会被传播到最终特征中。同时，因依赖预训练模型，无法仅从原始ICD编码完全复现特征（Simulatable仅为部分满足）。
- **特征含义存在歧义风险**：xMICD维度值反映的是“语义相似度”而非真实的组成员关系。高值不意味着患者直接患有该组疾病，可能引起过度解读或错误临床结论，需要谨慎解释。
