## 摘要
全基因组关联研究可识别与性状相关的基因组变异。使用全基因组关系矩阵的混合线性模型关联（MLMA）方法（如 GCTA 中实现的那些）功能强大，但计算成本高昂。在此，我们消除了 GCTA 中关键的内存和 CPU 瓶颈，将 REML 内存使用量减少近 75%，并在生物样本库规模队列中大幅加速 MLMA 达数个数量级，同时保持精确性。我们进一步通过降秩 Woodbury 矩阵方法利用映射队列中的亲缘关系，在控制基因组膨胀的同时，带来进一步的数个数量级性能提升。原生即时显性重编码也消除了对中间文件的缓慢 I/O 操作，从而能够在大型农业队列中高效进行加性和显性 MLMA 分析。

## Abstract
Genome-wide association studies identify genomic variants associated with traits. Mixed linear model association (MLMA) methods using a whole-genome relationship matrix, such as those implemented in GCTA, are powerful but computationally expensive. Here, we remove key memory and CPU bottlenecks in GCTA, reducing REML memory usage by nearly 75% and substantially accelerating MLMA by orders of magnitude in biobank-scale cohorts while preserving exactness. We further exploit relatedness in the mapping cohort through a reduced-rank Woodbury matrix approach, delivering further orders of magnitude performance gains with controlled genomic inflation. Native on-the-fly dominance recoding also eliminates slow I/O-operations on intermediate files, enabling efficient additive and dominance MLMA analyses in large agricultural cohorts.

- **背景**：GWAS 中混合线性模型关联（MLMA）通过全基因组关系矩阵（GRM）控制群体分层与个体亲缘关系造成的假阳性，GCTA 是其中最流行的工具之一，但计算成本极高，难以扩展到几十万个体、数百万标记的队列。
- **关键矛盾**：BOLT-LMM、GCTA-fastGWA、REGENIE 等依赖“稀疏 GRM”假设（个体间亲缘度可忽略）而具备可扩展性；但**农业群体因有效群体规模小、强人工选择、少数精英种畜广泛使用，GRM 呈“稠密”结构**，稀疏假设失效并导致检验统计量膨胀（假阳性升高）。因此农业 GWAS 亟需兼顾稠密亲缘结构与生物样本库规模的方法。
- **现有替代方案的不足**：样本切分＋meta 分析（信息有损、流程复杂）；固定方差项建模（大效应 SNP 下不稳健）；随机 REML（如 SLEMM，可能不收敛）；APY 等降秩方法（多用于 GBLUP 或方差组分估计，未完整替代全 GRM MLMA）。

- **整体含义**：论文通过“工程优化 + 可控近似 + 新功能”三层次改造 GCTA（GPL-3 合规，命名 GCTAg），使精确全 GRM GWAS 首次在六位数样本、千万级变异规模上可行，并原生支持显性 MLMA。

## 2. 方法论

### 2.1 核心思想
分三阶段推进：(i) 消除精确实现中的内存/CPU 瓶颈，**不改变数学结果**；(ii) 增强数值稳健性与功能（收敛判据、初始化、I/O、后端、显性重编码）；(iii) 引入两类**可控近似**（Hutch++ 迹估计、降秩 Woodbury 表示）以突破 O(n³) 时间与 O(n²) 内存限制。

### 2.2 精确实现优化
- **GRM 构建**：将硬编码的每批 128 个变异提高到 1024（CPU 与架构无关的最优值），使核心从内存受限转为计算受限，高核数下提升 30%+；仅填充矩阵单三角（对称性），峰值内存降约 35%（配合 jemalloc 并关闭透明大页 THP 才能在大规模下真正兑现）。
- **PCA 特征分解**：默认 `SelfAdjointEigenSolver` 走 DSYEV（QR 迭代），改用分治 DSYEVD 或 MRRR（DSYEVR，仅求前 k 个特征对）；并新增 **Lanczos**（精确）与 **rSVD**（幂迭代或 Nyström 近似）两种方法，前 4 个 PC 场景下 rSVD 比 MRRR 快 99%，前 10% PC 快 95%。
- **REML**：只填 V 的下三角；协变量校正改写为对称秩-c 更新，避免显式构造投影矩阵；主动释放/原地求解/交换大缓冲 → **峰值内存降低近 75%，运行时降低 33%**。
- **MLMA 变异扫描（最大瓶颈）**：将逐变异（BLAS-2、内存受限、难并行）改为**分块处理**（BLAS-3），使用全局变换后的表型与基因型，协变量校正只做一次；并采用**基因型流式读取**，峰值内存从 O(m) 降到 O(1)（N=150k、m=600k 全量解包需 90 GB，分块仅 1 GB）。**运行时降低近 99%，且统计量数学上精确**。
- **GRM 合并**：利用下三角一维二进制格式分块累加写出，内存恒定约 0.5 GB、4 核 15 分钟（对比 GCTA 615 GB、10 小时）。
- **I/O**：内存映射文件、连续内存分配、缓冲读写（字节级 I/O 的 CPU 周期从 1640 亿降至 130 亿）。

### 2.3 稳健性扩展
- **前向收敛判据**：由 `Δlog(ℒ) < 1e-4` 改为基于 AI 矩阵的 Newton 减量 `δ² = Uᵀ H_AI⁻¹ U < ε`；REML 迭代轮数约减半。
- **自适应阻尼**：上一步“可信”（实际增益/预测增益 ≳ 0.75）时取全步 ζ=1，否则 `ζ = min(1, (2δ²)⁻¹)`，避免固定常数阻尼。
- **HE 初始化**：用 Haseman–Elston 估计器暖启动方差组分（替代等分假设），跳过线性收敛的 EM 首轮；低遗传力性状（Trait A）REML 轮数减少近 60%，但复杂遗传结构（含上位性的 Trait B）HE 失败并回退。
- **分块 GRM 构建**：给定内存预算动态计算可容纳的 GRM 行数，单次调用完成；N=75k 时用 90% 更少内存、仅慢 26%。
- **对数显著性报告**：利用 `ln Q(a,x) ≈ −x + (a−1)ln x − ln Γ(a)`（x≫a）避免大样本下 p 值下溢，直接给出 −log₁₀(p)。
- **后端泛化**：支持任意 BLAS/LAPACK；Apple Accelerate 比 OpenBLAS 快 45% 且省 30% 内存；服务器上 AOCL（BLAS）＋MKL（LAPACK）组合最优，192 核下比 OpenBLAS 快约 70%、比 MKL 快约 92%。
- **Out-of-core GRM**：将 REML 中二次型 `R_j = yᵀPA_jPy` 按块累加（对角块计一次、上三角非对角块计两次），降低峰值内存但增加 I/O 压力，内存仍保持二次标度。

### 2.4 近似扩展
- **Hutch++ 迹估计**：用 s 个随机探针估计 `tr(PA_j)`，成本从 O(n³) 降至 O(sn²)，从不显式构造 P 或 V⁻¹；REML 运行时与内存分别降 67% 与 16%，MLMA 不受影响，相对基因组膨胀 < 0.1%（无偏但有轻微随机噪声）。
- **降秩 Woodbury 表示**：以 `G ≈ Q_kΛ_kQ_kᵀ` 代入 Woodbury 恒等式，`V⁻¹v = σ_eff⁻²(v − Q_k D_q Q_kᵀv)`，其中 `c_i = σ_g²λ_i/(1+σ_g²λ_i)`、`σ_eff² = σ_e² + σ_g²λ_tail`，并相应修正 `log|V|`；变异扫描改写为 `xᵀV⁻¹x = σ_eff⁻²(‖x‖² − ‖D_q^{1/2}Q_kᵀx‖²)`，无需构造完整逆。N=150k、k=10k 时 REML 运行时/内存降 95%/53%，MLMA 降 88%/85%，相对基因组膨胀约 3.5%。
- **秩 k 的数据驱动选择**：三种方法——MP（Marchenko–Pastur 随机矩阵边缘 `λ_c = (1+√(N/m))²`）、EIG（特征质量占比阈值 ρ）、VAR（截断尾部方差阈值 ξ）；配合 rSVD 逐轮倍增特征值数量。MP 便宜但显著低估 k（GRM 非随机矩阵且存在连锁不平衡）。
