## 摘要
电子健康记录（EHR）将临床病史编码为（时间、模态、编码）元组，而预训练语言模型期望的是文本词元。将其序列化为文本会膨胀序列长度，并冗余地编码结构信息。我们提出 EHRAdapt，一种将元组直接映射到冻结语言模型嵌入空间的适配器。模态获得可学习嵌入，时间间隔通过学习到的注意力偏置引入，事件编码则获得专用向量。学习事件向量是核心挑战：临床词汇呈长尾分布，导致罕见事件的观测过少，难以获得可靠估计。因此，EHRAdapt 将每个事件向量表示为语义先验与证据残差之和。该先验是来自在临床本体上训练的生物医学语言模型对事件临床描述的冻结嵌入，通过共享的可学习投影映射到模型的输入空间，因而即使在观测稀缺时也能提供临床语义。残差是学习到的低秩、事件特定的校正项，随着证据积累对其加以细化。我们在约 400 万患者的记录上进行继续预训练，使用三个冻结的 LLM 主干（OLMo2 1B、Llama3.2 1B 和 OLMo2 7B），仅训练适配器（占全部参数的 0.1--0.6%）。在留出的下一事件预测任务中，完整适配器在每个主干上均优于所有消融版本。移除语义通路对罕见事件的损害比最高频事件大十倍以上，而移除残差会损害整体预测，却改善了对最罕见事件的预测。在需上报传染病和综合征的下游分类任务上，EHRAdapt 优于基于文本的 LLM 和基于计数的基线，且两条通路均改善了罕见疾病判别。因此，这两条通路发挥互补作用，只有按事件频率细分结果而非取平均时才能显现。

## Abstract
Electronic health records (EHRs) encode clinical histories as (time, modality, code) tuples, whereas pretrained language models expect text tokens. Serializing them as text inflates sequence length and redundantly encodes structure. We introduce EHRAdapt, an adapter that maps tuples directly into a frozen language model's embedding space. Modality receives a learned embedding, time gaps enter through learned attention biases, and event codes receive dedicated vectors. Learning event vectors is the central challenge: clinical vocabularies are long-tailed, leaving rare events too few observations for reliable estimates. EHRAdapt therefore represents each event vector as the sum of a semantic prior and an evidence residual. The prior is a frozen embedding of the event's clinical description from a biomedical language model trained on clinical ontologies, mapped into the model's input space by a shared learned projection, so it supplies clinical meaning even when observations are scarce. The residual, a learned low-rank event-specific correction, refines it as evidence accumulates. We run continued pretraining on about 4 million patients' records with three frozen LLM backbones (OLMo2 1B, Llama3.2 1B, and OLMo2 7B), training only the adapter (0.1--0.6% of all parameters). The full adapter outperforms all ablations in held-out next-event prediction on every backbone. Removing the semantic pathway hurts rare events over ten times more than the most frequent ones, whereas removing the residual hurts overall prediction but improves it for the rarest events. On reportable infectious-disease and syndromic downstream classification tasks, EHRAdapt outperforms text-based LLM and count-based baselines, and both pathways improve rare-disease discrimination. The two pathways therefore play complementary roles, visible only when results are broken down by event frequency rather than averaged.

## 1. 核心问题与整体含义（研究动机与背景）

- **结构不匹配**：电子健康记录（EHR）以 `(时间, 模态, 编码)` 元组形式编码临床病史，而预训练语言模型（LLM）期望的是文本词元。将元组序列化为文本会膨胀序列长度，并反复冗余编码同一结构（事件类型、时间仅被隐式编码）。
- **长尾分布困境**：临床事件分布高度偏斜。在本文训练数据中，中位事件类型仅出现约 20 次，而最高频事件出现约 8760 万次（图 4）。约 50.1% 的事件类型出现次数 ≤20 次。
- **罕见事件的重要性与评估盲区**：罕见事件可能携带关键诊断信息（如监测类传染病），但模型从 EHR 数据中只能看到极少样本，难以独立估计可靠表示。同时，平均预测损失被高频事件主导，会掩盖对罕见事件的巨大影响。
- **整体含义**：论文提出 EHRAdapt，将结构化 EHR 元组直接映射进冻结 LLM 的嵌入空间，并通过“语义先验 + 证据残差”的分解，使罕见事件在观测稀缺时仍能借助外部临床知识获得有意义表示。研究强调必须按事件频率分层评估，才能看清各组件的作用。

## 2. 方法论

### 2.1 核心思想

- **适配器而非微调**：LLM 主干完全冻结，仅训练一个模型无关的适配器（占全部参数 0.1–0.6%），从而可低成本采纳更新的 LLM。
- **单 token 表示每个事件**：每个临床事件映射为单个向量，模态用可学习嵌入，时间间隔用学习到的注意力偏置，事件编码用专用向量。
- **两条互补通路**：事件向量 = 语义先验（来自生物医学语言模型的临床描述嵌入）+ 证据残差（从 EHR 轨迹中学习的低秩事件特定校正）。

### 2.2 关键技术细节与公式

- **问题设定**：患者历史为序列 `(c1,m1,t1),...,(cL,mL,tL)`，其中 `ci` 是词表 `V` 中的事件类型，`mi` 是模态，`ti` 是时间戳。继续预训练（CPT）目标为下一事件交叉熵（单位：nats）。

- **事件表示（式 1）**：
  - `ec = Psem(zc) + rc`，`rc = B ac`，`ac ∈ R^r`
  - `xi = eci + emod(mi)`
  - 其中 `zc ∈ R^{dsem}` 是事件临床描述的冻结 BioLORD 嵌入；`Psem ∈ R^{H×dsem}` 是共享可学习投影；`ac` 是事件特定低秩编码；`B ∈ R^{H×r}` 是共享投影；`emod(mi)` 是模态嵌入。

- **残差秩**：将 `ac` 堆叠为 `A ∈ R^{|V|×r}`，则残差表 `R = AB^T` 秩 ≤ r。参数量为 `(V+H)r`，远少于无约束表的 `VH`。H=2048 时，rank 64 约用 515 万残差参数，约为无约束表（1.61 亿）的 3.2%。

- **固定语义几何（对照）**：可将 `Psem = αQ` 固定，其中 `Q^T Q = I`、`α>0`，此时 `cos(αQzh, αQzl) = cos(zh, zl)`，完全保留 BioLORD 空间的角度与余弦近邻排序。学习 `Psem` 则放宽该约束，允许语义分量适配主干。

- **输出头与频率偏置（式 2）**：输出头与事件编码表 `E = [ec]` 绑定（tied）。
  - `logiti,c = s (hi · ec) + βc`，`s = exp(logit_scale)`
  - `βc` 初始化为训练集频率的 `log p(c)`；模态嵌入被刻意排除在输出表示之外。
  - 输入输出绑定使每个 `ac` 同时从两侧获得梯度：输入侧仅在事件出现时更新，输出侧全 softmax 在每个位置对每个事件都更新。

- **时间注意力偏置（式 3）**：对查询位置 `i` 和键位置 `j ≤ i`，`Δtij = ti - tj`：
  - `q_i^T k_j / √d_head + b^{(ℓ,h)}_{κ(Δtij)}`
  - `κ` 将时间差分配到 16 个桶（桶 0 专用于同时事件），偏置按层和注意力头学习，初始化为 0。灵感来自 T5 的分桶相对位置偏置，但用实际时间差替代词元距离。

### 2.3 算法流程

1. 冻结 BioLORD 编码每个事件临床描述，得到并缓存 `zc`（768 维，均值中心化）。
2. 共享可学习投影 `Psem` 将 `zc` 映射到主干隐藏维度，形成语义先验。
3. 事件特定低秩编码 `ac` 经共享投影 `B` 形成证据残差，与先验相加得到 `ec`。
4. 输入侧加上模态嵌入；时间差经分桶注意力偏置注入冻结 transformer。
5. 输出侧复用 `ec`（不含模态），加事件偏置 `βc` 与 logit 尺度 `s`，对全词表打分。
6. 最小化下一事件交叉熵，仅更新适配器参数。

## 3. 实验设计

- **继续预训练数据**：Kaiser Permanente Northern California（KPNC）EHR，约 400 万患者，2010–2018 年。含人口学及实验室、操作、药物、就诊类型、主诉、诊断编码、生命体征等纵向记录，**不含检验值、生命体征值和结局**。按患者确定性种子划分 98%/1%/1%（训练/验证/测试）。
- **序列构造**：患者轨迹切分为 16–512 事件的块，边界尽量对齐时间戳变化，同时事件不被拆分。每训练 epoch 约 7.21 亿预测目标。词表 78,384 个临床事件类型 + 4 个保留 token，`|V|=78,388`。
- **下游任务（生物监测）**：
  - **需上报传染病分类**：14 类（7 个较高频命名疾病、6 个临床归组的罕见疾病类、1 个匹配对照），约 19,129 例。
  - **ICD 症状学分类**：4 类（胃肠道综合征、呼吸道综合征、其他已知疾病、匹配对照），约 118,010 例。
  - 每个样本使用索引日前 2 个月的临床事件（不含索引日），预测类别。采用扩展时间评估：2019 训练→2020 测试；2019–2020 训练→2021 测试；2019–2021 训练→2022 测试。

- **CPT 指标**：全局测试交叉熵（CE，nats），以及按训练频率十等分（D1 最罕见 → D10 最高频）的分层 CE、Top-1 和 Top-10 准确率。

- **主干**：OLMo2 1B、Llama3.2 1B、OLMo2 7B（均冻结）。不选 Llama 3.1 8B 以避免模型规模与派生来源混淆。
