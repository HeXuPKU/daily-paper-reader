## 摘要
电子健康记录（EHR）将临床病史编码为（时间、模态、编码）元组，而预训练语言模型期望的是文本词元。将其序列化为文本会膨胀序列长度，并冗余地编码结构。我们提出 EHRAdapt，一种适配器，可将元组直接映射到冻结语言模型的嵌入空间。模态获得一个可学习的嵌入，时间间隔通过可学习的注意力偏置进入，事件编码获得专用向量。学习事件向量是核心挑战：临床词表呈长尾分布，导致罕见事件的观测过少，难以可靠估计。因此，EHRAdapt 将每个事件向量表示为语义先验与证据残差之和。先验是一个冻结嵌入，来自在临床本体上训练的生物医学语言模型对事件临床描述的输出，并通过共享的可学习投影映射到模型输入空间，从而在观测稀缺时仍能提供临床含义。残差是一个可学习的低秩、事件特定校正，随着证据积累对其细化。我们使用三个冻结的 LLM 主干（OLMo2 1B、Llama3.2 1B 和 OLMo2 7B），在约 400 万患者的记录上进行继续预训练，仅训练适配器（占全部参数的 0.1%–0.6%）。完整适配器在每个主干上的留出集下一事件预测中均优于所有消融。移除语义通路对罕见事件的损害比最常见事件高出十倍以上，而移除残差会损害整体预测，却对最罕见事件有所改善。在法定报告传染病和综合征下游分类任务上，EHRAdapt 优于基于文本的 LLM 和基于计数的基线，且两条通路均改善罕见疾病判别。因此，这两条通路发挥互补作用，只有按事件频率细分结果而非取平均时才能显现。

## Abstract
Electronic health records (EHRs) encode clinical histories as (time, modality, code) tuples, whereas pretrained language models expect text tokens. Serializing them as text inflates sequence length and redundantly encodes structure. We introduce EHRAdapt, an adapter that maps tuples directly into a frozen language model's embedding space. Modality receives a learned embedding, time gaps enter through learned attention biases, and event codes receive dedicated vectors. Learning event vectors is the central challenge: clinical vocabularies are long-tailed, leaving rare events too few observations for reliable estimates. EHRAdapt therefore represents each event vector as the sum of a semantic prior and an evidence residual. The prior is a frozen embedding of the event's clinical description from a biomedical language model trained on clinical ontologies, mapped into the model's input space by a shared learned projection, so it supplies clinical meaning even when observations are scarce. The residual, a learned low-rank event-specific correction, refines it as evidence accumulates. We run continued pretraining on about 4 million patients' records with three frozen LLM backbones (OLMo2 1B, Llama3.2 1B, and OLMo2 7B), training only the adapter (0.1--0.6% of all parameters). The full adapter outperforms all ablations in held-out next-event prediction on every backbone. Removing the semantic pathway hurts rare events over ten times more than the most frequent ones, whereas removing the residual hurts overall prediction but improves it for the rarest events. On reportable infectious-disease and syndromic downstream classification tasks, EHRAdapt outperforms text-based LLM and count-based baselines, and both pathways improve rare-disease discrimination. The two pathways therefore play complementary roles, visible only when results are broken down by event frequency rather than averaged.

## 1. 核心问题与研究动机

- **表示鸿沟**：电子健康记录（EHR）以 `(时间, 模态, 编码)` 元组形式存储临床事件，而预训练语言模型（LLM）期望的是文本 token。
- **文本序列化的代价**：把每个元组转写成文本会显著拉长患者历史序列，且事件类型（诊断/化验/用药）与时间信息只能被隐式编码，结构被冗余地重复表达。
- **长尾分布困境**：临床事件分布高度倾斜。在本文训练数据中，事件类型的中位出现次数仅约 20 次，而最常见事件约出现 8760 万次；约 50.1% 的事件类型出现 ≤ 20 次。罕见事件往往携带关键诊断信息，但 EHR 数据本身无法提供足够观测来独立估计其可靠表示。
- **评估偏差风险**：平均预测损失被高频事件主导，容易掩盖模型在罕见事件上的巨大效应，因此必须按频率分层评估。
- **整体含义**：论文提出 EHRAdapt——一种把结构化 EHR 事件直接映射进**冻结** LLM 嵌入空间的轻量适配器，通过"语义先验 + 证据残差"两条通路解决罕见事件表示问题，并强调只有在频率细分视角下才能观察到两条通路的互补作用。

## 2. 方法论

### 2.1 核心思想
- 每个临床事件**只占一个序列位置**，直接映射为 LLM 输入空间中的向量，而非展开为多个文本 token。
- 事件向量被分解为两部分：**语义先验**（来自生物医学语言模型的临床描述嵌入）与**证据残差**（从 EHR 轨迹中学到的低秩事件特定校正）。
- 语义先验在观测稀缺时提供临床含义，残差随证据积累逐步细化表示；二者按事件频率自然分工，类似贝叶斯学习中先验在数据稀缺时权重更大（但模型本身不做贝叶斯推断）。

### 2.2 关键公式与流程

**事件表示（式 1）**：
- 事件码向量：`e_c = P_sem(z_c) + r_c`，其中 `r_c = B·a_c`
- 输入向量：`x_i = e_{c_i} + e_mod(m_i)`
- 其中：
  - `z_c`：事件临床描述的**冻结 BioLORD 嵌入**（768 维，经均值池化 + L2 归一化 + 全局中心化）
  - `P_sem`：**共享的可学习投影**（H×768），将语义向量映射到主干隐藏维度 H
  - `a_c`：可学习的事件特定编码（维度 r）
  - `B`：共享投影（H×r），`r_c = B·a_c` 构成低秩残差
  - `e_mod(m_i)`：模态嵌入（仅输入侧使用）
- **低秩参数优势**：残差表 `R = AB^T` 秩 ≤ r，参数为 `(V+H)r`；H=2048、r=64 时约 515 万参数，相比无约束表（约 1.61 亿）仅 3.2%。

**固定语义几何的替代方案**：
- 可令 `P_sem = αQ`，其中 `Q^T Q = I`，则 BioLORD 空间中的所有角度与余弦近邻排序被严格保留，对应"固定先验"解释；论文将其作为对照实验。

**输出头（式 2）**：
- 与事件码表绑定：`logit_{i,c} = s·(h_i · e_c) + β_c`，`s = exp(logit_scale)`
- 输出表示**刻意排除模态嵌入**；`β_c` 为可学习事件偏置，`logit_scale` 为可学习缩放。
- 线性 `P_sem` 与投影残差使未缩放分数可分解为 `(h_i P_sem)Z^T + (h_i B)A^T`，避免物化 V×H 矩阵。
- **梯度来源**：输入侧仅在事件 c 出现时更新 `a_c`；输出侧因全 softmax 在每个位置对所有事件打分，故 `a_c` 每步都更新——事件频率决定的是"以 c 为输入/目标"的更新次数，而非总更新次数。

**时间注意力偏置（式 3）**：
- 在注意力分数上加入按层、按头学习的时间偏置：`q_i^T k_j / √d_head + b^{(ℓ,h)}_{κ(Δt_ij)}`
- `Δt_ij = t_i − t_j` 被归入 16 个时间桶（桶 0 专用于同时事件），偏置初始化为零，训练开始时保持主干注意力不变。
- 借鉴 T5 的分桶相对位置偏置思想，但用**真实时间间隔**替代 token 距离。

### 2.3 训练范式
- 两阶段：先在纵向 EHR 上做**继续预训练（CPT）**，目标为下一事件交叉熵；再复用适配后的模型做下游任务。
- 主干完全冻结，仅训练适配器（占全部参数的 **0.1%–0.6%**）；模型无关，可替换任意 LLM 主干。

## 3. 实验设计

### 3.1 数据集与场景
- **CPT 数据**：Kaiser Permanente Northern California（KPNC）EHR，约 **400 万患者**，2010–2018 年；包含人口统计学、化验、操作、用药、就诊类型、主诉、诊断码、生命体征（**不含具体数值与结局**）。
- **划分**：确定性、带种子的患者级划分，98% / 1% / 1%（训练/验证/测试）。
- **分块**：16–512 事件为一块，尽量按时间戳边界切分，尾块 <16 并入前块；每 epoch 约 **7.21 亿**预测目标；词表 78,384 个临床事件类型 + 4 个保留 token。
- **频率分层**：按训练频率分 10 个十分位（D1 最稀有 → D10 最常见）；因存在并列单例，D1–D10 并非等量分箱。

### 3.2 下游任务（生物监测场景）
- **基于 ICD 的综合征分类**：4 类（GI 综合征、呼吸综合征、其他已知疾病、匹配对照），约 11.8 万样本；报告 4 类宏平均、GI 与呼吸的一对多分数。
- **法定报告传染病分类**：14 类（7 种较高频具名疾病 + 6 个临床分组罕见病类 + 匹配对照），约 1.91 万样本；报告 All 14、Diseases 13、Frequent 7、Rare 6。
- **评估设置**：使用索引日前 2 个月的临床事件（排除索引日），采用**扩展式时间评估**（2019 训练→2020 测试；2019–2020→2021；2019–2021→2022）。
- 明确说明这些任务只评估监测的一个组成部分，**不衡量暴发检测或警报提前时间**。

### 3.3 对比方法与消融
- **主干**：OLMo2 1B、Llama3.2 1B、OLMo2 7B（三者均冻结）。
- **消融配置**（每个主干各一套）：
  1. Full model（可学习 `P_sem` + 秩 64 残差）
  2. Semantic prior only（去掉残差，r=0）
  3. Residual embeddings only（去掉语义通路）
  4. Frozen isometry + residual（固定 `P_sem = αQ`，保留残差）
  5. Frozen isometry only（固定投影且无残差）
- **额外对照**：OLMo2-1B 上的**模态内 BioLORD 向量置换对照**（打乱事件与临床描述的对应关系）与**残差秩扫描** r ∈ {0, 16, 64, 256, 512}。
- **下游基线**：原生文本输入（同一主干读文本，取最后 token 隐藏态）、BioLORD 嵌入（均匀平均 / 按事件龄指数衰减加权）、调优的随机森林（基于事件计数，树数 100–500 调优）。
- **探针**：所有表示均冻结，统一使用 ℓ2 正则逻辑回归探针（C ∈ {0.1, 1, 10} 按表示/任务/训练窗口用患者分组验证选择），并用有效样本数倒数加权（β=0.999）处理类别不平衡。

## 5. 实验数量与充分性

- **实验规模**：3 个主干 × 5 种配置 × 3 个随机种子，覆盖 CPT 全局与 10 个频率分层指标（CE、Top-1、Top-10）；另加置换对照与 5 档秩扫描。

- **充分性与公平性**：

- **局限**：
  - 基线不依赖 CPT 种子，**只运行一次、无 SD**；论文明确**未做显著性检验**。
  - 置换对照仅在 OLMo2-1B、秩 64 上运行，且 3 个种子不足以衡量置换本身的不确定性。

## 6. 主要结论与发现

- **全局 CPT**：Full model 在三个主干上均取得最低测试 CE（OLMo2-1B 2.847、Llama3.2-1B 2.806、OLMo2-7B 2.799 nats）；学习语义投影优于固定等距投影。
- **两条通路的互补性（按频率分层）**：
  - 移除语义通路对**稀有事件伤害最大**，且随频率升高惩罚递减。
  - 移除残差反而**改善最稀有事件（D1–D3）**，但损害中高频事件；两条曲线在 D5 附近交叉，D10 均趋近于零。
  - 因聚合 CE 被高频事件主导（D10 约占 98.6% 测试目标），稀有事件上的巨大效应在全局平均中几乎不可见。
- **置换对照**：打乱事件—描述对应后全局 CE 变差 0.042±0.020 nats，且在**每个分层、每个种子**都变差；D1、D2 优势最大（2.406、3.569 nats），D10 仅 0.039 nats，说明语义通路的增益来自**正确的临床描述对应**，而非向量分布本身。
- **下游任务**：Full model 在所有类别视图上超过所有基线。Rare-6 AUPRC 为 0.233–0.247（vs 随机森林 0.190）；4 类综合征 AUPRC 为 0.791–0.798（vs 随机森林 0.700）。呼吸类相对 RF 的优势（+0.244~0.254）大于 GI 类（+0.014~0.021）。
- **CPT 似然与下游表现不完全一致**：移除残差改善稀有事件似然，却使 Rare-6 AUPRC 下降 0.9–2.1 个百分点；移除语义分支损失 3.6–5.1 个 Rare-6 点，而 Frequent 7 仅损失 1.3–2.5 点。
- **表示几何**：学习 `P_sem` 大体保留 BioLORD 的最近邻（C），但显著改变相似度数值（角度）；加入
