## 摘要
电子健康记录（EHR）将临床病史编码为（时间、模态、代码）元组，而预训练语言模型期望的是文本词元。将其序列化为文本会膨胀序列长度，并冗余地编码结构。我们提出 EHRAdapt，一种适配器，可将元组直接映射到冻结语言模型的嵌入空间。模态获得一个学习到的嵌入，时间间隔通过学习到的注意力偏置进入，事件代码获得专用向量。学习事件向量是核心挑战：临床词汇呈长尾分布，罕见事件观测过少，难以可靠估计。因此，EHRAdapt 将每个事件向量表示为语义先验与证据残差之和。先验来自在临床本体上训练的生物医学语言模型对事件临床描述的冻结嵌入，并通过共享的学习投影映射到模型输入空间，因此即使在观测稀缺时也能提供临床语义。残差是一个学习到的低秩、事件特定的校正项，随着证据积累对其进行细化。我们在约 400 万患者记录上，以三个冻结的 LLM 主干（OLMo2 1B、Llama3.2 1B 和 OLMo2 7B）进行继续预训练，仅训练适配器（占全部参数的 0.1--0.6%）。完整适配器在每个主干上的留出集下一事件预测中均优于所有消融。移除语义通路对罕见事件的损害比最频繁事件高出十倍以上，而移除残差会损害整体预测，但对最罕见事件反而有所改善。在可报告传染病和综合征下游分类任务上，EHRAdapt 优于基于文本的 LLM 和基于计数的基线，且两条通路均改善罕见疾病判别。因此，两条通路发挥互补作用，这种作用只有在按事件频率细分结果而非取平均时才可见。

## Abstract
Electronic health records (EHRs) encode clinical histories as (time, modality, code) tuples, whereas pretrained language models expect text tokens. Serializing them as text inflates sequence length and redundantly encodes structure. We introduce EHRAdapt, an adapter that maps tuples directly into a frozen language model's embedding space. Modality receives a learned embedding, time gaps enter through learned attention biases, and event codes receive dedicated vectors. Learning event vectors is the central challenge: clinical vocabularies are long-tailed, leaving rare events too few observations for reliable estimates. EHRAdapt therefore represents each event vector as the sum of a semantic prior and an evidence residual. The prior is a frozen embedding of the event's clinical description from a biomedical language model trained on clinical ontologies, mapped into the model's input space by a shared learned projection, so it supplies clinical meaning even when observations are scarce. The residual, a learned low-rank event-specific correction, refines it as evidence accumulates. We run continued pretraining on about 4 million patients' records with three frozen LLM backbones (OLMo2 1B, Llama3.2 1B, and OLMo2 7B), training only the adapter (0.1--0.6% of all parameters). The full adapter outperforms all ablations in held-out next-event prediction on every backbone. Removing the semantic pathway hurts rare events over ten times more than the most frequent ones, whereas removing the residual hurts overall prediction but improves it for the rarest events. On reportable infectious-disease and syndromic downstream classification tasks, EHRAdapt outperforms text-based LLM and count-based baselines, and both pathways improve rare-disease discrimination. The two pathways therefore play complementary roles, visible only when results are broken down by event frequency rather than averaged.

## 1. 核心问题与研究背景

- **问题根源**：电子健康记录（EHR）以（时间、模态、代码）元组形式存储临床事件，而预训练语言模型（LLM）期望文本词元输入，二者存在表示鸿沟。
- **序列化文本的缺陷**：
  - 标准 LLM 分词器会把一个临床事件拆成多个词元，导致患者历史序列长度膨胀。
  - 事件类型（诊断/化验/用药等）与时间信息只能被**隐式**编码，结构冗余。
- **长尾分布挑战**：临床事件频率高度偏斜。本文训练数据中，事件类型的中位出现次数约 **20 次**，而最高频事件约 **8760 万次**（图 4）；约 50.1% 的事件类型出现 ≤20 次。罕见事件虽含重要诊断信息，但可用样本太少，难以独立学到可靠表示。
- **评估偏斜问题**：平均预测损失被高频事件主导，会掩盖对罕见事件的巨大效应，因此必须按频率分层评估。
- **整体含义**：与其从零训练 EHR 专用基础模型（成本高、需随新架构重训），不如**将已有 LLM 适配到结构化 EHR**；但直接文本化会带来上述问题，EHRAdapt 旨在用轻量适配器 + 语义先验解决数据稀缺下的罕见事件建模。

## 2. 方法论

### 2.1 核心思想

- 训练一个**适配器**，把结构化 EHR 元组**直接映射**到**冻结 LLM** 的嵌入空间，每个临床事件只占**一个序列位置**。
- 事件向量分解为两部分之和：
  - **语义先验**：来自临床描述在生物医学语言模型（BioLORD）中的冻结嵌入，携带临床知识，在观测稀缺时仍有效。
  - **证据残差**：事件特定的低秩可学习校正，随 EHR 证据积累而细化表示。
- 类比贝叶斯学习：数据稀缺时先验影响更大（罕见事件更贴近语义先验），数据充足时残差主导（高频事件更多由 EHR 数据塑造）——但作者明确说明**并未真正执行贝叶斯推断，也未显式强制该行为**。

### 2.2 关键技术细节

- **事件表示**（式 1）：
  - `e_c = P_sem(z_c) + r_c`，其中 `r_c = B a_c`
  - `z_c`：事件名称经冻结 BioLORD 编码得到的 768 维向量（均值池化 + L2 归一化 + 全局去中心化，不白化）
  - `P_sem`：**共享**的可学习投影（H×768），把语义向量映射到主干隐藏维度 H
  - `a_c`：事件特定可学习码（维度 r）；`B`：共享投影（H×r）
  - 输入表示：`x_i = e_{c_i} + e_mod(m_i)`（模态嵌入仅用于输入）
- **低秩残差与参数效率**：
  - 残差表 `R = A B^T`，秩 ≤ r，参数量为 `(V+H)r`，远小于无约束的 `VH`。
  - H=2048、r=64 时约 515 万参数，而无约束表约 1.61 亿（约 3.2%）。
  - 更高秩提升聚合拟合，但**不保证罕见事件更好**。
- **固定等距投影对照**：可令 `P_sem = αQ`（`Q^T Q = I`），严格保持 BioLORD 空间的夹角与余弦近邻排序，对应"固定先验"解释；默认模型则学习 `P_sem`，允许语义分量适配主干。
- **输出头与打分**（式 2）：
  - 输出头与事件码表 **E 绑定（tied）**，`logit_{i,c} = s (h_i · e_c) + β_c`，`s = exp(logit_scale)`
  - **模态嵌入刻意不进入输出表示**
  - 线性 `P_sem` + 投影残差可因式分解为 `(h_i P_sem) Z^T + (h_i B) A^T`，避免实体化 V×H 矩阵
  - 由于输入输出共享 `a_c`：输入侧仅当事件出现时更新，输出侧全 softmax 每步都更新
- **时间注意力偏置**（式 3）：
  - 在注意力 logits 上加**学习到的分桶偏置**，按经过时间 `Δt_ij` 分入 **16 个桶**（Δt=0 有专用桶）
  - 借鉴 T5 的分桶相对位置偏置，但用**经过时间**替代词元距离；偏置初始化为 0，训练开始时不影响主干注意力
- **初始化细节**：
  - `P_sem` 采用缩放半正交初始化，缩放目标为匹配主干预训练词元嵌入的平均范数（OLMo2-1B 10.724、Llama3.2-1B 0.987、OLMo2-7B 7.423）
  - 输出偏置 `β_c` 初始化为 `log p(c)`，相比均匀初始化降低初始 CE 4.899 nats
  - `logit_scale` 在训练校准子集上一维最小化标定

### 2.3 训练流程

- **两阶段**：
  1. **继续预训练（CPT）**：在纵向 EHR 上做下一事件交叉熵预测（单位 nats），主干冻结，仅训适配器。
  2. **下游复用**：最简单设置下适配器冻结，只训任务头（可用 LoRA 进一步适配，但本文未探索）。
